# Modul To-do {: #To-Do}


## Aktivierung des Moduls {: #activation}

Das Modul "To-do" als persönliches Werkzeug muss durch einen/eine Administrator:in vorgenommen werden.

![Modul To-do in der Modulliste einschalten und die Einstellungen für persönliche To-dos festlegen; Administration > Module > To-do](assets/todo_v1_de.png){ class="shadow lightbox" }

### Persönliches Werkzeug {: #personal_tool}

#### Eingeschaltet {: #enabled}

Schaltet das persönliche Werkzeug "To-do" für die OpenOlat-Instanz ein oder aus. Ist das Feld ausgeschaltet, steht das Werkzeug im persönlichen Menü nicht zur Verfügung, und die folgenden Felder sind ausgeblendet.

#### Erstellung persönlicher To-dos {: #create}

Legt fest, wer eigene To-dos erstellen darf: alle Benutzer:innen, nur Autor:innen und Manager:innen, oder niemand (deaktiviert).

#### Zuweisung an andere Benutzer:innen {: #assignee}

Legt fest, welche Benutzer:innen als Empfänger:innen einer Zuweisung zur Auswahl stehen: alle Benutzer:innen, nur Gruppenkontakte, oder keine (deaktiviert).

#### Delegierung an andere Benutzer:innen {: #delegatee}

Legt fest, an welche Benutzer:innen ein To-do delegiert werden darf: an alle Benutzer:innen, nur an Gruppenkontakte, oder an keine (deaktiviert).
