# e-Assessment Administration: ePortfolio {: #portfolio}

The administration switches ePortfolio 2.0 on or off under `Administration > e-Assessment > ePortfolio` and defines to what extent participants may create and use their own binders.

#### Activate ePortfolio {: #eportfolio_enabled}

Switches the ePortfolio 2.0 module on or off for the OpenOlat instance. If the field is off, the following fields are hidden and the ePortfolio functions are no longer available in the user interface. Existing binders and entries are retained.

#### Create binder {: #create_binder}

Defines whether participants may create their own binders: empty, from a template, or from a course. The three options can be activated independently.

#### Landing point in binder {: #binder_entry_point}

Defines which tab is shown first when a binder is opened: Overview or Entries. The selected tab must be activated under Visible sections, otherwise OpenOlat automatically switches to the other tab.

#### Visible sections {: #visible_tabs}

Defines which tabs are visible in a binder: Overview, Entries, and History. The tab selected as landing point in binder cannot be switched off.

#### Visible elements {: #visible_elements}

Defines whether the elements Search and Timeline are shown in the Entries tab.

#### Comments visible in {: #comments_visible}

Defines whether comments are visible in the overview and in the entries.

#### View of the entries {: #entries_view}

Defines in which view the entries of a binder are shown: table view, list view, or both.

#### Enable taxonomy linking {: #taxonomy_linking}

Switches the linking of taxonomies with the ePortfolio on or off. For participants to be able to assign taxonomies to their portfolio entries and use them in the [ePortfolio](../../manual_user/area_modules/Competences_tags.md), this option must be active.

![Enable taxonomy linking and linked taxonomies; Administration > e-Assessment > ePortfolio](assets/Tax%20eP%20aktivieren%20EN.png){ class="shadow lightbox" }

#### Linked taxonomies {: #linked_taxonomies}

Selects which of the taxonomies available in the system are available in the ePortfolio. This field only appears when taxonomy linking is enabled.
