# Anonymous guests and external users {: #guests_and_externals}

In addition to registered users, OpenOlat can also be used by

* **Guests** (anonymous, can only use the offers available to guests)
* **External users** (at least known by email, are only invited by email to a very specific course/group/portfolio/project, maximum usage period: default setting 180 days)

Administrators can determine whether and to what extent OpenOlat can be used in this way. You find these settings in the system administration under:<br>
`Administration > Login > Anonymous and external user`

## Anonymous guests {: #guests}

![Guest login and Links for guests activated, Full-text search for guest switched off, in the tab Anonymous user (guest)](assets/login_anonymous_external_user_tab1_v1_de.png){ class="shadow lightbox" }

* **"Guest login on login page":**<br>
Means that the guest access can be chosen on the login page.

* **"Links for guests":**<br>
In the access configuration access of courses can be given to guests.

* **"Full-text search for guest":**<br>
Allows guests to search system-wide for courses that are available to them.

## External users {: #externals}

![Invitation can be activated separately for each area, for course and groups additionally role and activation mode, tab External user](assets/login_anonymous_external_user_tab2_v1_de.png){ class="shadow lightbox" }

### Course

**"Invitation external users":**<br>
This setting determines whether external users are generally allowed for courses and can be invited.

**Role can invite**<br>
This setting determines which roles may invite external users to courses:<br>
- by administrators<br>
- by learning resource managers

**Owner with author role can invite**<br>
- **For all courses activated:** Means that course owners can invite external users at any time.<br>
- **Must be activated per course:** Means that an administrator or learning resource manager must first activate the function in the course settings before course owners can invite external users to a course.

### Groups

**"Invitation external users":**<br>
This setting determines whether external users are generally allowed in the "Groups" area and can be invited.

**Role can invite**<br>
This setting determines which roles may invite external users to groups:<br>
- by administrators<br>
- by group managers

**Coach with author role can invite**<br>
- **Activate for all groups:** Means that group coaches can invite external users at any time.<br>
- **Must be activated per group:** Means that an administrator or group manager must first activate the function in the group administration before group coaches with author rights can invite external users to a group.

### Portfolio

**"Invitation external users":**<br>
This setting determines whether external users are generally allowed in the "Portfolio" area and can be invited.


### Project

**"Invitation external users":**<br>
This setting determines whether external users are generally allowed in projects and can be invited.


!!! tip "Hint"

    In user management under `User type > External user` you get an overview of all external users.
