# Glossar

Ein Referenzglossar produktspezifischer Begriffe in OpenOlat. Diese Begriffe haben innerhalb des OpenOlat-LMS eine bestimmte Bedeutung. Das Glossar wird automatisch aus dem OpenOlat-Begriffsmodell generiert und umfasst 712 Begriffe.

## Katalog, Buchung und Bezahlung

Vom Katalogeintrag bis zur bezahlten Mitgliedschaft.

### Angebot

Die Festlegung, unter welchen Bedingungen eine Lernressource gebucht werden kann: für wen, in welchem Zeitraum, zu welchem Preis und auf welche Art. Eine Ressource kann mehrere Angebote nebeneinander führen.

*Englisch: Offer* · [Handbuch](../manual_user/area_modules/catalog2.0_angebote.de.md)

### Belastung

Eine Transaktion, die einer Person Kreditpunkte abzieht, zum Beispiel beim Einlösen für eine Rezertifizierung.

*Englisch: Debit*

### Buchung

Der Vorgang, mit dem eine Person Zugang zu einer Lernressource erhält. Er endet mit der Mitgliedschaft im Kurs oder mit einem Platz auf der Warteliste.

*Englisch: Booking* · [Handbuch](../manual_user/personal_menu/Bookings.de.md)

### Buchungsauftrag

Der Datensatz, der bei einer Buchung entsteht. Er hält fest, wer wann was zu welchem Preis gebucht hat, und bleibt auch nach dem Ende des Kurses erhalten.

*Englisch: Booking order* · [Handbuch](../manual_user/area_modules/Reports_BookingOrders.de.md)

### Gutschrift

Eine Transaktion, die einer Person Kreditpunkte hinzufügt, in der Regel nach einem bestandenen Kurs.

*Englisch: Credit*

### Katalog (Modul)

Das Modul, das Lernressourcen und Durchführungen mit einem Angebot zum Buchen ausstellt. Es ist über Taxonomie und Launcher gegliedert. Ohne Angebot erscheint eine Ressource nicht. Ohne Anmeldung ist es als Web-Katalog erreichbar, wenn dieser eingeschaltet ist.

*Englisch: Catalog* · [Handbuch](../manual_admin/administration/Modules_Catalog_2.0.de.md)

### Katalog (Navigationspunkt)

Der Eintrag Katalog in der Hauptnavigation, über den angemeldete Personen den Katalog öffnen. Er ist die Auslage der Plattform. Für Personen ohne Anmeldung spiegelt ihn der Web-Katalog.

*Englisch: Catalog* · [Handbuch](../manual_admin/administration/Modules_Catalog_2.0.de.md)

### Katalogverwaltung

Der Eintrag in der Hauptnavigation, über den der Katalog 1.0 gepflegt wird: seine Kategorien und die Zuordnung der Lernressourcen. Er erscheint nur, wenn der Katalog 1.0 eingeschaltet ist. Den Katalog 2.0 verwaltet die Administration unter Module.

*Englisch: Catalog administration* · [Handbuch](../manual_user/area_modules/catalog1.0.de.md)

### Kostenstelle

Die Stelle im Rechnungswesen der Organisation, welche die Kosten einer Buchung trägt.

*Englisch: Cost center* · [Handbuch](../manual_user/area_modules/Reports_BookingOrders.de.md)

### Kreditpunkte

Das Modul, das Kreditpunkte je Person in einem Kreditpunktesystem führt, sie bei bestandenen Kursen gutschreibt und in Zertifikatsprogrammen für die Rezertifizierung wieder abzieht. Das Bezahlen von Buchungen mit Kreditpunkten ist angekündigt, aber nicht umgesetzt.

*Englisch: Credit points* · [Handbuch](../manual_user/personal_menu/Credit_Points.de.md)

### Kreditpunktesystem

Ein benanntes System von Kreditpunkten mit eigener Einheit und eigenen Regeln, zum Beispiel ECTS. Eine Installation kann mehrere davon führen.

*Englisch: Credit point system* · [Handbuch](../manual_admin/administration/e-Assessment_Credit_Points.de.md)

### Launcher

Ein konfigurierbarer Abschnitt auf der Startseite des Katalogs, der Katalogeinträge nach einer Regel zusammenstellt. Es gibt sieben Launchertypen, zum Beispiel Taxonomieebene, Zuletzt veröffentlicht oder Beliebte Kurse.

*Englisch: Launcher* · [Handbuch](../manual_admin/administration/Modules_Catalog_2.0.de.md)

### Mehrwertsteuer

Die Mehrwertsteuer auf einem kostenpflichtigen Angebot. Der Satz wird systemweit hinterlegt und auf der Rechnung ausgewiesen.

*Englisch: VAT* · [Handbuch](../manual_admin/administration/Payment_modules.de.md)

### PayPal

Anbindung von PayPal als Zahlungsart für kostenpflichtige Angebote.

*Englisch: PayPal* · [Handbuch](../manual_admin/administration/Payment_PayPal.de.md)

### Rechnung

Die Zahlungsart, bei welcher der Betrag später in Rechnung gestellt wird, statt sofort online bezahlt zu werden.

*Englisch: Invoice* · [Handbuch](../manual_admin/administration/Payment_Invoice.de.md)

### Rechnungsadresse

Die Anschrift, an welche die Rechnung geht. Sie kann von der Anschrift der buchenden Person abweichen, etwa bei Buchung durch den Arbeitgeber.

*Englisch: Billing address* · [Handbuch](../manual_user/area_modules/Reports_BookingOrders.de.md)

### Transaktion

Eine einzelne Bewegung auf dem Kreditpunktkonto: Gutschrift, Belastung, Abzug, Storno oder Verfall. Der Bestand ist die Summe aller Transaktionen.

*Englisch: Transaction*

### Vorbestellung

Eine Buchung, die eingetragen wird, bevor die Person das Konto hat. Sie wartet, bis sich die Person über Shibboleth oder Selbstregistrierung anmeldet, und wird dann ausgeführt.

*Englisch: Pre-order*

### Warteliste

Die Reihe der Personen, die einen Kurs buchen oder sich in eine Gruppe eintragen wollten, als kein Platz mehr frei war. Wird ein Platz frei, rückt die erste Person nach, auf Wunsch selbständig.

*Englisch: Waiting list* · [Handbuch](../manual_user/groups/Create_Groups.de.md)

### Web-Katalog

Die Spiegelung des Katalogs ausserhalb der Anmeldung: Personen ohne Konto sehen Angebote, Preise und freie Plätze und werden erst beim Buchen durch die Registrierung geführt. Er setzt einen Katalog 2.0 voraus und wird in der Administration eingeschaltet.

*Englisch: Web catalog* · [Handbuch](../manual_user/area_modules/catalog2.0_web.de.md)

### Zugangscode

Eine Angebotsart, bei der nur Personen mit dem richtigen Code buchen können. Der Code wird ausserhalb von OpenOlat verteilt.

*Englisch: Access code* · [Handbuch](../manual_user/basic_concepts/Offer_Concepts.de.md)

### Zugangskontrolle

Das Modul, das entscheidet, wer eine Lernressource betreten darf und zu welchen Bedingungen. Es verwaltet die Angebote, die Buchungen und die Zahlungsarten.

*Englisch: Access control* · [Handbuch](../manual_admin/administration/Core_functions.de.md)

## Course Planner

Die Planungsebene über den Kursen: welches Bildungsangebot es gibt (Produkt), wie es strukturiert ist (Element) und wann es konkret läuft (Durchführung).

### Automatisierung

Die Regeln, mit denen der Course Planner wiederkehrende Arbeiten selbständig ausführt, zum Beispiel Kurse aus Templates erzeugen oder Durchführungen öffnen und schliessen.

*Englisch: Automation* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Automatisierungsregel

Eine einzelne Regel der Automatisierung. Sie besteht aus einem Auslöser, entweder ein Statuswechsel oder ein Zeitpunkt relativ zum Durchführungszeitraum, und einer Handlung wie Kurs instanziieren oder Status setzen. Der Elementtyp gibt sie vor, die Durchführung kann sie überschreiben.

*Englisch: Automation rule* · [Handbuch](../manual_admin/administration/Modules_Course_Planner.de.md)

### Bildungsprodukte (Course Planner)

Ein im Course Planner geführtes Bildungsangebot aus mehreren Kursen und Durchführungen, wie es Coaching und Katalog anzeigen.

*Englisch: Educational products* · [Handbuch](../manual_user/area_modules/Coaching_Educational_Products.de.md)

### Course Planner (Course Planner)

Das Modul, das die Planung des Bildungsangebots in OpenOlat einschaltet: Produkte mit Elementen und Durchführungen, Elementtypen, Kurstemplates, Automatisierung, To-dos und Reports. Es ersetzt das frühere Modul Curriculum und vergibt die Mitgliedschaften der eingebundenen Kurse.

*Englisch: Course Planner* · [Handbuch](../manual_admin/administration/Modules_Course_Planner.de.md)

### Durchführung

Der konkrete Durchgang eines Bildungsangebots, mit Zeitraum, Ort, Mitgliedern und Kursen. Das Produkt beschreibt, was angeboten wird, die Durchführung, wann und mit wem es tatsächlich läuft.

*Englisch: Implementation* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Element

Ein Knoten in der Struktur eines Produkts. Je nach Elementtyp steht er für einen Studiengang, ein Semester, ein Modul oder eine Durchführung. Die Elemente bilden die Hierarchie, in welche die Kurse eingehängt werden.

*Englisch: Element* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Elementtyp

Die Art eines Elements im Course Planner. Der Elementtyp legt fest, welche Elemente darunter erlaubt sind, ob das Element Mitglieder führt und wie es im Katalog erscheint.

*Englisch: Element type* · [Handbuch](../manual_admin/administration/Modules_Course_Planner.de.md)

### Instanziierung

Das Erzeugen eines Kurses aus einem Kurstemplate für eine bestimmte Durchführung. Das Template bleibt unverändert und dient weiteren Durchführungen.

*Englisch: Instantiation* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Kurstemplate

Ein Kurs, der im Course Planner einem Element zugewiesen wird, um daraus für jede Durchführung einen eigenen Kurs zu instanziieren. Das Template selbst wird nicht besucht und bleibt unverändert.

*Englisch: Course template* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Mitgliedschaft (Course Planner)

Die Zugehörigkeit einer Person zu einem Kurs, einer Gruppe oder einem Element des Course Planner, zusammen mit ihrer Rolle darin.

*Englisch: Membership* · [Handbuch](../manual_user/area_modules/Course_Planner_Implementations.de.md)

### Produkt

Die oberste Ebene im Course Planner. Ein Produkt beschreibt ein Bildungsangebot mit seiner Struktur, unter der die Elemente und die Durchführungen hängen.

*Englisch: Product* · [Handbuch](../manual_user/area_modules/Course_Planner_Products.de.md)

### Reports (Course Planner)

Der Bereich des Course Planner mit vorgefertigten Auswertungen zu den Buchungsaufträgen, erzeugt als Excel-Datei aus Report-Vorlagen. Er steht in der Übersicht für alle Durchführungen und als Tab auf jedem Produkt und jeder Durchführung für deren eigene.

*Englisch: Reports* · [Handbuch](../manual_user/area_modules/Course_Planner_Reports.de.md)

### Stundenplan

Die Zusammenstellung aller Termine einer Durchführung zu einem Plan, mit Räumen und Betreuenden.

*Englisch: Timetable* · [Handbuch](../manual_admin/administration/Modules_Course_Planner.de.md)

### To-do (Course Planner)

Eine Pendenz an einem Element des Course Planner, mit verantwortlicher Person und Frist. Sie hält die Planungsarbeit am Objekt fest, statt in einer getrennten Liste.

*Englisch: To-do* · [Handbuch](../manual_user/area_modules/Course_Planner_Todos.de.md)

### Zeitabschnitt

Ein zentral gepflegter, benannter Zeitraum wie ein Semester oder ein Quartal, den ein Kurs als Durchführungszeitraum wählen kann. Er dient dem Filtern und Sortieren im Autorenbereich und in den Listen des Course Planner.

*Englisch: Time period* · [Handbuch](../manual_admin/administration/Modules_Time_Period.de.md)

## Lernressourcen

Was im Autorenbereich liegt, wie es beschrieben und eingeordnet wird, und was die einzelnen Lernressourcentypen ausmacht: Blog und Podcast, Glossar, Video, Dateien.

### Andere Datei

Lernressource für eine hochgeladene Datei, deren Format keinem der übrigen Typen entspricht.

*Englisch: Other file* · [Handbuch](../manual_user/learningresources/index.de.md)

### Animation

Lernressource für eine Animationsdatei.

*Englisch: Animation* · [Handbuch](../manual_user/learningresources/index.de.md)

### Annotation

Ein Textfeld, das für eine bestimmte Zeit über dem Video erscheint und eine Erklärung einblendet.

*Englisch: Annotation* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Audio (Lernressourcen)

Lernressource für eine einzelne Audiodatei.

*Englisch: Audio* · [Handbuch](../manual_user/learningresources/index.de.md)

### Audio/Video-Aufnahme

Modul, mit dem Personen Audio und Video direkt im Browser aufnehmen: im Media Center, im Content Editor, in der Aufgabe und im Video-Editor. Die Aufnahme wird im Hintergrund in ein browsertaugliches Format umgewandelt, lokal oder durch einen externen Dienst.

*Englisch: Audio/video recording* · [Handbuch](../manual_admin/administration/Modules_Audio_Video_Recording.de.md)

### Begriff (Lernressourcen)

Ein Eintrag im Glossar: das Wort, das erklärt wird, mit seiner Definition, seinen Synonymen und seinen Flexionen. Im Kurs wird jeder Begriff im Text hervorgehoben.

*Englisch: Term* · [Handbuch](../manual_user/learningresources/Glossary_create.de.md)

### Beurteilung (Lernressourcen)

Die Bewertung einer Lernressource oder eines Inhalts durch ihre Nutzenden mit einem bis fünf Sternen. Angezeigt wird der Durchschnitt aller abgegebenen Sterne; die eigene Beurteilung lässt sich jederzeit ändern. Die Administration schaltet die Funktion systemweit ein oder aus.

*Englisch: Rating* · [Handbuch](../manual_user/learningresources/Blog_Blogging.de.md)

### Bild (Lernressourcen)

Lernressource für eine einzelne Bilddatei.

*Englisch: Image* · [Handbuch](../manual_user/learningresources/index.de.md)

### Blog (Lernressourcen)

Lernressource für Beiträge in umgekehrt chronologischer Reihenfolge. Leserinnen und Leser können die Beiträge abonnieren und kommentieren.

*Englisch: Blog* · [Handbuch](../manual_user/learningresources/Blog.de.md)

### CP-Lerninhalt (Lernressourcen)

Lernressource im Format IMS Content Packaging. Sie enthält fertigen Lerninhalt mit eigener Navigation, der in einem anderen Werkzeug erstellt wurde.

*Englisch: CP learning content* · [Handbuch](../manual_user/learningresources/Course_Element_CP_Learning_Content.de.md)

### Datei

Lernressource für eine einzelne hochgeladene Datei, deren Format OpenOlat nicht besonders behandelt.

*Englisch: File* · [Handbuch](../manual_user/learningresources/index.de.md)

### Ebenentyp

Die Art einer Taxonomieebene. Der Ebenentyp legt fest, ob Ebenen dieses Typs sichtbar sind, als Kompetenz taugen und Leistungsnachweise gruppieren dürfen.

*Englisch: Level type* · [Handbuch](../manual_admin/administration/Modules_Taxonomy.de.md)

### Eintrag (Lernressourcen)

Ein Beitrag in einem Blog, mit Titel, Zusammenfassung, Inhalt, Bild und Veröffentlichungsdatum. Er ist Entwurf, geplant oder veröffentlicht; Lesende können ihn kommentieren, bewerten und ins Media Center übernehmen.

*Englisch: Entry* · [Handbuch](../manual_user/learningresources/Blog_Blogging.de.md)

### Episode

Ein Beitrag in einem Podcast mit einer Audio- oder Videodatei als Anhang. Sie wird in OpenOlat abgespielt, heruntergeladen oder über den RSS-Feed in einer Podcast-App gehört.

*Englisch: Episode* · [Handbuch](../manual_user/learningresources/Podcast_listen_and_watch.de.md)

### Excel

Lernressource für ein Excel-Dokument. Es lässt sich im Browser bearbeiten, wenn ONLYOFFICE oder Microsoft 365 angebunden ist.

*Englisch: Excel* · [Handbuch](../manual_user/learningresources/index.de.md)

### Film

Lernressource für eine Videodatei, die ohne die Zusätze der Lernressource Video nur abgespielt wird.

*Englisch: Movie*

### Fragebogen (Lernressourcen)

Altbestand: eine Fragebogen-Lernressource im Format QTI 1.2, die Meinungen erhob statt Wissen zu messen. Sie lässt sich weder erstellen noch importieren. Der Kursbaustein Fragebogen bindet heute eine Test-Lernressource ein, die als Fragebogen konfiguriert ist.

*Englisch: Questionnaire* · [Handbuch](../manual_user/learningresources/Course_Element_Survey.de.md)

### Glossar

Lernressource mit Begriffen und deren Erklärung. In einen Kurs eingebunden, hebt sie die Begriffe im Kurstext hervor und zeigt die Erklärung beim Überfahren mit der Maus.

*Englisch: Glossary* · [Handbuch](../manual_user/learningresources/Glossary.de.md)

### Glossarbegriffe einbinden

Die Hervorhebung der Glossarbegriffe im Kurstext. Ein gepunkteter Unterstrich zeigt einen Begriff an; die Definition erscheint beim Überfahren mit der Maus. Lernende schalten die Hervorhebung in der Toolbar ein und aus.

*Englisch: Embed glossary terms* · [Handbuch](../manual_user/learningresources/Glossary_usage.de.md)

### Kapitel

Eine Sprungmarke im Video. Die Lernenden wählen ein Kapitel und landen an dieser Stelle.

*Englisch: Chapter* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Kommentar

Eine Einblendung als Text oder als kurzes Video, die an einer Stelle des Videos zusätzliche Information gibt.

*Englisch: Comment* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Kommentare und Bewertungen

Der Dienst, mit dem Lesende einen Inhalt kommentieren und mit einem bis fünf Sternen bewerten. Blog und Podcast schalten ihn je Feed ein; Kommentare können Anhänge tragen und beantwortet werden.

*Englisch: Comments and ratings* · [Handbuch](../manual_user/learningresources/Blog_Blogging.de.md)

### Kompetenz

Eine Fähigkeit, die einer Person zugeschrieben wird, benannt über eine Taxonomieebene. Sie entsteht durch Zuweisung oder durch das Bestehen eines Kurses.

*Englisch: Competence* · [Handbuch](../manual_user/personal_menu/Competences.de.md)

### Lernressource

Ein Inhaltsobjekt, das im Autorenbereich verwaltet wird: Kurs, Test, Formular, Video, Wiki und weitere. Sie trägt Metadaten, Besitzende und einen Lebenszyklus und lässt sich in Kurse einbinden.

*Englisch: Learning resource* · [Handbuch](../manual_admin/administration/Modules_Learning_Resource.de.md)

### Lost+found

Der Ablageordner einer Taxonomie für die Dokumente gelöschter Taxonomieebenen, etwa aus dem Dokumentenpool. Er ist der letzte Tab der Taxonomie; die Dokumente lassen sich von dort nicht wiederherstellen.

*Englisch: Lost+found* · [Handbuch](../manual_admin/administration/Modules_Taxonomy.de.md)

### Medien-Server

Eine externe Videoplattform, deren Videos OpenOlat per URL einbetten darf: YouTube, Vimeo, nanoo.tv und frei definierte Server. Die Administration gibt die Server in den Sicherheitseinstellungen frei; gesperrte Domänen werden nicht abgespielt.

*Englisch: Media server* · [Handbuch](../manual_user/learningresources/Single_Page_Add_edit_video.de.md)

### Metadaten (Lernressourcen)

Die beschreibenden Angaben zu einer Lernressource: Titel, Beschreibung, Sprache, Autorenschaft, Lizenz, Taxonomie und Aufwand. Sie speisen Katalog und Suche.

*Englisch: Metadata* · [Handbuch](../manual_user/learningresources/Course_Settings_Metadata.de.md)

### PDF

Lernressource für ein PDF-Dokument. OpenOlat zeigt es im eingebauten Betrachter an, ohne dass es heruntergeladen werden muss.

*Englisch: PDF* · [Handbuch](../manual_user/learningresources/index.de.md)

### Podcast (Lernressourcen)

Lernressource für abonnierbare Audio- und Video-Episoden. Sie stellt einen RSS-Feed bereit, über den Episoden auch ausserhalb von OpenOlat gehört werden.

*Englisch: Podcast* · [Handbuch](../manual_user/learningresources/Podcast.de.md)

### Portfolio 2.0 Vorlage

Lernressource, die Aufbau und Aufträge einer Portfoliomappe vorgibt. Der Kursbaustein Portfolioaufgabe weist jeder teilnehmenden Person eine Mappe aus dieser Vorlage zu.

*Englisch: Portfolio 2.0 template* · [Handbuch](../manual_user/learningresources/Portfolio_template_Creation.de.md)

### PowerPoint

Lernressource für eine PowerPoint-Präsentation. Sie lässt sich im Browser bearbeiten, wenn ONLYOFFICE oder Microsoft 365 angebunden ist.

*Englisch: PowerPoint* · [Handbuch](../manual_user/learningresources/index.de.md)

### Quiz (Lernressourcen)

Eine Frage, die das Video an einer festgelegten Stelle anhält. Die Lernenden antworten, bevor es weiterläuft.

*Englisch: Quiz* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### SCORM 1.2 (Lernressourcen)

Lernressource im Format SCORM 1.2. Anders als beim CP-Lerninhalt meldet das Paket Fortschritt und Punkte an OpenOlat zurück, deshalb ist es bewertbar.

*Englisch: SCORM 1.2* · [Handbuch](../manual_user/learningresources/index.de.md)

### Segment (Lernressourcen)

Ein Zeitabschnitt des Videos mit Beginn, Dauer und einem Begriff als Beschriftung. Segmente überschneiden sich nicht; die Videoaufgabe lässt Lernende die Segmente einem Begriff zuordnen.

*Englisch: Segment* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Taxonomie

Ein hierarchischer Baum von Begriffen, mit dem Lernressourcen, Fragen, Dokumente und Kompetenzen eingeordnet werden. Er ist nicht die Bloomsche Taxonomie der Lernziele.

*Englisch: Taxonomy* · [Handbuch](../manual_admin/administration/Modules_Taxonomy.de.md)

### Taxonomieebene

Ein Knoten in einer Taxonomie. Er ordnet Lernressourcen, Fragen und Dokumente ein und kann als Kompetenz verwendet werden.

*Englisch: Taxonomy level* · [Handbuch](../manual_admin/administration/Modules_Taxonomy.de.md)

### Test (Lernressourcen)

Lernressource mit Fragen im Format QTI 2.1, die Wissen misst. Sie wird über den Kursbaustein Test oder Selbsttest in einen Kurs eingebunden und kann Fragen aus dem Fragenpool übernehmen.

*Englisch: Test* · [Handbuch](../manual_user/learningresources/Course_Element_Test.de.md)

### Test (QTI 1.2 - nicht mehr unterstützt)

Altbestand: eine Test-Lernressource im Format QTI 1.2. Seit Release 15.0 läuft sie nicht mehr, seit 16.0 lässt sie sich nicht mehr konvertieren. Sie kann weder erstellt noch importiert werden und erscheint nur noch in Listen alter Einträge.

*Englisch: Test (QTI 1.2 - no longer supported)* · [Handbuch](../manual_user/learningresources/Changing_from_QTI_1.2_to_QTI_2.1.de.md)

### Timeline (Lernressourcen)

Die Zeitachse unter dem Video. Sie zeigt jedes Ereignis an seiner Stelle: Kapitel, Annotation, Kommentar, Quiz und Segment.

*Englisch: Timeline* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Transkodierung

Die Umwandlung einer hochgeladenen Videodatei in mehrere Auflösungen, damit die Wiedergabe zur Leitung passt. Sie läuft im Hintergrund.

*Englisch: Transcoding* · [Handbuch](../manual_admin/administration/Modules_Video.de.md)

### Untertitel

Eine Untertitelspur zum Video, je Sprache eine Datei im WebVTT-Format. OpenOlat kann sie auch selbst erzeugen.

*Englisch: Subtitles* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Video (Lernressourcen)

Lernressource für eine Videodatei im Format mp4, ergänzt um Kapitel, Quizfragen, Kommentare, Segmente und Annotationen. OpenOlat wandelt die Datei in mehrere Auflösungen um.

*Englisch: Video* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Video-Editor

Die Arbeitsfläche der Lernressource Video. Hier entstehen Kapitel, Annotationen, Kommentare, Quizfragen und Segmente, alle an einen Zeitpunkt im Video gebunden.

*Englisch: Video editor* · [Handbuch](../manual_user/learningresources/Learning_resource_Video.de.md)

### Wiki (Lernressourcen)

Lernressource für Seiten, die mehrere Personen gemeinsam schreiben und untereinander verlinken. Jede Änderung wird versioniert.

*Englisch: Wiki* · [Handbuch](../manual_user/learningresources/Course_Element_Wiki.de.md)

### Word

Lernressource für ein Word-Dokument. Es lässt sich im Browser bearbeiten, wenn ONLYOFFICE oder Microsoft 365 angebunden ist.

*Englisch: Word* · [Handbuch](../manual_user/learningresources/index.de.md)

## Inhalte und Medien

Womit Inhalte gebaut werden: der Content Editor mit seinen Inhaltselementen und das Media Center, in dem die Medien kursübergreifend liegen.

### Audio (Inhalte und Medien)

Eine Tonaufnahme auf einer Seite, aus dem Media Center oder direkt im Browser aufgenommen.

## Aufgaben und Üben

Alles, wo Lernende etwas abgeben, überarbeiten oder üben, und der Workflow, den Betreuende dafür durchlaufen.

### Abgabe

Der Schritt, in dem die teilnehmende Person ihre Lösung hochlädt oder direkt im Browser schreibt. Nach dem Abgabedatum ist keine Abgabe mehr möglich.

### Abgabeordner (Aufgaben und Üben)

Der Ordner innerhalb eines Aufgabenbausteins, in dem eine teilnehmende Person ihre Arbeit hochlädt. Nur sie und die Betreuenden sehen ihn.

*Englisch: Drop box*

### Aufgabe (Aufgaben und Üben)

Kursbaustein für einen Aufgabenworkflow mit konfigurierbaren Teilschritten: Aufgabe zuweisen, Lösung abgeben, überarbeiten, bewerten und Musterlösung freigeben. Jede teilnehmende Person arbeitet für sich.

*Englisch: Task* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Aufgabenstellung

Der Schritt, in dem die teilnehmende Person ihre Aufgabenstellung erhält. Sie wird zugewiesen oder aus einer Liste selbst gewählt.

*Englisch: Assignment* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Begriff (Aufgaben und Üben)

Ein Begriff, den Teilnehmende einem Segment zuordnen. Die Begriffe bilden das Raster, nach dem im Video beobachtet wird.

*Englisch: Term* · [Handbuch](../manual_user/learningresources/Course_Element_Video_Task.de.md)

### Bewertung (Aufgaben und Üben)

Der Schritt, in dem Betreuende die abgegebene Arbeit bewerten und Punkte, Status oder Note vergeben.

*Englisch: Assessment* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Challenge

Ein Zwischenziel aus mehreren Übungsserien. Nach dem Abschluss einer Challenge sieht die teilnehmende Person ihre Rangliste und ihre Statistik zum Lernstand.

### Gruppenaufgabe

Kursbaustein mit demselben Aufgabenworkflow wie die Aufgabe, aber für Gruppen. Eine Gruppe gibt gemeinsam ab und erhält eine gemeinsame Bewertung.

*Englisch: Group task* · [Handbuch](../manual_user/learningresources/Course_Element_Grouptask.de.md)

### Korrekturanforderung

Die Aufforderung der Betreuenden, eine abgegebene Lösung zu überarbeiten. Sie startet eine weitere Runde der Überarbeitung.

*Englisch: Correction request* · [Handbuch](../manual_user/learningresources/Assessment.de.md)

### Lernstand

Der Stand einer Person je Frage, ausgedrückt als Level. Wer eine Frage dreimal hintereinander richtig beantwortet, erreicht Level 3; eine falsche Antwort senkt das Level wieder. So lässt sich der Fortschritt ohne Punkte ablesen.

*Englisch: Learning status* · [Handbuch](../manual_user/learningresources/Course_Element_Practice.de.md)

### Level

Das Fach der Lernkartei in der Übung. Jede richtige Antwort hebt eine Frage um ein Level, eine falsche senkt sie um eines; die Anzahl Levels legt die Konfiguration fest.

*Englisch: Level* · [Handbuch](../manual_user/learningresources/Course_Element_Practice.de.md)

### Musterlösung (Aufgaben und Üben)

Die Musterlösung zu einer Aufgabe, als Dokument hinterlegt. Sie wird ab einem festgelegten Datum sichtbar, für alle Teilnehmenden oder nur für jene, deren Abgabe akzeptiert wurde.

*Englisch: Sample solution* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

Der Schritt, in dem Teilnehmende die Arbeiten anderer Teilnehmender begutachten und ihnen eine Rückmeldung geben. Wer wessen Arbeit erhält, verteilt OpenOlat.

### Qualitäts-Feedback für Reviewer:in

Einstellung des Peer-Reviews, mit der Teilnehmende ein erhaltenes Review beurteilen: ob es hilfreich war, mit Daumen oder Sternen.

*Englisch: Quality feedback for reviewer* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Review-Objekt

Die Arbeit einer anderen teilnehmenden Person, die im Peer-Review zu begutachten ist.

*Englisch: Review object* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Rückgabeordner (Aufgaben und Üben)

Der Ordner innerhalb eines Aufgabenbausteins, in dem Betreuende die korrigierte Arbeit an die teilnehmende Person zurückgeben.

*Englisch: Return box*

### Rückgabe und Feedback

Der Schritt, in dem die Betreuenden die korrigierte Arbeit und ihre Rückmeldung an die teilnehmende Person zurückgeben.

*Englisch: Return and feedback* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Segment (Aufgaben und Üben)

Ein Abschnitt des Videos, der eine zu beurteilende Situation enthält. Segmente werden im Video-Editor der Lernressource festgelegt.

*Englisch: Segment* · [Handbuch](../manual_user/learningresources/Course_Element_Video_Task.de.md)

### Überarbeitung

Der Schritt, in dem die teilnehmende Person ihre Lösung nach einer Rückmeldung überarbeitet und erneut abgibt. Er lässt sich mehrfach durchlaufen.

*Englisch: Revision* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Übung (Aufgaben und Üben)

Kursbaustein zum Üben nach dem Prinzip der Lernkartei. Teilnehmende beantworten Fragen aus Test-Lernressourcen oder aus Freigaben des Fragenpools in Übungsserien; falsch beantwortete Fragen kommen wieder. Er vergibt keine Punkte, Betreuende sehen den Lernstand als Level.

*Englisch: Practice* · [Handbuch](../manual_user/learningresources/Course_Element_Practice.de.md)

### Übungsserie

Ein Block von Fragen, den eine teilnehmende Person am Stück durcharbeitet, zum Beispiel zehn Fragen. Die Anzahl legt die Konfiguration fest.

*Englisch: Practice series* · [Handbuch](../manual_user/learningresources/Course_Element_Practice.de.md)

### Verspätete Abgabe

Einstellung, die eine Abgabe nach der Frist bis zu einem zweiten Termin zulässt. Solche Abgaben tragen die Kennzeichnung Verspätet, und Betreuende sehen die Verspätung im Bewertungswerkzeug.

*Englisch: Late submission* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Videoaufgabe (Aufgaben und Üben)

Kursbaustein, in dem Teilnehmende Stellen in einem Video markieren und ihnen Begriffe zuordnen. Er dient dem Beobachten und Beurteilen von Situationen, zum Beispiel in der Lehrerbildung oder in der Pflege.

*Englisch: Video task* · [Handbuch](../manual_user/learningresources/Course_Element_Video_Task.de.md)

### Workflow

Die Folge der Schritte, die eine Aufgabe durchläuft. Jeder Schritt lässt sich einzeln zuschalten, sodass von der reinen Abgabe bis zum vollen Ablauf mit Überarbeitung und Peer-Review alles möglich ist.

*Englisch: Workflow* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

### Zuweisung Betreuende/Teilnehmende

Einstellung im Workflow, die jeder teilnehmenden Person eine betreuende Person zuordnet, manuell oder automatisch. Die zugeordnete Person bewertet dann diese Abgaben und wird über neue Abgaben benachrichtigt.

*Englisch: Assignment coaches/participants* · [Handbuch](../manual_user/learningresources/Course_Element_Task.de.md)

## Termine und Absenzen

Präsenzbetrieb: wann etwas stattfindet, wer anwesend war und wie eine Abwesenheit geregelt wird.

### Abmeldung

Die vorgängige Meldung, dass eine Person an einem Termin fehlen wird. Sie erfolgt vor dem Termin, die Absenz wird danach festgestellt.

*Englisch: Notice of absence* · [Handbuch](../manual_user/personal_menu/Absences.de.md)

### Absenz

Das Fehlen einer Person an einem Termin. Sie gilt als entschuldigt oder unentschuldigt, je nachdem ob eine anerkannte Begründung vorliegt.

*Englisch: Absence* · [Handbuch](../manual_user/personal_menu/Absences.de.md)

### Absenzenbegründung

Die von der Administration gepflegte Einordnung einer Absenz, zum Beispiel Krankheit oder Unfall. Sie wird bei der Absenz oder Meldung aus einer Liste gewählt und entscheidet mit, ob die Absenz entschuldigt ist.

*Englisch: Reason of absence* · [Handbuch](../manual_admin/administration/Modules_Events_and_Absences.de.md)

### Absenzenliste

Die druckbare Liste der erfassten Absenzen eines Termins, je Teilnehmende und Einheit. Sie wird nach der Anwesenheitskontrolle aus dem Menü des Termins erzeugt.

*Englisch: Absence list* · [Handbuch](../manual_user/area_modules/Coaching_Events_Absences.de.md)

### Absenzenverwaltung

Der Eintrag in der Hauptnavigation für die kursübergreifende Bearbeitung der Absenzen durch Absenzenverwalter:innen: Cockpit, Termine, Absenzen, Meldungen, Rekurse, Personensuche und Report über alle Kurse.

*Englisch: Absence management* · [Handbuch](../manual_user/area_modules/Absence_Management.de.md)

### Anwesenheit

Die Feststellung, dass eine Person an einem Termin teilgenommen hat. Sie wird je Lektion erfasst und zur Anwesenheitsquote verdichtet.

*Englisch: Attendance* · [Handbuch](../manual_user/learningresources/Events_and_absences.de.md)

### Anwesenheitskontrolle

Die Erfassung der Anwesenheit je Teilnehmende und je Einheit eines Termins durch die Dozierenden. Sie ist je Kurs einschaltbar und liefert die Absenzen, aus denen die Anwesenheitsquote entsteht.

*Englisch: Roll call* · [Handbuch](../manual_user/learningresources/Toolbar_Events.de.md)

### Begründungen Termine

Die von der Administration gepflegte Liste der Gründe, aus denen ein Termin abweichend abgeschlossen wird, zum Beispiel früher beendet. Beim Abschliessen wählen Dozierende einen Grund aus der Liste; ohne Einträge erscheint die Auswahl nicht.

*Englisch: Reasons events* · [Handbuch](../manual_admin/administration/Modules_Events_and_Absences.de.md)

### Dispens

Die vorgängige Befreiung von der Anwesenheitspflicht für einen Zeitraum. Die betroffenen Lektionen zählen nicht gegen die Anwesenheitsquote.

*Englisch: Dispensation* · [Handbuch](../manual_user/personal_menu/Absences.de.md)

### Gebäude

Ein Gebäude, dem Räume zugeordnet sind. Es trägt Kennzeichen, Adresse mit Karte, eine Farbe für Listen und Kalender und die Einschränkung auf bestimmte Organisationen.

*Englisch: Building* · [Handbuch](../manual_admin/administration/Modules_Rooms.de.md)

### Meldung

Der Eintrag, mit dem eine Abwesenheit für einen Zeitraum oder für bestimmte Termine gemeldet wird: als Abmeldung, als Dispens oder als Absenz ohne Abmeldung. Meldungen erfassen Teilnehmende selbst, Dozierende oder Absenzenverwalter:innen.

*Englisch: Notice* · [Handbuch](../manual_user/area_modules/Coaching_Events_Absences.de.md)

Die Erfassung der Anwesenheit für mehrere Termine in einem Arbeitsgang, statt Termin für Termin.

*Englisch: Multi-absence recording*

### Online Meeting

Die Verbindung eines Termins mit einer Onlinesitzung in BigBlueButton, in Microsoft Teams oder über den Sitzungs-Link eines anderen Anbieters. Teilnehmende betreten die Sitzung direkt aus dem Termin.

*Englisch: Online meeting* · [Handbuch](../manual_user/learningresources/Events_and_absences.de.md)

### Präsenzliste

*Englisch: Attendance list* · [Handbuch](../manual_user/area_modules/Coaching_Events_Absences.de.md)

### Raum

Ein physischer Raum in einem Gebäude, mit Kennzeichen, Platzzahl, Zusatzinformationen und Belegung. Termine buchen ihn; ein inaktiver Raum kann nicht mehr gebucht werden.

*Englisch: Room* · [Handbuch](../manual_admin/administration/Modules_Rooms.de.md)

### Raumbuchung

Die Belegung eines Raums durch einen Termin, mit Beginn, Ende und optionaler Pufferzeit davor und danach. Sie entsteht, wenn einem Termin ein Raum zugewiesen wird, und erscheint in der Raumplanung mit ihren Warnungen.

*Englisch: Room management* · [Handbuch](../manual_user/area_modules/Course_Planner_Rooms.de.md)

### Termin (Termine und Absenzen)

Eine planbare Unterrichtseinheit aus 1 bis 12 Lektionen, mit Datum, Raum und Dozierenden. Sie ist die Einheit, für welche die Anwesenheit erfasst wird.

*Englisch: Event* · [Handbuch](../manual_user/learningresources/Toolbar_Events.de.md)

### Termine und Absenzen

Das Modul für den Präsenzbetrieb: Termine mit Dozierenden und Einheiten, die Anwesenheitskontrolle je Termin und die daraus folgenden Absenzen, Meldungen und Rekurse. ## ePortfolio

Wie Lernende ihre Lernprozesse dokumentieren, reflektieren und zur Rückmeldung freigeben: die Mappe mit ihren Bereichen, Einträgen und Aufgaben, die Freigabe, die Einschätzung mit dem Formular und die Bewertung durch Betreuende.

### Änderungsprotokoll

Der Reiter einer Mappe, der alle Änderungen in zeitlicher Reihenfolge auflistet, die neueste zuoberst. Die Administration kann ihn ausschalten.

*Englisch: History* · [Handbuch](../manual_user/area_modules/My_portfolio_binders.de.md)

Die Liste der Mappen und Einträge, die andere Personen an die angemeldete Person freigegeben haben. Betreuende finden hier die Mappen ihrer Lernenden in den Reitern Favoriten, Einträge / To do und Mappen und kommentieren, bewerten oder schliessen sie.

*Englisch: Shared with me* · [Handbuch](../manual_user/area_modules/Shared_with_me.de.md)

### Aufgabe (ePortfolio)

Ein Auftrag in einem Bereich der Mappe, den die Vorlage vorgibt: ein Freitext, ein Dokument oder ein Formular. Die lernende Person wählt die Aufgabe zur Bearbeitung und beantwortet sie mit einem Eintrag.

### Bewertung (ePortfolio)

Das Urteil der Betreuenden über eine Mappe: Punkte und Bestanden je Bereich, eingetragen im Reiter Bewertung der Mappe. Das Ergebnis fliesst in den Kursbaustein Portfolioaufgabe und damit ins Bewertungswerkzeug des Kurses. Einzelne Einträge werden nicht bewertet, nur kommentiert.

*Englisch: Assessment* · [Handbuch](../manual_user/learningresources/Portfolio_assignment_Grading.de.md)

Das ausgefüllte Formular zu einer Aufgabe vom Typ Formular. Die Person schätzt sich selbst ein, und je nach Einstellung geben freigegebene Personen eine Fremdeinschätzung ab, offen oder anonym; die Auswertung stellt mehrere Einschätzungen einander gegenüber.

### Eintrag (ePortfolio)

Eine Seite in einer Mappe, gebaut mit dem Content Editor aus Text, Bildern, Videos, Dokumenten und Formularen. Ein Eintrag beantwortet eine Aufgabe oder steht für sich. Die Person schreibt ihn als Entwurf und publiziert ihn; danach ist er nicht mehr bearbeitbar, nur noch kommentierbar.

*Englisch: Entry* · [Handbuch](../manual_user/portfolio/Three_steps_to_your_portfolio_binder.de.md)

### ePortfolio

Das Modul, mit dem Lernende ihre Lernprozesse dokumentieren und reflektieren. Es stellt jeder Person Mappen, Bereiche und Einträge bereit, und die Kursbausteine Portfolioaufgabe verteilen darüber Mappen aus einer Vorlage. Die Administration schaltet es unter e-Assessment ein oder aus.

*Englisch: ePortfolio* · [Handbuch](../manual_admin/administration/eAssessment_ePortfolio.de.md)

Ein Eintrag, der keiner Mappe zugeordnet ist. Er entsteht unter Meine Einträge, lässt sich später in eine Mappe importieren und ist ohne Freigabe nur für die Person selbst sichtbar.

*Englisch: Floating entry* · [Handbuch](../manual_user/area_modules/My_entries.de.md)

Der Reiter einer Mappe, in dem die besitzende Person Zugangsrechte vergibt. Rückmeldungen unter einem Eintrag. Freigegebene Personen mit Kommentarrecht schreiben sie, sobald der Eintrag publiziert ist; die Administration legt fest, ob Kommentare im Überblick und in den Einträgen sichtbar sind.

*Englisch: Binder* · [Handbuch](../manual_user/portfolio/Three_steps_to_your_portfolio_binder.de.md)

*Englisch: My entries* · [Handbuch](../manual_user/area_modules/My_entries.de.md)

### Meine Portfoliomappen

Die Liste aller eigenen Mappen unter Portfolio 2.0. Hier erstellt die Person neue Mappen: leer, aus einer Vorlage, aus einer Portfolioaufgabe eines Kurses oder aus bestehenden Einträgen. Aus einem Kurs abgeholte Mappen tragen einen roten Randstreifen und den Namen des Kurses.

### Papierkorb (ePortfolio)

*Englisch: Trash*

### Portfolio 2.0

Der Eintrag Portfolio 2.0 im persönlichen Menü. Er führt zu den eigenen Mappen, den eigenen Einträgen, dem Media Center, den Freigaben und dem Papierkorb der Person.

Die Einschätzung, die die besitzende Person zu ihrer eigenen Aufgabe abgibt. Sie ist bei jedem Formular möglich; ob Eingeladene sie sehen, legt die Aufgabe fest, und zwar erst nach deren eigener Fremdeinschätzung.

Die Liste der eigenen Mappen, die die Person an andere freigegeben hat. Sie zeigt, wer auf welche Mappe zugreifen darf, und führt zur Freigabe der Mappe, um Rechte zu ändern.

## Test und Fragenpool

Wie eine Prüfung gebaut, durchgeführt, korrigiert und ausgewertet wird, und woher die Fragen kommen.

### Antwort

Eine Antwortmöglichkeit einer Frage. Sie ist als richtig oder falsch hinterlegt und trägt die Punkte, die ihre Wahl bringt.

*Englisch: Answer* · [Handbuch](../manual_user/learningresources/Configure_test_questions.de.md)

### Betreuer:innen-Chat

Ein Chat während einer Prüfung. Prüflinge stellen darin ihre Fragen, die aufsichtführende Person antwortet.

*Englisch: Supervisor chat* · [Handbuch](../manual_how-to/communication_during_exam/communication_during_exam.de.md)

### Beurteilungsprozess

Der Qualitätsprozess des Fragenpools. Fachkolleginnen und Fachkollegen beurteilen eine neue Frage mit Sternen; sie durchläuft die Status Draft, Review, bei Bedarf Revision und Final, bevor sie in Tests verwendet werden darf.

*Englisch: Review process* · [Handbuch](../manual_user/area_modules/Question_Bank_Review_Process.de.md)

### Datei hochladen (Test und Fragenpool)

Fragetyp, bei dem die Testperson eine oder mehrere Dateien als Antwort hochlädt. Er muss manuell bewertet werden.

*Englisch: Upload file* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Drag and Drop

Fragetyp wie die Matrix, aber mit Ziehen statt Ankreuzen. Die Testperson zieht die Begriffe in die passenden Kategorien.

*Englisch: Drag and Drop* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Feedback

Ein Text, den die Testperson nach der Beantwortung sieht. Er lässt sich getrennt für die richtige Antwort, die falsche Antwort und einzelne Antwortmöglichkeiten hinterlegen.

*Englisch: Feedback* · [Handbuch](../manual_user/learningresources/Configure_test_questions.de.md)

### Frage

Eine einzelne Frage in einem Test, einem Fragebogen oder im Fragenpool. Sie trägt den Fragetext, die Antwortmöglichkeiten, die Punkte und das Feedback.

*Englisch: Question* · [Handbuch](../manual_user/learningresources/Configure_test_questions.de.md)

### Fragebogen (Test und Fragenpool)

Kursbaustein, der eine Test-Lernressource (QTI 2.1) einbindet, die als Fragebogen konfiguriert ist. Er erhebt Meinungen statt Wissen und wertet die Antworten anonym aus.

*Englisch: Questionnaire* · [Handbuch](../manual_user/learningresources/Course_Archiving.de.md)

### Fragenpool (Test und Fragenpool)

Der Bereich, in dem Fragen unabhängig von einem einzelnen Test gesammelt, verschlagwortet, freigegeben und beurteilt werden. Dieselbe Frage lässt sich so in mehreren Tests verwenden.

*Englisch: Question bank* · [Handbuch](../manual_user/area_modules/Question_Bank.de.md)

### Fragetyp

Die Art einer Frage. Der Fragetyp bestimmt, wie die Testperson antwortet, wie die Punkte verrechnet werden und ob OpenOlat automatisch bewerten kann.

*Englisch: Question type* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Freigaben (Test und Fragenpool)

Die Freigabe von Fragen des Fragenpools an eine Gruppe oder einen Pool. Sie entscheidet, wer eine Frage sieht und in eigene Tests übernehmen darf.

*Englisch: Shares* · [Handbuch](../manual_user/area_modules/Question_Bank.de.md)

### Freitext

Fragetyp mit einem freien Textfeld. Die Testperson formuliert die Antwort selbst, deshalb muss die Frage manuell bewertet werden.

*Englisch: Essay* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Hotspot

Fragetyp mit einem Bild, auf dem Bereiche hinterlegt sind. Die Testperson klickt die zutreffenden Bereiche an, wahlweise einen oder mehrere.

*Englisch: Hotspot* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Hottext

Fragetyp, bei dem in einem Fliesstext einzelne Begriffe markierbar sind. Die Testperson wählt die zutreffenden Begriffe im Text aus.

*Englisch: Hottext* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Korrekte Lösung

Die richtige Antwort einer Frage, als Feedback hinterlegt. Die Testperson sieht sie automatisch nach einer falschen Antwort; bei Freitext, Datei hochladen und Zeichnen dient sie den Korrigierenden als Referenz.

*Englisch: Correct solution* · [Handbuch](../manual_user/learningresources/Configure_test_questions.de.md)

### Korrekturwerkzeug

Das Werkzeug, in dem Betreuende oder Korrigierende die manuell zu bewertenden Fragen eines Tests korrigieren: Punkte vergeben und Kommentare hinterlassen, Frage für Frage oder Person für Person.

*Englisch: Correction tool* · [Handbuch](../manual_user/learningresources/Assessing_tests.de.md)

### Kprim

Fragetyp mit genau vier Aussagen. Die Testperson entscheidet für jede Aussage, ob sie zutrifft. Null bis vier Aussagen können richtig sein, und das Punkteschema ist fest vorgegeben.

*Englisch: Kprim* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Liste

Eine persönliche Zusammenstellung von Fragen im Fragenpool, mit der eine Person ihre eigenen Fragen ordnet. Die Liste ändert nichts daran, wer eine Frage sieht.

*Englisch: List* · [Handbuch](../manual_user/area_modules/Question_bank_possible_operations.de.md)

### Lückentext

Fragetyp mit einem Fliesstext, in den Lücken eingebaut sind. Die Testperson tippt den fehlenden Text ein.

*Englisch: Gap FIB text* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Lückentext gemischt

Fragetyp, der Textlücken, numerische Lücken und Dropdown-Lücken in einem Fliesstext verbindet. Er bildet zum Beispiel eine Rechenaufgabe samt Begründung in einer einzigen Frage ab.

*Englisch: Gap mixed* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Lückentext mit Dropdown

Fragetyp, der Lückentext und Single Choice verbindet. Statt zu tippen, wählt die Testperson den Lückeninhalt aus einem Dropdown.

*Englisch: Gap with dropdown* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Lückentext numerisch

Fragetyp wie der Lückentext, aber nur für Zahlen. Zu jeder Lücke lässt sich eine zulässige Toleranz festlegen.

*Englisch: Gap FIB numerical* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Matrix

Fragetyp mit Zeilen und Spalten. Die Testperson kreuzt je Zeile an, welche Spalte zutrifft, wahlweise als Single Choice oder als Multiple Choice.

*Englisch: Match* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Multiple Choice

Fragetyp mit mindestens zwei Antwortmöglichkeiten, von denen mehrere gewählt werden können und mehrere richtig sein können.

*Englisch: Multiple choice* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Pool

Eine Sammelstelle im Fragenpool, in die Fragen freigegeben werden, damit andere sie sehen und in eigene Tests übernehmen. Poolverwaltende legen die Pools an; meist gibt es einen öffentlichen Pool.

*Englisch: Pool* · [Handbuch](../manual_user/area_modules/Question_Bank_Administration.de.md)

### Reihenfolge

Fragetyp, bei dem die Testperson Texte oder Bilder in die richtige Reihenfolge zieht.

*Englisch: Order* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Resultate

Die Auswertung eines Testversuchs, die die Testperson nach der Abgabe oder auf der Test-Startseite sieht. Die Einstellung "Übersicht Resultate" legt fest, wie detailliert: von der Testzusammenfassung bis zu Frage, Antwort und Lösung.

*Englisch: Results* · [Handbuch](../manual_user/learningresources/Course_Element_Test.de.md)

### Sektion

Gliederungsebene innerhalb eines Test-Parts. Die Sektion fasst Fragen zu einem Block zusammen und kann daraus eine Zufallsauswahl ziehen, sodass nicht alle Testpersonen dieselben Fragen erhalten.

*Englisch: Section* · [Handbuch](../manual_user/learningresources/Configure_tests.de.md)

### Selbsttest (Test und Fragenpool)

Kursbaustein, der eine Test-Lernressource zur Selbstkontrolle einbindet. Das Ergebnis geht nicht in die Kursbewertung ein, die Resultate werden anonymisiert gespeichert, und die Anzahl Durchgänge ist unbegrenzt.

*Englisch: Self-test* · [Handbuch](../manual_user/learningresources/Course_Element_Self_Test.de.md)

### Single Choice

Fragetyp mit mehreren Antwortmöglichkeiten, von denen genau eine gewählt werden kann und genau eine richtig ist.

*Englisch: Single choice* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Test (Test und Fragenpool)

Kursbaustein, der eine Test-Lernressource in den Kurs einbindet. Das Ergebnis zählt zur Kursbewertung.

*Englisch: Test* · [Handbuch](../manual_user/learningresources/Course_Element_Test.de.md)

### Test-Part

Oberste Gliederungsebene eines Tests. Ein Test-Part fasst Sektionen zusammen und legt für sie gemeinsam fest, ob die Testperson zurückblättern und Antworten ändern darf.

*Englisch: Test part* · [Handbuch](../manual_user/learningresources/Configure_tests.de.md)

### Testquittung

Eine digital signierte Bestätigung über einen abgeschlossenen Testversuch. Sie belegt später, was zu welchem Zeitpunkt abgegeben wurde.

*Englisch: Test receipt* · [Handbuch](../manual_how-to/achievements/achievements.de.md)

### Test Statistiken

Die Auswertung eines durchgeführten Tests: Kennzahlen je Frage, Trennschärfe, Schwierigkeit und die Verteilung der Ergebnisse.

*Englisch: Test Statistics* · [Handbuch](../manual_user/learningresources/Statistics_Test.de.md)

### Testversuch

Ein Durchlauf einer Person durch einen Test, von der ersten Frage bis zur Abgabe. Er hält die Antworten, die Dauer und die Punkte fest.

*Englisch: Test run* · [Handbuch](../manual_user/learningresources/Assessing_tests.de.md)

### True/false

Fragetyp wie Kprim, aber mit beliebig vielen Zeilen. Je Aussage wählt die Testperson zwischen Unbeantwortet, Richtig und Falsch.

*Englisch: True/false* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Zeichnen

Fragetyp, bei dem die Testperson ein vorgegebenes Hintergrundbild mit Zeichenwerkzeugen bearbeitet. Er muss manuell bewertet werden.

*Englisch: Drawing* · [Handbuch](../manual_user/learningresources/Test_question_types.de.md)

### Zusätzliche Seite

Ein zusätzliches Blatt im Ausdruck eines Tests, das der Testperson Platz für Nebenrechnungen und Notizen gibt.

*Englisch: Additional sheet* · [Handbuch](../manual_user/learningresources/Test_settings.de.md)

## Bewertung

Alles, was eine Leistung erfasst, bewertet, in eine Note umrechnet und freigibt.

### Änderungsverlauf

Die Aufzeichnung aller Änderungen an einer Bewertung, mit Person und Zeitpunkt. Sie ist die Grundlage, wenn eine Bewertung später bestritten wird.

*Englisch: Change log*

### Bewertung (Bewertung)

Das Urteil über die Leistung einer Person in einem bewertbaren Kursbaustein, ausgedrückt als Status, Punkte oder Note. Es beurteilt Personen; das Qualitätsmanagement beurteilt dagegen Angebote.

*Englisch: Assessment* · [Handbuch](../manual_user/learningresources/Course_Element_Assessment.de.md)

### Bewertungsdokumente

Dateien, welche Betreuende zu einer Bewertung ablegen, zum Beispiel ein korrigiertes Prüfungsblatt oder ein Beurteilungsraster.

*Englisch: Assessment documents* · [Handbuch](../manual_user/learningresources/The_assessment_form.de.md)

### Bewertungsskala

Die Zuordnung von Punktebereichen zu Notenwerten. Sie übersetzt eine Punktzahl in eine Note.

*Englisch: Grading scale* · [Handbuch](../manual_user/learningresources/Assessment_translate_points_in_grades.de.md)

### Bewertungssystem

Ein benanntes System von Notenwerten, zum Beispiel die schweizerische Notenskala von 1 bis 6. Es legt fest, welche Werte es gibt und welche als bestanden gelten.

*Englisch: Grading system* · [Handbuch](../manual_admin/administration/Assessment_translate_points_in_grades_admin.de.md)

### Bewertungswerkzeug

Der Bereich eines Kurses, in dem Betreuende und Besitzende alle Resultate der Teilnehmenden sehen, bewerten, freigeben und zurücksetzen.

*Englisch: Assessment tool* · [Handbuch](../manual_user/learningresources/Assessment_tool_overview.de.md)

### Einstufung/Noten

Das Modul, in dem die Bewertungssysteme und ihre Skalen gepflegt werden. Es legt fest, welche Noten es gibt und ab welcher Punktzahl eine Note erreicht ist.

*Englisch: Levels/Grading* · [Handbuch](../manual_user/learningresources/Assessment_translate_points_in_grades.de.md)

### Korrektur

Das Durchsehen und Benoten einer abgegebenen Arbeit durch eine Person. Sie ist nötig, wo OpenOlat nicht automatisch bewerten kann, etwa bei Freitextfragen.

*Englisch: Correction* · [Handbuch](../manual_user/learningresources/Test_settings.de.md)

### Korrekturauftrag

Der Auftrag an eine korrigierende Person, eine bestimmte Testabgabe von Hand zu benoten, mit Frist und erfasster Korrekturzeit. Er dient dort, wo die Korrektur ausserhalb des Kursteams vergeben und abgerechnet wird.

*Englisch: Grading assignment* · [Handbuch](../manual_user/area_modules/Coaching_Order_Management.de.md)

### Leistungsübersicht

Der Block mit Status, Punkten, Note und Kommentar einer Bewertung. Teilnehmende sehen ihn im Kursbaustein, Betreuende im Bewertungsformular und dort zusätzlich als Vorschau der Ansicht der Teilnehmenden.

*Englisch: Performance summary* · [Handbuch](../manual_user/learningresources/Course_Element_Structure.de.md)

### Massenbewertung

Die Bewertung vieler Teilnehmender in einem Arbeitsgang, über eine hochgeladene Tabelle oder eine Eingabemaske. Sie erspart das Öffnen jeder einzelnen Person.

*Englisch: Bulk assessment* · [Handbuch](../manual_how-to/bulk_assessment/bulk_assessment.de.md)

### Nachteilsausgleich

Eine Anpassung der Prüfungsbedingungen für eine Person mit einer Behinderung oder Beeinträchtigung, in der Regel als Zusatzzeit. Sie gilt für diese Person und lässt die Aufgabe unverändert.

*Englisch: Disadvantage compensation* · [Handbuch](../manual_admin/usermanagement/Configure_User.de.md)

### Note

Der Wert, mit dem eine Leistung nach einem Bewertungssystem benannt wird, zum Beispiel die Note 5 oder das Prädikat gut. Sie entsteht aus den Punkten über die Bewertungsskala.

*Englisch: Grade* · [Handbuch](../manual_user/learningresources/Assessment_translate_points_in_grades.de.md)

### Prüfungseinsicht

Der beaufsichtigte Einblick in die eigene korrigierte Prüfung. Die geprüfte Person sieht ihre Antworten und die Bewertung in einem festgelegten Zeitfenster, ohne etwas ändern zu können.

*Englisch: Assessment inspection* · [Handbuch](../manual_user/learningresources/Assessment_inspection.de.md)

### Prüfungskurs

Ein Kurs, der nur für die Durchführung einer Prüfung angelegt wird. Der Assistent erstellt ihn mit Prüfungsmodus und Test in einem Schritt.

*Englisch: Exam course* · [Handbuch](../manual_how-to/test_creation_procedure/test_creation_procedure.de.md)

### Prüfungsmodus

Ein Zeitfenster, in dem ein Kurs zur Prüfung wird. Während des Prüfungsmodus sind alle anderen Bereiche von OpenOlat gesperrt, der Zugang lässt sich auf bestimmte Rechner begrenzen und der Safe Exam Browser lässt sich verlangen.

*Englisch: Assessment mode* · [Handbuch](../manual_user/learningresources/Assessment_mode.de.md)

### Prüfungsverwaltung

Die Verwaltung von Prüfungsmodus und Prüfungseinsicht. Im Kurs ist sie das Werkzeug der Kursadministration mit den beiden Tabs Prüfungsmodus und Prüfungseinsicht. In der Administration unter e-Assessment listet sie die Prüfungsmodi aller Kurse und hält die Einstellungen.

*Englisch: Assessment management* · [Handbuch](../manual_user/learningresources/Assessment_Management.de.md)

### Rubrik-Bewertung

Die kriterienbasierte Bewertung eines Bausteins mit Hilfe einer Rubrik. Sie wird am Bewertungsbaustein eingeschaltet und benutzt dafür ein Rubrik-Formular.

*Englisch: Rubric assessment* · [Handbuch](../manual_user/learningresources/Course_Element_Assessment.de.md)

### Rubrik-Formular

Ein Formular mit einer Rubrik, das Betreuende beim Bewerten ausfüllen. Es macht die Kriterien sichtbar und die Bewertung zwischen mehreren Betreuenden vergleichbar.

*Englisch: Rubric form* · [Handbuch](../manual_user/learningresources/Forms_in_Rubric_Scoring.de.md)

### Safe Exam Browser

Anbindung des Safe Exam Browser. Der Prüfungsmodus verlangt diesen Browser und sperrt damit während der Prüfung alle anderen Programme des Geräts.

## Nachweise

Was am Ende herauskommt und belegbar ist: der Leistungsnachweis aus dem Kurs, das Zertifikat als Dokument, das Zertifikatsprogramm als laufende Mitgliedschaft und der Badge als offener Nachweis.

### Badge

Eine digitale Auszeichnung nach dem Standard Open Badges, mit Bild, Kriterien und ausstellender Stelle. Anders als das Zertifikat lässt sie sich ausserhalb von OpenOlat vorweisen und maschinell prüfen.

*Englisch: Badge* · [Handbuch](../manual_user/personal_menu/OpenBadges.de.md)

### Badge-Klasse

Die Art eines Badges, mit Bild, Beschreibung, Herausgeber und Vergabekriterien. Die einzelne Auszeichnung ist eine Ausgabe dieser Klasse an eine Person. Eine Badge-Klasse kann in mehreren Versionen vorliegen; Empfangende behalten die vergebene Version.

*Englisch: Badge class* · [Handbuch](../manual_user/learningresources/OpenBadges.de.md)

### Leistungsnachweis

Die Zusammenstellung aller Resultate einer Person in einem Kurs, je bewertbarem Baustein, mit Punkten, Status und Datum.

*Englisch: Evidence of achievement* · [Handbuch](../manual_user/personal_menu/Evidence_of_Achievements.de.md)

### Mitgliedschaft (Nachweise)

Die Zugehörigkeit einer Person zu einem Zertifikatsprogramm. Kandidat:innen nehmen an einer verknüpften Durchführung teil und haben noch kein Zertifikat; aktive Mitglieder besitzen eines; Alumni sind aus dem Programm ausgeschieden.

*Englisch: Membership* · [Handbuch](../manual_user/area_modules/Course_Planner_Certification_Programs.de.md)

### OpenBadges

Standard Open Badges. Er beschreibt eine digitale Auszeichnung so, dass sie prüfbar ist und sich ausserhalb der ausstellenden Plattform vorweisen lässt.

*Englisch: OpenBadges* · [Handbuch](../manual_user/personal_menu/OpenBadges.de.md)

### Rezertifizierung

Die erneute Ausstellung eines Zertifikats, bevor oder nachdem es abläuft. Im einzelnen Kurs absolvieren Teilnehmende den Kurs dafür erneut. Im Zertifikatsprogramm läuft sie automatisch oder von Hand, wahlweise gegen Kreditpunkte.

*Englisch: Recertification* · [Handbuch](../manual_user/learningresources/Course_Settings_Assessment_Certificate.de.md)

### Vergabekriterien

Die Bedingungen, unter denen ein Badge vergeben wird, zum Beispiel ein bestandener Kurs oder eine erreichte Punktzahl.

*Englisch: Award criteria* · [Handbuch](../manual_user/learningresources/OpenBadges.de.md)

### Vergebener Badge

Der einzelne Badge, den eine Person aus einer Badge-Klasse erhalten hat, mit Empfangenden, Datum der Vergabe und Bild. Die Metadaten stecken im Bild selbst; so lässt sich der Badge herunterladen, auf LinkedIn teilen und prüfen.

*Englisch: Awarded badge* · [Handbuch](../manual_user/personal_menu/OpenBadges.de.md)

### Verifizierung

Die Prüfung, ob ein Badge echt ist und von dieser Instanz stammt. Jede Badge-Klasse legt bei der Erstellung die Methode fest: Hosted holt die Daten von der OpenOlat-Adresse, Signed prüft eine digitale Signatur. Die Administration lädt dazu eine Badge-Datei hoch.

*Englisch: Verification* · [Handbuch](../manual_admin/administration/e-Assessment_openBadges.de.md)

### Vorlage (Nachweise)

Ein Bild in SVG oder PNG, aus dem der Wizard eine Badge-Klasse erstellt. Die Vorlage kann Farben und Text zum Anpassen enthalten und gehört zu einer Kategorie. Die Administration pflegt die Vorlagen unter e-Assessment; ein Standardset ist mitgeliefert.

*Englisch: Template* · [Handbuch](../manual_admin/administration/e-Assessment_openBadges.de.md)

### Zertifikat

Ein PDF, das die erfolgreiche Teilnahme an einem Kurs oder den Abschluss eines Zertifikatsprogramms bescheinigt, mit Name, Datum und Seriennummer. Der Leistungsnachweis zeigt, was jemand geleistet hat; das Zertifikat bescheinigt es nach aussen. Extern erworbene Zertifikate lassen sich hochladen, wenn die Administration das erlaubt.

*Englisch: Certificate* · [Handbuch](../manual_user/personal_menu/Certificates.de.md)

### Zertifikatsprogramm

Ein Programm, das mehrere Kurse zu einer Zertifizierung verbindet und deren Gültigkeit überwacht. Es fordert nach Ablauf der Gültigkeit eine Rezertifizierung.

*Englisch: Certification program* · [Handbuch](../manual_user/area_modules/Course_Planner_Certification_Programs.de.md)

### Zertifikatsvorlage

Die Vorlage, aus der OpenOlat ein Zertifikat als PDF erzeugt. Sie ist ein PDF-Formular oder eine HTML-Vorlage als ZIP mit index.html; die HTML-Vorlage braucht den PDF-Dienst. Die Administration stellt systemweite Vorlagen bereit, Kursbesitzende laden eigene hoch.

*Englisch: Certificate template* · [Handbuch](../manual_user/learningresources/Course_Settings_Assessment_Certificate.de.md)

## Qualitätsmanagement und Formulare

Wie Feedback erhoben, ausgewertet und in Massnahmen überführt wird, und die Formularbausteine, auf denen das aufsetzt.

### Analyse

Der Bereich, in dem die Antworten mehrerer Datenerhebungen gemeinsam ausgewertet werden, mit Filtern, Gruppierungen, Heatmap und Trend.

*Englisch: Analysis* · [Handbuch](../manual_user/area_modules/Quality_Management_Analysis.de.md)

### Angaben zum:r Betreuer:in

Ein Block im Formular, der Angaben zur beurteilten Betreuungsperson einer Datenerhebung anzeigt. Er ist für Formulare des Qualitätsmanagements gedacht.

*Englisch: Coach details*

### Angaben zur befragten Person

Ein Block im Formular, der Angaben zur befragten Person abfragt oder vorbelegt, etwa Name oder E-Mail, freiwillig, obligatorisch oder automatisch eingetragen. Er steht nur einmal je Formular und hebt die Anonymität auf.

*Englisch: Respondent details* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Datei hochladen (Qualitätsmanagement und Formulare)

Ein Feld im Formular, über das die befragte Person eine Datei abgibt. Die Autorin legt die erlaubten Dateitypen und die maximale Grösse fest.

*Englisch: Upload file* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Datenerhebung

Eine einzelne Erhebung mit einem Formular, einem Beurteilungsgegenstand, einem Zeitraum und einem Kreis von Befragten. Sie ist die Arbeitseinheit des Qualitätsmanagements.

*Englisch: Data collection* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collections.de.md)

### Datenerhebungsgenerator

Eine Regel, die Datenerhebungen selbständig anlegt, sobald ein Ereignis eintritt, zum Beispiel das Ende eines Kurses. Sie erspart das wiederholte Anlegen gleichartiger Erhebungen.

*Englisch: Data collection generator* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collection_Generators.de.md)

### Datenerhebungsvorschau

Die Übersicht der anstehenden Datenerhebungen, die Generatoren anlegen werden. Sie steht im Qualitätsmanagement, in der Kursadministration und im Course Planner und muss in der Administration eingeschaltet werden.

*Englisch: Data collection previews* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collection_Preview.de.md)

### Datum / Zeit

Ein Eingabefeld im Formular für ein Datum, wahlweise mit Uhrzeit.

*Englisch: Date / Time* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Einzelauswahl

Eine Frage im Formular mit mehreren Antworten, von denen genau eine gewählt werden kann.

*Englisch: Single choice* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Erinnerung (Qualitätsmanagement und Formulare)

Eine E-Mail einer Datenerhebung an die Befragten: die Einladung mit dem Link zum Formular und bis zu zwei Erinnerungen an Personen, die noch nicht geantwortet haben. Das Versanddatum wird je Datenerhebung festgelegt.

*Englisch: Reminder* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collections.de.md)

### Erstbefragung

Eine frühere Erhebung zum selben Gegenstand, die als Vergleichswert dient. Ohne sie lässt sich keine Entwicklung über die Zeit zeigen.

*Englisch: Previous survey*

### Formular (Qualitätsmanagement und Formulare)

Die generische Lernressource für erfasste Angaben, gebaut im Content Editor. Sie wird an sechs Stellen mit unterschiedlicher Bedeutung eingesetzt: als Beurteilungsraster im E-Portfolio, im Kursbaustein Bewertung und im Kursbaustein Aufgabe samt Peer-Review; als Qualitätsraster im Qualitätsmanagement und im Kursbaustein Umfrage; als Formular im Kursbaustein Formular. Die Bedeutung kommt von der einbindenden Stelle, nicht vom Formular.

*Englisch: Form* · [Handbuch](../manual_user/learningresources/Form.de.md)

### Heatmap

Die Ansicht der Analyse, die die Durchschnittswerte je Gruppierung und Frage als farbige Punkte zeigt. Die Farbe folgt den Gütebereichen der Rubrik, die Grösse der Anzahl Antworten. Sie macht problematische Stellen auf einen Blick sichtbar.

*Englisch: Heat map* · [Handbuch](../manual_user/area_modules/Quality_Management_Analysis.de.md)

### Kennzahlen

Die statistischen Werte, mit denen die Analyse die Antworten zusammenfasst.

*Englisch: Key figures* · [Handbuch](../manual_user/area_modules/Quality_Management_Analysis.de.md)

### Massnahmen To-dos

Die Massnahmen, die aus den Ergebnissen einer Datenerhebung folgen, geführt als To-dos mit verantwortlicher Person und Frist. Sie schliessen den Kreis von der Messung zur Verbesserung.

*Englisch: Action to-dos* · [Handbuch](../manual_user/area_modules/Quality_Management_To-dos.de.md)

### Mehrfachauswahl

Eine Frage im Formular mit mehreren Antworten, von denen mehrere gewählt werden können.

*Englisch: Multiple choice* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Negativliste

Die Liste der Kurse oder Durchführungen, die ein Generator übergehen soll. Sie nimmt einzelne Fälle von einer sonst allgemeinen Regel aus.

*Englisch: Black list* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collection_Generators.de.md)

### Nutzungsbedingungen (Qualitätsmanagement und Formulare)

Ein Text im Formular, dem die befragte Person zustimmen muss, bevor sie das Formular abgeben kann.

*Englisch: Terms of use* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Öffentlicher Zugang

Ein Zugang zu einer Datenerhebung ohne Anmeldung. Er erlaubt es, auch Personen ohne Konto zu befragen, zum Beispiel Praktikumsbetriebe.

*Englisch: Public link* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collections.de.md)

### Positivliste

Die Liste der Kurse oder Durchführungen, auf die ein Generator seine Regel einschränkt: Datenerhebungen entstehen nur für Fälle, die die Regel erfasst und die auf der Liste stehen. Sie ist das Gegenstück zur Negativliste.

*Englisch: White list* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collection_Generators.de.md)

### Qualitätsmanagement

Modul für die Beurteilung der eigenen Angebote und Abläufe. Es plant Datenerhebungen, führt sie durch, wertet die Antworten aus und verfolgt die daraus abgeleiteten Massnahmen. Es steht am Ende des Bildungszyklus und beurteilt das Angebot, nicht die Lernenden.

*Englisch: Quality management* · [Handbuch](../manual_admin/administration/Modules_Quality_Management.de.md)

### Report

Die Auswertung einer einzelnen Datenerhebung: die Antworten und Kennzahlen des Formulars. Der Tab erscheint, sobald ein Report vorliegt. Wer ihn sehen darf, legt der Tab Berechtigungen Report nach Rolle fest, wahlweise mit E-Mail nach Abschluss.

*Englisch: Report* · [Handbuch](../manual_user/area_modules/Quality_Management_Data_Collections.de.md)

### Rubrik (Qualitätsmanagement und Formulare)

Ein Block im Formular, der mehrere Aussagen auf derselben Skala beurteilen lässt. Er liefert die Zahlen, mit denen die Analyse rechnet.

*Englisch: Rubric* · [Handbuch](../manual_user/learningresources/Form_Element_Rubric.de.md)

### Teilnahme Datenerhebung

Die Teilnahme einer einzelnen Person an einer Datenerhebung. Sie hält fest, ob jemand geantwortet hat, nicht was geantwortet wurde.

*Englisch: Data collection participation*

### Textblock

Ein Eingabefeld im Formular für eine frei formulierte Antwort, ein- oder mehrzeilig, wahlweise auf eine Zahl oder ein Datum beschränkt.

*Englisch: Text block* · [Handbuch](../manual_user/learningresources/Form_Elements.de.md)

### Trend Detail

Die Entwicklung eines Wertes über mehrere Erhebungen hinweg. Sie zeigt, ob eine Massnahme gewirkt hat.

*Englisch: Trend details* · [Handbuch](../manual_user/area_modules/Quality_Management_Analysis.de.md)

### Verbesserungsvorschlag

Ein Verbesserungsvorschlag, den eine Person zu einem Kurs oder einem Angebot einreicht. Anders als eine Datenerhebung geht er von der einreichenden Person aus und nicht von einer Befragung.

*Englisch: Suggestion for improvement* · [Handbuch](../manual_user/area_modules/Quality_Management_Improvement.de.md)

## Selectus

Das Modul für Berufungsverfahren: Ausschreibung einer Professur, Bewerbung, Kommission, externe Gutachten, Referenzschreiben und der A/B/C-Entscheid.

### Abschlusszertifikate

Die Urkunden zu den erreichten akademischen Abschlüssen.

*Englisch: Degree certificates*

### Anschreiben

Das Begleitschreiben einer Bewerbung, in dem die bewerbende Person ihr Interesse an der Professur begründet.

*Englisch: Covering letter*

### Assistenzprofessur

Der Professurtyp für eine befristete Professur am Anfang der akademischen Laufbahn, häufig mit einer Option auf Entfristung.

*Englisch: Assistant professor*

### Ausschreibung

Eine ausgeschriebene Professur in Selectus. Sie enthält den Ausschreibungstext, das Bewerbungsformular, die Fristen und die Berufungskommission.

*Englisch: Position*

### Auswertung

Die Site, auf der Referenzpersonen und Gutachtende ihre Schreiben einreichen und auf der öffentliche Rückmeldungen abgegeben werden. Sie öffnet sich über einen persönlichen Link ohne OpenOlat-Konto.

*Englisch: Evaluation*

### Beurteilung (Selectus)

Die Einschätzung einer Bewerbung mit A, B oder C durch ein einzelnes Kommissionsmitglied.

*Englisch: Rating*

### Beurteilungsrichtlinien

Die Regeln einer Ausschreibung dafür, wer welche Beurteilungen und Reviews sehen darf und ab wann. Sie verhindern, dass sich Kommissionsmitglieder gegenseitig beeinflussen.

*Englisch: Rating policy*

### Bewerben

Die Site für Bewerbende. Sie zeigt die publizierten Ausschreibungen und führt durch das Bewerbungsformular. Bewerbende erreichen sie ohne OpenOlat-Konto über den Link einer Ausschreibung oder über die Login-Seite.

*Englisch: Apply*

### Bewerbung

Die Einreichung einer Bewerberin oder eines Bewerbers auf eine Ausschreibung, bestehend aus Personendaten, akademischem Hintergrund und den hochgeladenen Dokumenten.

*Englisch: Application*

### Bewerbungsformular

Das mehrstufige Formular, mit dem sich eine Person auf eine Ausschreibung bewirbt: Personendaten, akademischer Hintergrund, Projekt, bis zu vier eigene Schritte der Ausschreibung, Dokumente und Anhänge, Datenschutz. Die Sachbearbeitung konfiguriert die Schritte und Felder je Ausschreibung.

*Englisch: Application form*

### Chirurgische Expertise

Der Nachweis der operativen Erfahrung einer bewerbenden Person, mit Art und Anzahl der Eingriffe. Er wird bei chirurgischen Professuren verlangt.

*Englisch: Surgical expertise*

### Dashboard (Selectus)

Die Startseite der Bewerbenden nach der Anmeldung. Sie listet die eigenen Bewerbungen mit Status und Frist und führt zur Referenzverwaltung.

*Englisch: Dashboard*

### Dokumente und Anhänge

Der Schritt des Bewerbungsformulars mit allen Dokumenten, die eine Bewerbung mitbringt. Welche Dokumente zur Verfügung stehen und welche Pflicht sind, legt die Ausschreibung fest.

*Englisch: Documents and attachments*

### Drittmittel

Der Nachweis der eingeworbenen Forschungsmittel von fremden Geldgebern, mit Betrag und Geldgeber.

*Englisch: External funding*

### E-Mail-Protokoll

Die Tabelle im Mailcenter mit allen bereits gesendeten E-Mails einer Ausschreibung, mit Empfangenden, Vorlage und Zeitpunkt.

*Englisch: Email log*

### E-Mail-Vorlage

Eine Vorlage für die Korrespondenz einer Ausschreibung, zum Beispiel die Anfrage an eine Referenzperson oder das Ablehnungsschreiben. Sie enthält Platzhalter, die beim Versand gefüllt werden.

*Englisch: Mail template*

### Enthaltung

Der ausdrückliche Verzicht eines Kommissionsmitglieds auf die Beurteilung einer Bewerbung.

*Englisch: Abstention*

### Entscheid (Selectus)

Das Ergebnis der Kommission zu einer Bewerbung mit A, B oder C. A bezeichnet die stärksten Kandidaturen, C ist die Grundlage für eine Ablehnung.

*Englisch: Decision*

### Entscheidungswerkzeug

Ein Raster aus gewichteten Rubriken, mit dem Präsidium und Sachbearbeitung nach dem Screening eine weitere Beurteilung erfassen, zum Beispiel zum Vortrag. Die Summe der Rubriken stützt den Entscheid. Kommissionsmitglieder haben keinen Zugriff.

*Englisch: Decision tool*

### Fakultätsfeedback

Rückmeldungen zu einer Bewerbung, die bei Fakultätsmitgliedern eingeholt werden, die nicht der Berufungskommission angehören.

*Englisch: Faculty feedback*

### Forschungsziel

Das Dokument, in dem eine bewerbende Person ihr Forschungsvorhaben für die ausgeschriebene Professur darlegt.

*Englisch: Research statement*

### Führungsphilosophie

Das Dokument, in dem eine bewerbende Person darlegt, wie sie eine Arbeitsgruppe oder ein Institut führen will.

*Englisch: Leadership philosophy*

### Gutachten

Eine schriftliche Beurteilung einer Bewerbung durch eine von der Kommission bestimmte externe Fachperson.

*Englisch: Expert assessment*

### Klinische Expertise

Der Nachweis der klinischen Erfahrung einer bewerbenden Person. Er wird bei medizinischen Professuren verlangt.

*Englisch: Clinical expertise*

### Kombiniertes Dokument

Alle Dokumente einer Bewerbung zu einem einzigen PDF zusammengefügt, zum Lesen und Ausdrucken.

*Englisch: Combined document*

### Kommission

Das Gremium einer Ausschreibung, das die Bewerbungen beurteilt und über sie entscheidet. Es besteht aus dem Präsidium, dem Sekretariat, den Kommissionsmitgliedern und den Ex-Officio-Mitgliedern; jede Ausschreibung hat ihre eigene Kommission.

*Englisch: Committee*

### Kommissionsbeurteilung

Die zusammengefasste Beurteilung einer Bewerbung durch die gesamte Kommission, im Unterschied zur Beurteilung eines einzelnen Mitglieds.

*Englisch: Committee rating*

### Kommissionsentscheid

Der förmliche Beschluss der Kommission zu einer Bewerbung. Er schliesst die Beurteilung ab und ist die Grundlage für die Korrespondenz.

*Englisch: Committee decision*

### Kommissionszuweisung

Die Zuteilung von Bewerbungen an einzelne Kommissionsmitglieder. Sie legt fest, wer welche Bewerbung beurteilen muss.

*Englisch: Committee assignment*

### Lebenslauf

Der Lebenslauf einer bewerbenden Person mit Ausbildung, Stellen und wissenschaftlicher Laufbahn.

*Englisch: Curriculum vitae*

### Lehransatz

Das Dokument, in dem eine bewerbende Person ihr Verständnis von Lehre und ihre geplante Lehrtätigkeit darlegt.

*Englisch: Teaching statement*

### Lehrbeurteilung

Ein Nachweis über die Qualität der bisherigen Lehre, zum Beispiel Ergebnisse von Lehrevaluationen.

*Englisch: Teaching assessment*

### Link für öffentliche Rückmeldungen

Der Link, den die Sachbearbeitung je Bewerbung erzeugt und verteilt. Wer ihn öffnet, gibt ohne Anmeldung eine öffentliche Rückmeldung bis zur Einreichefrist ab.

*Englisch: Public feedback link*

### Mailcenter

Der Bereich für die Serienkorrespondenz mit Bewerbenden, mit einer Vorlage je Entscheidgruppe.

*Englisch: Mail center*

### Öffentliche Rückmeldung

Rückmeldungen, die über einen öffentlichen Link ohne Login abgegeben werden, zum Beispiel nach einem Probevortrag.

*Englisch: Public feedback*

### Ordentliche Professur

Der Professurtyp für eine unbefristete Professur mit vollem Umfang an Forschung, Lehre und Selbstverwaltung. Er ist die höchste Stufe der Professurtypen.

*Englisch: Full professor*

### Organisationseinheit

Die Fakultät oder das Institut, dem eine Ausschreibung gehört und die eine eigene Absenderadresse und E-Mail-Signatur bereitstellt.

*Englisch: Organisation unit*

### Profildokument

Das Dokument, das das Profil der ausgeschriebenen Professur beschreibt und der Berufungskommission zur Verfügung steht.

*Englisch: Profile paper*

### Referenzenliste

Die Liste der Referenzpersonen, die eine bewerbende Person angegeben hat, mit dem Stand der jeweiligen Anfrage.

*Englisch: List of referees*

### Referenzschreiben

Ein Empfehlungsschreiben, das eine von der Bewerberin oder dem Bewerber angegebene Referenzperson verfasst.

*Englisch: Letter of recommendation*

### Referenzverwaltung

Der Bereich, in dem Bewerbende ihre Referenzpersonen selbst erfassen und verfolgen, ob die Anfragen beantwortet wurden.

*Englisch: Referee management*

### Reporting

Der Bereich in Selectus für die statistische Auswertung abgeschlossener Ausschreibungen. Eine Ausschreibung im Status Reporting ist nur noch hier zugänglich; die Sachbearbeitung ergänzt die Angaben für die Statistik und erzeugt den Excel-Report des Verfahrens.

*Englisch: Reporting*

### Review

Eine strukturierte Beurteilung einer Bewerbung durch ein Kommissionsmitglied mit einem Fragebogen aus Schiebereglern und Freitext.

*Englisch: Review*

### Review-Diskussion

Kommentare und Antworten, die Kommissionsmitglieder zu einem Review erfassen können.

*Englisch: Review discussion*

### Review-Fragebogen

Die konfigurierbare Zusammenstellung von Schiebereglern und Textfeldern, die Kommissionsmitglieder pro Bewerbung ausfüllen.

*Englisch: Review questionnaire*

### Review-Werkzeug

Der Bereich, in dem Kommissionsmitglieder ihre Reviews zu den zugewiesenen Bewerbungen erfassen und die Reviews der anderen lesen, soweit die Sichtbarkeit es erlaubt.

*Englisch: Review tool*

### Rollenrechte der Kommission

Die Einstellung, welche Kommissionsrolle in einer Ausschreibung was darf: bewerten, Notizen führen, Reviews sehen, Kommentare lesen. Pro Recht wählt die Selectusverwaltung die zugelassenen Rollen aus Mitglied, Präsidium, Sekretariat und Ex-Officio.

*Englisch: Committee role permissions*

### Rubrik (Selectus)

Ein gewichtetes Kriterium im Entscheidungswerkzeug mit Name, Typ und Gewichtung. Die Summe aller Rubriken ergibt den Wert einer Bewerbung.

*Englisch: Rubric*

### Screening

Die Phase, in der die Berufungskommission die eingegangenen Bewerbungen liest und beurteilt.

*Englisch: Screening*

### Selectus

Modul für Berufungsverfahren: Ausschreibung von Professuren, Erfassung der Online-Bewerbungen und Begleitung der Berufungskommission bis zum Entscheid.

*Englisch: Selectus*

### Serienbrief

Ein PDF-Brief, der aus einer Vorlage erzeugt und zusammen mit einer E-Mail versendet wird, zum Beispiel ein Ablehnungsschreiben.

*Englisch: Form letter*

### Sonderdrucke von bis zu 5 Publikationen

Bis zu fünf Publikationen im Volltext, welche die bewerbende Person selbst als ihre wichtigsten auswählt.

*Englisch: Reprints up to 5 publications*

### Studienbescheinigung

Eine Bescheinigung über ein absolviertes Studium.

*Englisch: Certificate of Study*

### Vergleichsgutachten

Ein Gutachten, in dem mehrere Bewerbungen derselben Ausschreibung miteinander verglichen werden.

*Englisch: Comparative assessment*

### Weitere Bewerbungen

Die Liste der anderen Ausschreibungen, auf die sich dieselbe Person beworben hat. Ob Mehrfachbewerbungen erlaubt sind, legt die Konfiguration fest.

*Englisch: Other applications*

## Künstliche Intelligenz

Das KI Modul und die Funktionen darauf.

### Anthropic Claude

Der KI Anbieter Anthropic Claude, angebunden über einen API Schlüssel. Die Nutzung verursacht Kosten im Konto der Betreiberin.

*Englisch: Anthropic Claude* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Bewertungs-Kit (Referenz + Musterantwort)

Die Vorgabe, an der die Essay Bewertung eine Antwort misst: Lernziel, Quelltext-Auszug, Musterantwort, Schlüsselpunkte, Bewertungskriterien und häufige Missverständnisse. Der Essay Fragen Generator füllt es vor, die Autorin pflegt es im Tab "KI-Feedback" der Frage. Ohne Kit hat die KI keinen Massstab.

*Englisch: Grading kit (reference + model answer)* · [Handbuch](../manual_user/area_modules/Question_Bank_Create_Questions.de.md)

### Bildbeschreibungs-Generator

KI Funktion, die für hochgeladene Bilder Titel, Beschreibung, Alt-Text und Schlagwörter erzeugt. Der Alt-Text ist der Teil, der für die Barrierefreiheit zählt. Im Media Center startet sie per Button, beim Markdown-Import in den Content Editor läuft sie im Hintergrund. Für SVG-Bilder steht sie nicht zur Verfügung.

*Englisch: Image Description Generator* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Einbettungsmodell

Ein Modell, das Text in einen Zahlenvektor übersetzt, sodass sich inhaltliche Nähe rechnen lässt. Die Taxonomie-Zuordnung verwendet es, um einen Text der passenden Taxonomieebene zuzuordnen. Es erzeugt keinen Text.

*Englisch: Embedding model* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Essay Bewertung

KI Funktion, die zu Freitextantworten der Lernenden ein formatives Feedback erzeugt. Sie liefert Hinweise zur Antwort, keine Note und keinen Status. Sie wirkt nur im Quiz einer Seite, nicht in den Kursbausteinen Test und Selbsttest. Die Bewertung bleibt bei den Betreuenden.

*Englisch: Essay Grading* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Essay Fragen Generator

KI Funktion, die aus einem Quelltext oder einer hochgeladenen Datei Freitextfragen samt Bewertungskriterien erstellt. Die Kriterien sind die Grundlage, auf der die Essay Bewertung später Feedback erzeugt.

*Englisch: Essay Question Generator* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Generischer KI Anbieter

Ein KI Anbieter, der über eine OpenAI-kompatible Schnittstelle angebunden wird, zum Beispiel vLLM, Ollama oder LiteLLM. Damit lässt sich ein Modell im eigenen Rechenzentrum betreiben, sodass keine Daten das Haus verlassen. Auf jeder Installation ist ein solcher Anbieter unter der festen Kennung Generic_0 vorhanden.

*Englisch: Generic AI Provider* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### KI Anbieter

Der Dienst, dessen Modelle eine KI Funktion verwendet. Mehrere Anbieter lassen sich gleichzeitig einrichten, und jede Funktion wählt einen davon. Ein Anbieter ist erst betriebsbereit, wenn sein API Schlüssel geprüft ist.

*Englisch: AI Provider* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### KI-Aufruf

Eine einzelne Anfrage von OpenOlat an ein KI-Modell, ausgelöst durch eine KI-Funktion. Jeder Aufruf wird als Zeile im Nutzungsprotokoll festgehalten, mit Funktion, Anbieter, Modell, Dauer, Tokens und dem Status Erfolgreich oder Fehlgeschlagen.

*Englisch: AI call* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### KI-Feedback

Das formative Feedback, das Lernende im Quiz einer Seite zu ihrer Freitextantwort abrufen. Es besteht aus der Beurteilung, einer Gesamteinschätzung, der Verlässlichkeit und den Abschnitten "Was gut gelungen ist", "Was fehlt noch", "Nächster Schritt" und "Sprache". Es vergibt keine Punkte. Im Fragen-Editor heisst so auch der Tab, in dem das Bewertungs-Kit gepflegt wird.

*Englisch: AI feedback* · [Handbuch](../manual_user/basic_concepts/Content_Editor.de.md)

### KI Funktion

Ein Einsatzbereich der KI im Produkt, zum Beispiel der MC Fragen Generator. Jede Funktion wird einzeln aktiviert und erhält einen Anbieter, ein Modell, eine Obergrenze für Ein- und Ausgabe sowie ein Timeout.

*Englisch: AI Feature* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### KI Modul

Das Modul, das die Anbindung an KI-Dienste verwaltet: welche Anbieter zur Verfügung stehen, welche Funktionen aktiv sind, welches Modell jede Funktion verwendet und wie viele Aufrufe gleichzeitig laufen dürfen. Es liefert selbst keine Funktion für Lernende, sondern bedient die Funktionen anderer Module.

*Englisch: AI module* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### KI-Verarbeitungs-Pool

Das Kontingent gleichzeitiger KI-Aufrufe je Serverknoten. Das KI Modul führt zwei Pools getrennt, damit ein langer Auftrag nicht die Aufrufe blockiert, auf die jemand wartet.

*Englisch: AI processing pool* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### MC Fragen Generator

KI Funktion, die aus einem Quelltext oder einer hochgeladenen Datei Vorschläge für Multiple-Choice-Fragen erstellt, im Fragenpool und im Quiz einer Seite. Die Generierung läuft im Hintergrund. Die Vorschläge sind Entwürfe: erzeugte Fragen erhalten den Status Review, und jede Frage muss einzeln auf inhaltliche Korrektheit geprüft werden.

*Englisch: MC Question Generator* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Nutzungsprotokoll

Die Aufzeichnung aller KI-Aufrufe einer Installation mit Funktion, Anbieter, Modell, Status, Dauer und Tokens. Sie ist die Grundlage für die Kostenkontrolle und für die Auskunft darüber, wofür die KI verwendet wurde. Auswertbar nach Zeitbereich und als Excel-Datei.

*Englisch: Usage log* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### ONNX Einbettungsmodell

Ein Einbettungsmodell im Format ONNX, das OpenOlat aus einem Modellverzeichnis auf dem eigenen Server lädt. Es liefert nur Einbettungen für die Taxonomie-Zuordnung und kein Sprachmodell. Es braucht keinen API Schlüssel, und kein Text verlässt den Server.

*Englisch: ONNX embedding model*

### OpenAI

Der KI Anbieter OpenAI, angebunden über einen API Schlüssel. Die Nutzung verursacht Kosten im Konto der Betreiberin.

*Englisch: OpenAI* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Pool "Batch" (Threads)

Der Pool für langlaufende KI-Aufträge wie die Fragengenerierung aus Seiteninhalten. Ein solcher Auftrag kann mehrere Minuten dauern.

*Englisch: Pool "Batch" (threads)* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Pool "Interaktiv" (Threads)

Der Pool für KI-Aufgaben, auf die eine Person aktiv wartet, zum Beispiel das Feedback zu einer Freitextantwort. Er muss gross genug sein, um eine gleichzeitig abgebende Lerngruppe zu bedienen.

*Englisch: Pool "Interactive" (threads)* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Sprachmodell

Das Modell eines Anbieters, das eine KI Funktion aufruft. Je Funktion wird ein eigenes Modell gewählt, damit teure Modelle nur dort laufen, wo sie nötig sind.

*Englisch: Language model* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Taxonomie-Zuordnung (Embeddings)

KI Funktion, die einen Text per Einbettungsmodell der passenden Taxonomieebene zuordnet. Sie schlägt eine Einordnung vor, statt sie von Hand suchen zu lassen.

*Englisch: Taxonomy Matching (Embeddings)* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)

### Vision Modell

Ein Modell, das Bilder auswerten kann. Der Bildbeschreibungs-Generator braucht es, weil ein reines Sprachmodell ein Bild nicht liest.

*Englisch: Vision model* · [Handbuch](../manual_admin/administration/External_Tools_AI.de.md)
