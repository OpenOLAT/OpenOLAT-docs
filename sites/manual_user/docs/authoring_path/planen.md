# Plan {: #planen}

<p class="oo-mh-sub">Create the course</p>

You create the course and make the one decision that shapes everything else: learning path course or conventional course. The course status tells you which phase the course is in.

## Terms of this station {: #terms}

### Course {: #course_course}

A course is a learning resource, but a special one: it is the only one that keeps members, roles and assessments.

??? note "Course in detail"

    A course is a learning resource, but a special one: it is the only one that keeps members, roles and assessments. No other learning resource has any of that, and they are embedded into a course in order to reach participants. The course ties content, activities and assessment into one structured sequence.

    **German:** Kurs

    **What users call it:** course, class, training

    [Read in the manual](../learningresources/index.md) · [Ask Sophia](?sophia=What%20is%20%22Course%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

<p class="oo-mh-kind">Setting</p>

### Course design {: #course_course_design}

The choice when creating a course between learning path course and conventional course.

??? note "Course design in detail"

    The choice when creating a course between learning path course and conventional course. It decides whether access to the elements is steered through the learning path or through conditions, and can later only be changed by duplicating.

    **German:** Kursdesign

    [Read in the manual](../learningresources/Administration.md) · [Ask Sophia](?sophia=What%20is%20%22Course%20design%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

<p class="oo-mh-partof">Includes:</p>

??? note "Learning path course in detail"

    A course design that puts the course elements into an order and measures the progress per element. It steers through the learning path and exceptions, whereas the conventional course steers through conditions.

    **German:** Lernpfadkurs

    **Not to be confused with [Conventional course](../learningresources/Creating_Course.md):** The learning path course steers through the learning path and exceptions, the conventional course through conditions.

    [Read in the manual](../learningresources/Learning_path_course.md) · [Ask Sophia](?sophia=What%20is%20%22Learning%20path%20course%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Conventional course in detail"

    A course design in which the participants navigate the course menu freely. Access to single elements is steered through conditions, not through an order.

    **German:** Herkömmlicher Kurs

    **What users call it:** classic course

    **Not to be confused with [Learning path course](../learningresources/Learning_path_course.md):** The learning path course steers through the learning path and exceptions, the conventional course through conditions.

    [Read in the manual](../learningresources/Creating_Course.md) · [Ask Sophia](?sophia=What%20is%20%22Conventional%20course%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

</div>
