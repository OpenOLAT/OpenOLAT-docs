# Evaluate {: #auswerten}

<p class="oo-mh-sub">How the course is doing</p>

Course statistics and test statistics show how the course is doing. Course reminders bring back participants who have got stuck.

### Course statistics {: #course_course_statistics}

The course tool that counts the accesses to the course elements and shows them as a table and a chart: per hour, per day, per weekday and per week.

??? note "Course statistics in detail"

    The course tool that counts the accesses to the course elements and shows them as a table and a chart: per hour, per day, per weekday and per week. Counted is the click on an element in the course menu, not the click inside its content.

    **German:** Kurs Statistiken

    **What users call it:** access statistics, usage statistics
