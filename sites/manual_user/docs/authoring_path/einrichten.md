# Set up {: #einrichten}

<p class="oo-mh-sub">Role and place</p>

Before you build, you need the Author role. With it, Authoring appears in the main navigation. Everything you create there is a learning resource.

## Terms of this station {: #terms}

<div class="oo-mh-terms" markdown>

<div class="oo-mh-term" markdown>

<p class="oo-mh-kind">Role</p>

### Author {: #roles_role_author}

An organisation role. It allows learning resources to be created in the authoring area.

??? note "Author in detail"

    An organisation role. It allows learning resources to be created in the authoring area. Authors manage their own resources, not those of the organisation.

    **German:** Autor:in

    [Read in the manual](../basic_concepts/Roles.md) · [Ask Sophia](?sophia=What%20is%20%22Author%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

</div>

<div class="oo-mh-term" markdown>

<p class="oo-mh-kind">Area</p>

### Authoring {: #platform_area_authoring}

The area where learning resources are created, edited, copied and managed.

??? note "Authoring in detail"

    The area where learning resources are created, edited, copied and managed. It is only accessible with the Author role or with an administrative role.

    **German:** Autorenbereich

    [Read in the manual](../area_modules/Authoring.md) · [Ask Sophia](?sophia=What%20is%20%22Authoring%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

</div>

<div class="oo-mh-term" markdown>

<p class="oo-mh-kind">Concept</p>

### Learning resource {: #resources_learning_resource}

A content object managed in the authoring area: course, test, form, video, wiki and others.

??? note "Learning resource in detail"

    A content object managed in the authoring area: course, test, form, video, wiki and others. It carries metadata, owners and a lifecycle and can be embedded into courses.

    **German:** Lernressource

    **What users call it:** resource, content, material, repository entry

    [Read in the manual](../learningresources/index.md) · [Ask Sophia](?sophia=What%20is%20%22Learning%20resource%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)
