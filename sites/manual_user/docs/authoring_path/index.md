# The path to your first course {: #authoring_path}

Seven stations lead from the Author role to the evaluation of the running course. The order follows the lifecycle of a course. Each station explains its terms, shows what is easily confused, and opens two doors: try it out and read up.

<p class="oo-mh-phases"><span class="oo-mh-phase oo-mh-phase--on"><b>Knowledge</b>: you are here</span> <span class="oo-mh-phase"><b>Apply</b>: with frentix or with the how-to «My first course»</span> <span class="oo-mh-phase"><b>Deepen</b>: once the first course is running</span></p>

## The stations {: #stations}

<div class="oo-mh-stations" markdown>

1. [Plan <small>Create the course</small>](planen.md)

## Before you start {: #before_you_start}

You need the Author role. With it, Authoring appears in the main navigation. Who assigns the role is explained in the station [Set up](einrichten.md).
