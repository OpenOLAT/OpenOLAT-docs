# Prüfen {: #pruefen}

<p class="oo-mh-sub">Leistung messen</p>

Tests messen Wissen, Selbsttests dienen der Übung. Das Bewertungswerkzeug sammelt die Resultate, der Leistungsnachweis fasst sie dauerhaft zusammen. Zertifikat und Badge bescheinigen.

### Test {: #testing_test}

Kursbaustein, der eine Test-Lernressource in den Kurs einbindet.

??? note "Test im Detail"

    Kursbaustein, der eine Test-Lernressource in den Kurs einbindet. Das Ergebnis zählt zur Kursbewertung.

    **Englisch:** Test

    **Wie Nutzende es nennen:** Prüfung, Klausur, Quiz, Examen, Leistungstest, Wissensabfrage, Leistungskontrolle, eTest

    **Nicht verwechseln mit «[Selbsttest](../learningresources/Course_Element_Self_Test.de.md)»:** Der Test wird bewertet und zählt. Der Selbsttest dient der Selbstkontrolle und geht nicht in die Kursbewertung ein.

### Selbsttest {: #testing_self_test}

Kursbaustein, der eine Test-Lernressource zur Selbstkontrolle einbindet.

??? note "Selbsttest im Detail"

    Kursbaustein, der eine Test-Lernressource zur Selbstkontrolle einbindet. Das Ergebnis geht nicht in die Kursbewertung ein, die Resultate werden anonymisiert gespeichert, und die Anzahl Durchgänge ist unbegrenzt.

    **Englisch:** Self-test

    **Wie Nutzende es nennen:** Übungstest, Probetest, Lernkontrolle

    **Nicht verwechseln mit «[Test](../learningresources/Course_Element_Test.de.md)»:** Der Test wird bewertet und zählt. Der Selbsttest dient der Selbstkontrolle und geht nicht in die Kursbewertung ein.

### Fragenpool {: #testing_question_bank}

Der Bereich, in dem Fragen unabhängig von einem einzelnen Test gesammelt, verschlagwortet, freigegeben und beurteilt werden.

??? note "Fragenpool im Detail"

    Der Bereich, in dem Fragen unabhängig von einem einzelnen Test gesammelt, verschlagwortet, freigegeben und beurteilt werden. Dieselbe Frage lässt sich so in mehreren Tests verwenden.

    **Englisch:** Question bank

    **Wie Nutzende es nennen:** Fragendatenbank, Aufgabenpool, Itembank, Fragensammlung, Testfragen-Datenbank, Fragenkatalog, Fragen-Repository, Testfragenkatalog, Quizpool, Fragenbank

### Bewertung {: #assessment_assessment}

Das Urteil über die Leistung einer Person in einem bewertbaren Kursbaustein, ausgedrückt als Status, Punkte oder Note.

??? note "Bewertung im Detail"

    Das Urteil über die Leistung einer Person in einem bewertbaren Kursbaustein, ausgedrückt als Status, Punkte oder Note. Es beurteilt Personen; das Qualitätsmanagement beurteilt dagegen Angebote.

    **Englisch:** Assessment

    **Wie Nutzende es nennen:** Benotung, Punkte

    Der Bereich eines Kurses, in dem Betreuende und Besitzende alle Resultate der Teilnehmenden sehen, bewerten, freigeben und zurücksetzen.

    **Englisch:** Assessment tool

    **Wie Nutzende es nennen:** Bewertungstool, Benotungstool, Prüfungswerkzeug, Beurteilungstool, Benotungswerkzeug, Testinstrument

### Leistungsnachweis {: #evidence_evidence_of_achievement}

Die Zusammenstellung aller Resultate einer Person in einem Kurs, je bewertbarem Baustein, mit Punkten, Status und Datum.

??? note "Leistungsnachweis im Detail"

    Die Zusammenstellung aller Resultate einer Person in einem Kurs, je bewertbarem Baustein, mit Punkten, Status und Datum.

    **Englisch:** Evidence of achievement

    **Wie Nutzende es nennen:** Zeugnis, Nachweis, Bescheinigung, Teilnahmebestätigung, Leistungsbescheinigung, Leistungsbestätigung, Testergebnis-Dokumentation

    **Nicht verwechseln mit «[Zertifikat](../personal_menu/Certificates.de.md)»:** Der Leistungsnachweis ist die Auswertung im System und immer da. Das Zertifikat ist ein PDF, das ausgestellt wird.

### Zertifikat {: #evidence_certificate}

Ein PDF, das die erfolgreiche Teilnahme an einem Kurs oder den Abschluss eines Zertifikatsprogramms bescheinigt, mit Name, Datum und Seriennummer.

??? note "Zertifikat im Detail"

    Ein PDF, das die erfolgreiche Teilnahme an einem Kurs oder den Abschluss eines Zertifikatsprogramms bescheinigt, mit Name, Datum und Seriennummer. Der Leistungsnachweis zeigt, was jemand geleistet hat; das Zertifikat bescheinigt es nach aussen. Extern erworbene Zertifikate lassen sich hochladen, wenn die Administration das erlaubt.

    **Englisch:** Certificate

    **Wie Nutzende es nennen:** Diplom, Urkunde, Zeugnis, Bescheinigung, Abschluss, Titel, Teilnahmebescheinigung, Kompetenznachweis, Leistungsbestätigung, Teilnehmerbescheinigung, Abschlussbescheinigung, Qualifikationsnachweis

    **Nicht verwechseln mit «[Leistungsnachweis](../personal_menu/Evidence_of_Achievements.de.md)»:** Der Leistungsnachweis ist die Auswertung im System und immer da. Das Zertifikat ist ein PDF, das ausgestellt wird.

    **Nicht verwechseln mit «[Badge](../personal_menu/OpenBadges.de.md)»:** Das Zertifikat ist ein PDF aus einer Vorlage. Der Badge ist ein maschinenlesbarer OpenBadge mit Bild und Kriterien.

    [Im Handbuch lesen](../personal_menu/Certificates.de.md) · [Sophia fragen](?sophia=Was%20ist%20%22Zertifikat%22%20in%20OpenOlat%20und%20wie%20verwende%20ich%20es%3F)

### Badge {: #evidence_badge}

Eine digitale Auszeichnung nach dem Standard Open Badges, mit Bild, Kriterien und ausstellender Stelle.

    **Englisch:** Badge

    **Wie Nutzende es nennen:** Abzeichen, Auszeichnung, Orden, Micro-Credential, Digitales Abzeichen, Leistungsabzeichen, Erfolgsabzeichen, Digitale Auszeichnung, Lernabzeichen

    **Nicht verwechseln mit «[Zertifikat](../personal_menu/Certificates.de.md)»:** Das Zertifikat ist ein PDF aus einer Vorlage. Der Badge ist ein maschinenlesbarer OpenBadge mit Bild und Kriterien.
