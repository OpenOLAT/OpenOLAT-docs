# Auswerten {: #auswerten}

<p class="oo-mh-sub">Wie läuft der Kurs</p>

Kurs Statistiken und Test Statistiken zeigen, wie der Kurs läuft. Kurserinnerungen holen Teilnehmende zurück, die stehen geblieben sind.

### Kurs Statistiken {: #course_course_statistics}

Das Kurswerkzeug, das die Zugriffe auf die Kursbausteine zählt und als Tabelle und Grafik zeigt: pro Stunde, pro Tag, pro Wochentag und pro Woche.

??? note "Kurs Statistiken im Detail"

    Das Kurswerkzeug, das die Zugriffe auf die Kursbausteine zählt und als Tabelle und Grafik zeigt: pro Stunde, pro Tag, pro Wochentag und pro Woche. Gezählt wird der Klick auf einen Baustein im Kursmenü, nicht der Klick in dessen Inhalt.

    **Englisch:** Course statistics

    **Wie Nutzende es nennen:** Kursstatistik, Zugriffsstatistik, Nutzungsstatistik

Automatische E-Mails an Teilnehmende, ausgelöst durch eine Bedingung im Kurs, zum Beispiel eine fehlende Abgabe oder einen nahen Termin.
