# Build {: #bauen}

<p class="oo-mh-sub">Assemble the content</p>

In the course editor you put course elements together. You write pages in the Content editor, media are kept in the Media Center, files in the storage folder. Only publishing makes changes visible to participants.

### Course element {: #course_course_element}

An element that can be added to the course structure in the course editor.

??? note "Course element in detail"

    An element that can be added to the course structure in the course editor.

    **German:** Kursbaustein

    **What users call it:** course element, building block, node

    [Read in the manual](../learningresources/Course_Elements.md) · [Ask Sophia](?sophia=What%20is%20%22Course%20element%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

<div class="oo-mh-kids" markdown>

<p class="oo-mh-partof">Includes:</p>

??? note "Structure in detail"

    A course element that structures the course menu into chapters. It combines the assessments of the elements below it into one overall assessment.

    **German:** Struktur

    [Read in the manual](../learningresources/Course_Element_Structure.md) · [Ask Sophia](?sophia=What%20is%20%22Structure%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Page in detail"

    A course element that presents content in a block-based layout. The page is written in the content editor straight in the course and needs no file.

    **German:** Seite

    [Read in the manual](../learningresources/Course_Element_Page.md) · [Ask Sophia](?sophia=What%20is%20%22Page%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "HTML page in detail"

    A course element that shows a single HTML page with texts, images and videos. The page sits as a file in the storage folder of the course.

    **German:** HTML-Seite

    [Read in the manual](../learningresources/Course_Element_HTML_Page.md) · [Ask Sophia](?sophia=What%20is%20%22HTML%20page%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Folder in detail"

    A course element that offers files for download, for example course material. Coaches can also open the folder for uploads by participants.

    **German:** Ordner

    [Read in the manual](../learningresources/Course_Element_Folder.md) · [Ask Sophia](?sophia=What%20is%20%22Folder%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Forum in detail"

    A course element for asynchronous online discussions. Participants open topics, reply to each other and subscribe to new posts.

    **German:** Forum

    [Read in the manual](../learningresources/Course_Element_Forum.md) · [Ask Sophia](?sophia=What%20is%20%22Forum%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Task in detail"

    The course element for a task workflow with configurable steps: assign the task, submit the solution, revise it, assess it and release the sample solution. Every participant works on their own.

    **German:** Aufgabe

    **What users call it:** assignment, homework, exercise, submission

    [Read in the manual](../learningresources/Course_Element_Task.md) · [Ask Sophia](?sophia=What%20is%20%22Task%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Assessment in detail"

    A course element in which coaches assess a performance without anything being submitted in OpenOlat. It serves performances outside the platform, for example a presentation or an exam in the classroom.

    **German:** Bewertung

    [Read in the manual](../learningresources/Course_Element_Assessment.md) · [Ask Sophia](?sophia=What%20is%20%22Assessment%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

### Media Center {: #authoring_media_center}

The module in which each person stores and manages their media: images, videos, audio, documents, citations, diagrams and texts.

??? note "Media Center in detail"

    The module in which each person stores and manages their media: images, videos, audio, documents, citations, diagrams and texts. Media can be versioned, given tags and a license, and shared with people, groups, courses and organisations. Pages, forms and portfolios embed them instead of copying them.

    **German:** Media Center

    [Read in the manual](../basic_concepts/Media_Center_Concept.md) · [Ask Sophia](?sophia=What%20is%20%22Media%20Center%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

### Storage folder {: #course_storage_folder}

The file area of a course where the files of the course sit.

??? note "Storage folder in detail"

    The file area of a course where the files of the course sit. Participants do not see it; they reach the files only through the course elements.

    **German:** Ablageordner

    **Not to be confused with [Resource folder](../learningresources/Resource_Folder.md):** The storage folder belongs to one course, the resource folder is a learning resource of its own for several courses.

    [Read in the manual](../learningresources/Storage_folder.md) · [Ask Sophia](?sophia=What%20is%20%22Storage%20folder%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

## Deepen once the first course is running {: #deepen}

The first course is in place. Now the things that did not matter while building pay off: the terms of this station have parts and settings that control the course more precisely.

- **Course editor:** Enable edit mode.
- **Course element:** [External page](../learningresources/Course_Element_External_Page.md), [Link list](../learningresources/Course_Element_Link_List.md), [CP learning content](../learningresources/Course_Element_CP_Learning_Content.md), [SCORM 1.2](../learningresources/Course_Element_SCORM_Learning_Content.md) and more. All settings are on the page [Types of Course Elements](../learningresources/Course_Elements.md).
- **Task:** [Group task](../learningresources/Course_Element_Grouptask.md), [Workflow](../learningresources/Course_Element_Task.md).
- **Content editor:** [Content element](../basic_concepts/Content_Editor.md) (in the interface: **Add content**), [Import](../basic_concepts/Content_Editor.md), [Inspector](../basic_concepts/Content_Editor.md).
- **Media Center:** [Shares](../../manual_admin/administration/Modules_Media_Center.md). All settings are on the page [Media Center Concept](../basic_concepts/Media_Center_Concept.md).
