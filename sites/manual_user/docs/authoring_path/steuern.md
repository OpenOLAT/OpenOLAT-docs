# Control {: #steuern}

<p class="oo-mh-sub">Who sees what, when</p>

In a learning path course, the learning path is in control: execution, completion criterion and sequence of steps. In a conventional course, the condition is in control: visibility and access per course element.

## Terms of this station {: #terms}

<div class="oo-mh-terms" markdown>

<div class="oo-mh-term" markdown>

<p class="oo-mh-kind">Concept</p>

### Learning path {: #course_learning_path}

The ordered sequence of the course elements in a learning path course.

??? note "Learning path in detail"

    The ordered sequence of the course elements in a learning path course. It sets what is to be done in which order, measures the progress per element and can exempt elements for individual people.

    **German:** Lernpfad

    **What users call it:** learning path, sequence

    [Read in the manual](../learningresources/Learning_path_course_Course_editor.md) · [Ask Sophia](?sophia=What%20is%20%22Learning%20path%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

<p class="oo-mh-partof">Includes:</p>

??? note "Execution in detail"

    The obligation of a course element in the learning path: mandatory counts towards the learning progress, optional does not, excluded hides the element. Exceptions can change the obligation per person or group.

    **German:** Durchführung

    **What users call it:** obligation, mandatory element

    [Read in the manual](../learningresources/Learning_path_course_Course_editor.md) · [Ask Sophia](?sophia=What%20is%20%22Execution%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Completion criterion in detail"

    The rule that decides when a course element in the learning path counts as done: open the element, confirmation by the person, score, passed or an element-specific criterion such as "Test beendet".

    **German:** Erledigungskriterium

    **What users call it:** completion trigger, done criterion

    [Read in the manual](../learningresources/Learning_path_course_Course_editor.md) · [Ask Sophia](?sophia=What%20is%20%22Completion%20criterion%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Sequence of steps in detail"

    The setting on the course or on a structure element whether the elements below are accessible sequentially, that is only after the previous one is done, or in no sequence.

    **German:** Abfolge der Lernschritte

    **What users call it:** order, sequential

    [Read in the manual](../learningresources/Learning_path_course_Course_editor.md) · [Ask Sophia](?sophia=What%20is%20%22Sequence%20of%20steps%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

### Condition {: #course_condition}

The rule that steers the visibility and access of a course element in the conventional course: blocked for learners, depending on date, group or assessment, only in assessment mode.

??? note "Condition in detail"

    The rule that steers the visibility and access of a course element in the conventional course: blocked for learners, depending on date, group or assessment, only in assessment mode. In expert mode it is written as an expression.

    **German:** Bedingung

    **What users call it:** access rule, visibility rule, restriction, precondition

    **Not to be confused with [Exception](../learningresources/Learning_path_course_Course_editor.md):** The exception refines the execution in the learning path course, the condition steers visibility and access in the conventional course.

    [Read in the manual](../learningresources/General_Configuration_of_Course_Elements.md) · [Ask Sophia](?sophia=What%20is%20%22Condition%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

<p class="oo-mh-partof">Includes:</p>

??? note "Visibility in detail"

    The condition in the visibility tab of a course element in a conventional course: who sees the element in the course menu. It is kept apart from the access: invisible does not mean blocked. Calendars and groups have a visibility of their own.

    **German:** Sichtbarkeit

    **Not to be confused with [Access](../learningresources/General_Configuration_of_Course_Elements.md):** Visibility decides whether the element appears in the menu, access whether it can be opened.

    [Read in the manual](../learningresources/General_Configuration_of_Course_Elements.md) · [Ask Sophia](?sophia=What%20is%20%22Visibility%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)

??? note "Access in detail"

    The condition in the access tab of a course element in the conventional course: who may open the element. A visible but blocked element shows an explanation instead of the content.

    **German:** Zugang

    **Not to be confused with [Visibility](../learningresources/General_Configuration_of_Course_Elements.md):** Visibility decides whether the element appears in the menu, access whether it can be opened.

    [Read in the manual](../learningresources/General_Configuration_of_Course_Elements.md) · [Ask Sophia](?sophia=What%20is%20%22Access%22%20in%20OpenOlat%20and%20how%20do%20I%20use%20it%3F)
