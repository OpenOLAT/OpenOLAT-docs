# Navigation {: #navigation}

After the login you get either to

* a defined landing page, e.g. the Authoring area for authors or the Courses for non-authors,
* an info page, a page that usually contains general information on various topics (similar to a course with info),
* the OpenOlat portal or
* a landing page you defined individually. Every OpenOlat page can be marked as an individual landing page.

!!! info "Important"

    If you cannot see the "Portal" tab, this page has been switched off system-wide by the system administrators.

## Global navigation {: #global_navigation}

The [chat](Chat.md) (instant messenger) and the [search](Search_General.md) are generally available in the top navigation bar. Which other elements are displayed at the top right of the navigation bar depends on your settings.

![Right-hand part of the top navigation bar with chat icon, number of logged-in people, search and personal menu](assets/global_navigation.png){ class="shadow aside-right lightbox"}

In the [personal menu](../personal_menu/index.md) you find the areas user tools, configuration and system. Depending on the tools selected under "Settings", certain user tools are moved to the top navigation bar or remain accessible via the personal menu.

Further information on the individual elements can be found under the corresponding links.
