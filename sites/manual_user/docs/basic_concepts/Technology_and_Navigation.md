# Technology and Navigation

OpenOlat is a web application and is mainly written in Java. In addition, the common standards for web applications are used: Apache as web server, Tomcat as application server, a PostgreSQL database (other databases can also be used) and XML for data management. Intuitive user interfaces are implemented using Web 2.0 technologies. Files can be uploaded by drag & drop.

OpenOlat is designed responsively to meet the requirements of users of mobile devices. This way, OpenOlat can also be used without restrictions on the small screens of mobile phones, because the layout and structure of the page content adapt to the window size and orientation. The arrangement of menu bars and page content depends on the window size in which OpenOlat is open.
