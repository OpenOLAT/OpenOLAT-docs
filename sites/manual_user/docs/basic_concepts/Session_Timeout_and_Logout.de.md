# Session-Timeout und Logout [:octicons-tag-16:{ title="ab Release 19.0 (OO-7672)" }](https://track.frentix.com/issue/OO-7672) {: #session_timeout_logout}

Für jede eingeloggte Benutzer:in verwaltet OpenOlat eine Session. Bei jedem Klick (beispielsweise Aufrufen einer Frage in einem Test) beginnt die Session-Time der Session wieder neu zu laufen. Die Session-Time kann von den Systemadministrator:innen beliebig eingestellt werden. Wenn Sie innerhalb der Session-Time keinen Klick in OpenOlat machen, läuft die Session ab.

Der Ablauf der Session wird nicht im Voraus angekündigt. Beim nächsten Klick nach dem Ablauf erscheint die Meldung "Sie wurden abgemeldet". Über "Neu anmelden" gelangen Sie zur Login-Seite. Alle nicht gespeicherten Daten gehen beim erneuten Login verloren. Über "Zurück zur Seite" können Sie ungespeicherte Eingaben vorher noch in die Zwischenablage kopieren. Speichern Sie deshalb Ihre Arbeit regelmässig.

Sie können sich jederzeit über "Abmelden" im [persönlichen Menü](../personal_menu/index.de.md) oben rechts aus OpenOlat ausloggen. So gelangen Sie zurück zur [Login-Seite](../login_registration/Login_Page.de.md). Wenn Sie sich nicht ausloggen, sondern das Browserfenster oder den Browser schliessen, läuft Ihre Session bis zum Session-Timeout weiter.

Wenn Sie OpenOlat an öffentlichen Arbeitsplätzen verwenden, ist es wichtig, dass Sie sich nach der Arbeit mit OpenOlat ausloggen und nicht nur das Browserfenster schliessen. Solange Ihre Session läuft, könnte auf demselben Rechner eine andere Person mit Ihren Login-Daten in OpenOlat arbeiten.
