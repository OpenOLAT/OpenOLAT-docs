# Roles and Rights: Overview {: #overview}

What a person sees and is allowed to do in OpenOlat depends on their user type and on their roles. In OpenOlat you find 3 user types. Registered users in particular can be assigned various roles, and certain rights are linked to each role, including rights in courses. The main navigation is therefore role-dependent: every task has its own working area.

If you are looking for an answer about roles and rights, the table tells you on which page it is. The table follows the order of the navigation.

| Page | What for |
|---|---|
| [Working areas](../Roles_Home_Areas.md) | Look up in which area of the main navigation each role works and why two people see different menus after login. |
| [User types](../User_Types.md) | Distinguish the 3 user types: registered users, external users and anonymous guests. |
| [Roles](../Roles/index.md) | Look up what each role allows and where it applies: in the organisation, in the course, in the group, in the Course Planner or in a relationship between people. |
| [Assign roles](../Assign_Roles.md) | Look up where you assign a role: organisation roles mostly in the user management, course roles in the members management of the course, further roles in other places. |
| [Authorisation in courses](../Authorisation_Concept.md) | Look up what owners, coaches, participants and the organisation-wide roles can access in a course, depending on the status of the course. |
| [Guest access](../guest_access.md) | Give learners whose data does not need to be saved access to conventional courses and other learning resources as anonymous guests, without an OpenOlat account. The system administrators switch on guest access. |
