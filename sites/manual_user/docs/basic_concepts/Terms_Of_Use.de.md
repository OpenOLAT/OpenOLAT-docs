# Nutzungsbedingungen {: #terms_of_use}

## Welche Nutzungsbedingungen müssen akzeptiert werden?

Wenn Sie OpenOlat oder bestimmte Elemente darin zum ersten Mal nutzen, kann eine Zustimmung zu den Nutzungsbedingungen erforderlich sein. Wird dies von der betreibenden Institution oder von Besitzer:innen eines Kurses oder sonstigen Elements verlangt, können verschiedene Nutzungsbedingungen zur Bestätigung eingeblendet werden.

## Nutzungsbedingungen der OpenOlat-Plattform {: #terms_of_use_platform}

### Bestätigung durch OpenOlat-Benutzer:innen beim ersten Aufruf

Beim ersten Aufruf von OpenOlat werden alle Benutzer:innen um Bestätigung der Nutzungsbedingungen gebeten. Lehnen Sie ab, kehren Sie zurück zur Login-Seite.

![Text der Nutzungsbedingungen mit der Checkbox zur Zustimmung, dem Link Drucken und den Buttons Ablehnen und Akzeptieren, im Dialog beim ersten Login auf der Login-Seite](assets/terms_of_use_platform_accept_v1_de.png){ class="shadow lightbox" }


### Nutzungsbedingungen der Plattform definieren {: #terms_of_use_platform_define}

**Administrator:innen** definieren den Text der Nutzungsbedingungen in der System-Administration unter `Administration > Customizing > Impressum`. Die Nutzungsbedingungen lassen sich nur hinterlegen, wenn das Impressum eingeschaltet ist. Für jede aktivierte Sprache kann ein eigener Text erstellt werden.

![Ein Button je aktivierter Sprache zum Hinterlegen der Nutzungsbedingungen, unterhalb des Impressumstexts, auf der Seite Impressum im Menü Customizing der System-Administration](assets/terms_of_use_platform_define_v1_de.png){ class="shadow lightbox" }


### Akzeptierte Nutzungsbedingungen nachlesen {: #terms_of_use_platform_verify}

Alle Benutzer:innen können die Nutzungsbedingungen, denen sie einmal zugestimmt haben, in ihrem persönlichen Menü jederzeit nachlesen:<br>`Persönliches Menü > Einstellungen > Tab "Nutzungsbedingungen"`

![Der akzeptierte Text der Nutzungsbedingungen mit drei angehakten Checkboxen zur Zustimmung und dem Link Drucken, im Tab Nutzungsbedingungen der Einstellungen im persönlichen Menü](assets/terms_of_use_pers_menu_v1_de.png){ class="shadow lightbox" }

## Nutzungsbedingungen in den Kurseinstellungen {: #terms_of_use_course}

### Bestätigung durch Lernende im Kurs

Beim ersten Aufruf eines Kurses kann eine weitere Bestätigung von Nutzungsbedingungen erforderlich sein, denn die Kursbesitzer:innen können für ihren Kurs jeweils **kursspezifische** Nutzungsbedingungen definieren, die von den Teilnehmer:innen akzeptiert werden müssen.


### Nutzungsbedingungen eines Kurses definieren {: #terms_of_use_course_define}

Kursbesitzer:innen erstellen für ihren Kurs kursspezifische Nutzungsbedingungen unter:<br>`Kurs > Administration > Einstellungen > Tab "Nutzungsbedingungen"`

Der Texteditor wird angezeigt, sobald die Checkbox "Nutzungsbedingungen" angehakt ist. Auf demselben Tab kann zusätzlich eine kursbezogene Datenschutzerklärung eingeschaltet werden; sie ist gleich aufgebaut.

![Nutzungsbedingungen eingeschaltet, darunter die Felder Titel, Bedingungen mit Texteditor sowie Beschriftung Checkbox 1 und 2, im Tab Nutzungsbedingungen der Kurseinstellungen](assets/terms_of_use_course_define_v1_de.png){ class="shadow lightbox" }

Im Feld "Beschriftung Checkbox 1" am unteren Rand der Seite definieren Sie, welcher Text den Teilnehmer:innen neben ihrer Checkbox zum Akzeptieren der Nutzungsbedingungen angezeigt wird.

Zusätzlich kann im Feld "Beschriftung Checkbox 2" eine zweite Checkbox mit einem beliebigen Beschreibungstext zur Bestätigung definiert werden. Wird ein Text eingegeben, müssen beide Checkboxen von den Teilnehmer:innen bestätigt werden, damit die Nutzungsbedingungen als akzeptiert gelten. Ist kein Beschreibungstext eingegeben, wird die zweite Checkbox den Teilnehmer:innen nicht angezeigt.

![Feld Beschriftung Checkbox 2 mit dem Beispieltext "Ich willige ein, dass ...", im Tab Nutzungsbedingungen der Kurseinstellungen](assets/terms_of_use_course_checkbox2_v1_de.png){ class="shadow lightbox" }


### Bestätigungsaufforderung für einen Kurs aktivieren

Damit die Nutzungsbedingungen angezeigt werden, müssen sie durch die Kursbesitzer:in eingeschaltet werden. Wurde ein Text für die Nutzungsbedingungen erfasst, bleibt er nach dem Speichern erhalten, unabhängig davon, ob die Anzeige aktiviert ist. Sie können eingefügte Nutzungsbedingungen also z.B. bearbeiten und dann so lange deaktivieren, bis die finale Version erstellt ist.

![Checkbox Eingeschaltet neben Nutzungsbedingungen angehakt, im Tab Nutzungsbedingungen der Kurseinstellungen](assets/terms_of_use_course_activate_v1_de.png){ class="shadow lightbox" }


### Verwaltung der Nutzungsbedingungen in der Mitgliederverwaltung

Welche Kursteilnehmer:innen ihre Zustimmung zu den kursspezifischen Nutzungsbedingungen gegeben haben, sehen Kursbesitzer:innen in der [Mitgliederverwaltung](../learningresources/Members_management.de.md) unter:<br>`Kurs > Administration > Mitgliederverwaltung > Einwilligungen`

![Eintrag Mitgliederverwaltung im aufgeklappten Menü Administration der Kurs-Toolbar](assets/terms_of_use_course_members_management1_v1_de.png){ class="shadow lightbox" }

![Tabelle der Einwilligungen mit Datum je Person, ein widerrufener Eintrag durchgestrichen, darunter die Buttons zum Widerrufen und Löschen, im Bereich Einwilligungen der Mitgliederverwaltung](assets/terms_of_use_course_members_management2_v1_de.png){ class="shadow lightbox" }

* Lehnt eine Teilnehmer:in ab, kann direkt mit der betroffenen Person Kontakt aufgenommen werden.
* Kursbesitzer:innen können ausgewählte Einwilligungen widerrufen oder die Einträge löschen.


### Übernahme von Nutzungsbedingungen beim Kopieren von Kursen

[Lernpfadkurse](../learningresources/Creating_learning_path_courses.de.md) können mit Hilfe eines Wizards kopiert werden: `Kurs > Administration > Kopieren mit Wizard`. Mit diesem Wizard kann vor der Ausführung des Kopiervorgangs festgelegt werden, welche [Kurseinstellungen](../learningresources/Course_Settings.de.md) in die Kopie übernommen werden sollen. Unter anderem können so auch die Nutzungsbedingungen übernommen werden.

![Zeile Nutzungsbedingungen mit den Optionen Anpassen, Kopieren und Nicht kopieren, im Schritt Kopieroptionen des Wizards Kurs kopieren](assets/terms_of_use_course_copy_v1_de.png){ class="shadow lightbox" }

## Nutzungsbedingungen in Formularen {: #terms_of_use_form}

### Bestätigung durch Lernende

Auch beim Ausfüllen eines Formulars kann der erfasste Inhalt es erforderlich machen, dass die Teilnehmer:innen eine Erklärung zu den Nutzungsbedingungen akzeptieren.

![Text der Einverständniserklärung mit der Checkbox zur Zustimmung, in der Teilnehmer:innenansicht eines Formulars](assets/terms_of_use_form3_v1_de.png){ class="shadow lightbox" }

### Nutzungsbedingungen eines Formulars definieren

Innerhalb der Lernressource Formular gibt es das Element "Nutzungsbedingungen", das Autor:innen im [Formular-Editor](../learningresources/Form_Editor.de.md) über "Inhalt hinzufügen" einfügen. Im Element definieren Sie den Text der Einverständniserklärung und die Beschriftung der Checkbox.

![Element Nutzungsbedingungen in der Gruppe Organisatorisch des Dialogs Inhalt hinzufügen, im Formular-Editor](assets/terms_of_use_form1_v1_de.png){ class="shadow lightbox" }
![Felder Einverständniserklärung und Beschriftung Einverständniserklärung des Elements Nutzungsbedingungen, rechts der Inspektor mit dem Schalter Hinweis-Box, im Formular-Editor](assets/terms_of_use_form2_v1_de.png){ class="shadow lightbox" }

## Nutzungsbedingungen externer Werkzeuge {: #terms_of_use_external_tools}

In OpenOlat sind an einigen Stellen externe Werkzeuge eingebunden (meistens ebenfalls Open Source, aber nicht von frentix entwickelt), für die ebenfalls vor Benutzung die Bedingungen akzeptiert werden müssen.

Beispiel **draw.io**<br>
draw.io ist ein Online-Werkzeug zur Erstellung von Diagrammen, das in OpenOlat an vielen Stellen eingesetzt werden kann, z.B. in Projekten, im Portfolio, im Kursbaustein "Dokument", im Media Center und überall, wo neue Dokumente erstellt werden können. In draw.io können auch mehrere Personen kooperativ an einem Diagramm arbeiten.
