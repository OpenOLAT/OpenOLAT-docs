# Gruppenwerkzeuge nutzen {: #group_tools}

Mit den Gruppenwerkzeugen arbeiten die Mitglieder einer Gruppe zusammen: Sie tauschen Dateien aus, diskutieren, planen Termine und treffen sich online. Welche Werkzeuge eine Gruppe hat, legen die Gruppenbetreuer:innen im Tab "Werkzeuge" der [Gruppenadministration](Group_Administration/index.de.md#tools) fest. Jedes eingeschaltete Werkzeug erscheint mit seinem Symbol im Menü der Gruppe links:

| Symbol | Name |   | Beschreibung |
| ------ | ---- | - | ------------ |
| :o_icon_o_icon_news: | Information | :material-rss: | Mit der "Information" erstellen Gruppenbetreuer:innen Mitteilungen für alle Gruppenmitglieder. Bei Bedarf verschicken sie die Mitteilung zusätzlich per E-Mail an die Personen, die die "Information" abonniert haben, an die Betreuer:innen oder an die Teilnehmer:innen der Gruppe. Ob auch Gruppenteilnehmer:innen Mitteilungen erstellen, legen die Gruppenbetreuer:innen im Tab "Werkzeuge" fest; dort heisst das Werkzeug "Information an Mitglieder". Dieselbe Funktion haben im Kurs das Werkzeug ["Mitteilungen"](../learningresources/Course_Settings_Toolbar.de.md#notifications) der Toolbar und der [Kursbaustein "Mitteilungen"](../learningresources/Course_Element_Notifications.de.md). Weil die "Information" ein eigenes Werkzeug der Gruppe ist, trägt sie im Menü der Gruppe das Info-Symbol; die Mitteilungen im Kurs tragen das Megafon-Symbol. |
| :o_icon_o_calendar_icon: | Kalender | :material-rss: | Verwalten Sie die Termine Ihrer Gruppe über den Gruppenkalender. Je nach Konfiguration haben Sie Schreib- oder nur Leserechte. Allgemeines zum Kalender beschreibt die Seite [Persönliche Werkzeuge: Kalender](../personal_menu/Calendar.de.md). |
| :o_icon_o_CourseModule_icon: | Kurs |  | Ist die Gruppe mit einem oder mehreren Kursen verbunden, rufen Sie diese über den Eintrag "Kurs" im Menü der Gruppe auf. |
| :o_icon_o_icon_group: | Mitglieder |  | Sofern die Anzeige aktiviert ist, sehen Sie eine Liste mit allen Teilnehmer:innen und/oder Betreuer:innen der Gruppe. Je nach Einstellung ist auch die Warteliste sichtbar. Die Liste kann je nach Konfiguration heruntergeladen und gedruckt werden. An die Mitglieder können E-Mails verschickt werden. |
| :o_icon_o_co_icon: | E-Mail |  | Schicken Sie allen oder ausgewählten Gruppenbetreuer:innen oder -teilnehmer:innen eine E-Mail. |
| :o_icon_o_bc_icon: | Ordner | :material-rss: | Tauschen Sie über den Ordner Dokumente mit anderen Gruppenmitgliedern aus. Dateien können hochgeladen oder erstellt werden. Eine weitere Strukturierung mit Unterordnern ist ebenfalls möglich. |
| :o_icon_o_fo_icon: | Forum | :material-rss: | Im Forum tauschen sich die Gruppenmitglieder zeitversetzt aus: Sie eröffnen Diskussionsthemen und antworten darauf mit Beiträgen. Wie ein Forum funktioniert, beschreibt die Seite [Kursbaustein "Forum"](../learningresources/Course_Element_Forum.de.md). |
| :o_icon_o_icon_chat: | Chat |  | Sie sehen, welche anderen Mitglieder sich im Gruppenchat befinden. Betreten Sie den Chatraum, um miteinander in Echtzeit zu kommunizieren. |
| :o_icon_o_wiki_icon: | Wiki | :material-rss: | Nutzen Sie das Wiki, um gemeinsam Inhalte zu erstellen. Wie die Arbeit mit einem Wiki geht, beschreibt die Seite [Wiki](../learningresources/Wiki.de.md). |
| :o_icon_o_ep_icon: | Portfolio |  | Nutzen Sie das [Portfolio](../area_modules/Portfolio_General_Information.de.md), um gemeinsam eine Mappe zu erstellen und Einträge hinzuzufügen. |
| :o_icon_o_openmeetings_icon: | OpenMeetings |  | Nutzen Sie OpenMeetings zur Online-Kommunikation und Zusammenarbeit in einem virtuellen Raum. Das Werkzeug funktioniert ähnlich wie der [Kursbaustein "OpenMeetings"](../learningresources/Course_Element_OpenMeetings.de.md). |
| :o_icon_o_vc_icon: | Adobe Connect |  | Nutzen Sie Adobe Connect zur Online-Kommunikation in einem virtuellen Meetingraum. Das Werkzeug funktioniert ähnlich wie der [Kursbaustein "Adobe Connect"](../learningresources/Course_Element_Adobe_Connect.de.md) [:octicons-tag-16:{ title="ab Release 14.0 (OO-3889)" }](https://track.frentix.com/issue/OO-3889). |
| :o_icon_o_vc_icon: | BigBlueButton |  | Nutzen Sie BigBlueButton zur Online-Kommunikation und Zusammenarbeit in virtuellen Räumen. Bei entsprechender Freigabe der Raumvorlagen können sowohl Gruppenbetreuer:innen als auch Gruppenteilnehmer:innen neue Meetings für gemeinsame Online-Sessions anlegen. Wie im Kursbaustein stehen die Aufzeichnungen nach Meeting-Ende für einen weiteren Zugriff bereit. Die Funktionalität ist im [Kursbaustein "BigBlueButton"](../learningresources/bigbluebutton/index.de.md) näher beschrieben. |
| :o_icon_o_vc_icon: | Microsoft Teams |  | Nutzen Sie MS Teams zur Online-Kommunikation und Zusammenarbeit in virtuellen Räumen. Bei entsprechender Konfiguration durch die Gruppenbetreuer:innen können sowohl Gruppenbetreuer:innen als auch Gruppenteilnehmer:innen neue Online-Termine anlegen. Ob dabei auch permanente Reservierungen ohne Datum zur Wahl stehen, legt die System-Administration fest [:octicons-tag-16:{ title="ab Release 21.1.0 (OO-9666)" }](https://track.frentix.com/issue/OO-9666). Die Funktionalität ist im [Kursbaustein "Microsoft Teams"](../learningresources/Course_Element_Microsoft_Teams.de.md) näher beschrieben. |
| :o_icon_o_vc_icon: | Zoom |  | Nutzen Sie Zoom für Online-Meetings der Gruppe. Das Werkzeug funktioniert ähnlich wie der [Kursbaustein "Zoom"](../learningresources/zoom/index.de.md) [:octicons-tag-16:{ title="ab Release 17.0.0 (OO-6189)" }](https://track.frentix.com/issue/OO-6189). |

!!! info "Wichtig"

    Die mit einem :material-rss: markierten Werkzeuge können abonniert werden, so dass man schnell über Änderungen informiert wird. Ihre Abonnements finden Sie unter [Persönliche Werkzeuge: Abonnements](../personal_menu/Subscriptions.de.md).

!!! info "Virtuelle Klassenräume"

    Je nach Konfiguration durch die [Systemadministrator:innen](../../manual_admin/administration/External_Tools_-_Administration/index.de.md) stehen unterschiedliche virtuelle Klassenräume wie OpenMeetings, Adobe Connect, BigBlueButton, Microsoft Teams oder Zoom als Gruppenwerkzeug zur Verfügung.



!!! info "Gruppenkalender in Verbindung mit Kurskalendern"

    In einem Gruppenkalender sehen die Gruppenteilnehmer:innen alle Einträge der Gruppenmitglieder, egal ob die Termine privat oder öffentlich gesetzt sind.

    Ist die Gruppe mit einem Kurs verbunden, werden im Kurskalender den Gruppenteilnehmer:innen folgende Einträge angezeigt:

    - öffentliche Einträge der Gruppe,
    - die Einträge, die das jeweilige Gruppenmitglied selbst im Gruppenkalender erstellt hat,
    - sowie die kursspezifischen Kalendereinträge.

    Die Einträge eines Gruppenkalenders sehen im Kurskalender nur die Mitglieder dieser Gruppe. Sind mehrere Gruppen mit einem Kurs verbunden, sehen die Mitglieder jeder Gruppe also nur die Einträge ihrer eigenen Gruppe.
