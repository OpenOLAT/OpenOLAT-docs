# Projekte - Whiteboard

Im Bereich "Projekte" kommt das freie Zeichen- und Diagrammwerkzeug "draw.io" als Whiteboard zum Einsatz. Es kann auch kollaborativ von mehreren Projektmitgliedern genutzt werden.


![Whiteboard im Cockpit eines Projekts mit einem Diagramm neben dem Schnellzugriff](assets/project_whiteboard_v1_de.png){ class="shadow lightbox" }


![Zeichenfläche von draw.io mit Formenpalette links und Format-Panel rechts, geöffnet aus dem Whiteboard des Projekts](assets/project_drawio_v1_de.png){ class="shadow lightbox" }


Die erstellten Zeichnungen können auch zusammen mit den übrigen Dateien des Projektes gespeichert werden: `Whiteboard > 3-Punkte-Menü > "Aktuelle Version in Projektdateien ablegen"`.

![Option Aktuelle Version in Projektdateien ablegen im 3-Punkte-Menü des Whiteboards, daneben Bearbeiten und Whiteboard zurücksetzen](assets/Whiteboard_speichern.jpg){ class="shadow lightbox" }

Mit "Whiteboard zurücksetzen" im selben Menü legt OpenOlat die aktuelle Version des Whiteboards als Datei im Bereich "Dateien" ab und löscht den gesamten Inhalt des Whiteboards.
