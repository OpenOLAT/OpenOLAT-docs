# Fragetypen {: #question_types}

Beim Erstellen einer Frage im Fragenpool wählen Sie im Dialog "Frage erstellen" im Feld "Fragetyp" einen der 16 Fragetypen: `Fragenpool > Meine Fragen > Frage erstellen`. Die Liste zeigt jeden Typ mit seinem Zweck und seiner Bewertung, ein Klick auf den Namen öffnet die Seite des Typs mit allen Einstellungen. Die Liste folgt der Reihenfolge im Testeditor, das Feld "Fragetyp" zeigt die Typen in einer anderen Reihenfolge.

Den Fragenpool sehen Sie in der Hauptnavigation, wenn die System-Administration ihn auf der Seite [Bereiche](../../../manual_admin/administration/Customizing.de.md#sites) aktiviert hat und Ihre Rolle in der Spalte "Zugang" eingeschlossen ist. In der Standardeinstellung "Autor:innen" sind das Autor:innen, Administrator:innen und Principals. Dieselben 16 Typen bietet der Testeditor eines Tests auch ohne Fragenpool an, siehe [Fragetypen unter Test](../../learningresources/Test_question_types/index.de.md).
