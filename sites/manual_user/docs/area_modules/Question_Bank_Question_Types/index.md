# Question types {: #question_types}

When you create a question in the question bank, you choose one of the 16 question types in the "Type" field of the "Create question" dialog: `Question bank > My questions > Create question`. The list shows each type with its purpose and its scoring; a click on the name opens the page of the type with all settings. The list follows the order in the test editor; the "Type" field shows the types in a different order.

You see the question bank in the main navigation if the system administration has activated it on the [Sites](../../../manual_admin/administration/Customizing.md#sites) page and your role is included in the "Access" column. With the default setting "Authors only", these are authors, administrators and principals. The test editor of a test offers the same 16 types also without the question bank, see [Question types under Test](../../learningresources/Test_question_types/index.md).
