# Meine Mappen {: #my_portfolio_binders}

Unter "Meine Mappen" finden Sie alle Ihre Mappen an einer Stelle, die in einem Kurs abgeholten wie die selbst erstellten, und legen hier auch neue Mappen an. Jede Benutzer:in erreicht das eigene Portfolio über das persönliche Menü:<br>
`Persönliches Menü > Portfolio 2.0 > Zu meinen Mappen`

![Bereich Meine Mappen mit dem Link Neue Mappe erstellen, dem gleichnamigen Kasten und den eigenen Mappen als Kacheln; abgeholte Mappen tragen einen roten Randstreifen und den Kurshinweis](assets/Meine_Mappen.jpg){ class="shadow lightbox" title="Bereich Meine Mappen im Portfolio" }

## Die zwei Mappenvarianten

Es werden grundsätzlich zwei Arten von Mappen unterschieden:

* In einem Kurs abgeholte Mappen
* Selbst erstellte, kursunabhängige Mappen

### Abgeholte, vorbereitete Mappen [:octicons-tag-16:{ title="ab Release 11.0 (OO-2305)" }](https://track.frentix.com/issue/OO-2305)

In einem Kurs bei einer Portfolioaufgabe abgeholte Mappen erkennen Sie am roten Randstreifen und dem Hinweis auf den zugehörigen Kurs. Diese Mappen basieren auf einer ["Portfolio 2.0 Vorlage"](../learningresources/Portfolio_template_Creation.de.md) und werden in der Regel von einer anderen Person, meist den Lehrenden, erstellt. Abgeholt wird die Mappe im Kurs über den Kursbaustein "[Portfolioaufgabe](../learningresources/Course_Element_Portfolio_Task.de.md)". Alternativ ist es auch möglich, Portfoliovorlagen kursunabhängig zu buchen und abzuholen.

Sobald Lernende eine Mappe abholen, wird eine Kopie der Vorlage erstellt und die abgeholte Mappe erscheint im persönlichen Portfoliobereich unter "Meine Mappen". Wer diese Mappe öffnet, kann die dort hinterlegten Aufgaben (Typ Freitext oder Formular) wählen bzw. abholen und die bereitgestellten Portfolioaktivitäten bearbeiten, indem diverse Artefakte (Texte, Dateien, Bilder usw.) hinterlegt oder ein vorbereitetes Formular ausgefüllt wird.

Im [Portfolio Editor](../area_modules/The_portfolio_editor_17_1.de.md) muss immer zuerst ein Layout ausgewählt werden, bevor es mit Inhalten und Artefakten, wahlweise auch aus dem [Media Center](../basic_concepts/Media_Center_Concept.de.md), gefüllt werden kann. Es können auch mehrere Layouts für eine bereitgestellte Aufgabe verwendet werden.

Alternativ können auch schon erstellte Portfolioeinträge über den Button ["Inhalt referenzieren"](Multiple_use_of_entries.de.md) verknüpft werden. Änderungen an den Einträgen sind dann an allen referenzierten Stellen möglich.

!!! info "Wichtig"

    Benutzer:innen können allerdings keine neuen "Bereiche" in einer abgeholten Mappe anlegen. Auch das Erstellen von eigenen "Einträgen" ist standardmässig deaktiviert. Welche Aktionen Sie in einer abgeholten Mappe haben, steht unter [Die Toolbar einer Mappe](#binder_toolbar).

### Individuelle Mappen [:octicons-tag-16:{ title="ab Release 11.0 (OO-2297)" }](https://track.frentix.com/issue/OO-2297) {: #individuelle-portfoliomappen}

Alle OpenOlat Benutzer:innen können individuelle, unabhängige, persönliche Mappen mit Bereichen, Einträgen und diversen Inhalten erstellen und so z.B. den eigenen Lernprozess dokumentieren und begleiten, ohne dass ein Kursbezug oder ein formaler Lehrrahmen besteht.

Es gibt im Bereich "Meine Mappen" zwei Stellen, an denen neue Mappen erstellt werden können.

#### a) Über den Link "Neue Mappe erstellen" rechts oben

Auf diesem Weg erhalten Sie rasch eine neue, leere Mappe. In einer selbst erstellten Mappe stehen Ihnen alle Aktionen der [Toolbar](#binder_toolbar) zur Verfügung, vom Gliedern in Bereiche über das Bearbeiten der Metadaten bis zum Export und Löschen. Zugangsrechte vergeben Sie im Tab "Freigabe".

#### b) Über das Ausklappmenü im Kasten "Neue Mappe erstellen"

Im Kasten "Neue Mappe erstellen" öffnet der gleichnamige Button ein Ausklappmenü mit allen Wegen zu einer neuen Mappe.

![Ausklappmenü des Buttons Neue Mappe erstellen mit vier Wegen zur neuen Mappe: leer, aus einer Vorlage, aus einer Portfolioaufgabe im Kurs, aus Einträgen](assets/portfolio_mappe_erstellen2.jpg.png){ class="shadow lightbox" title="Kasten Neue Mappe erstellen in Meine Mappen" }

Neben der Möglichkeit, eine leere Mappe wie unter a) zu erstellen, gibt es noch folgende weitere Optionen:

* **"Mappe basierend auf Vorlage erstellen"**: Hier kann als Basis eine Portfolio 2.0 Vorlage verwendet werden, für die die Benutzer:in die Berechtigung hat.
* **"Mappe für Portfolioaufgabe aus Kurs erstellen"**: Hier werden Portfolioaufgaben aus den eigenen Kursen angezeigt und es kann eine ausgewählt werden. Dieses Vorgehen führt zum selben Ergebnis wie das Abholen der Portfolioaufgabe im Kurs.
* **"Mappe aus Einträgen erstellen"**: Hier können zuvor erstellte Einträge in einer neuen Mappe gebündelt werden. Ein Assistent führt dabei Schritt für Schritt durch die Auswahl.

!!! info "Wichtig"

    Die Möglichkeit, selbst Mappen zu erstellen, kann von Ihrer [Administrator:in](../../manual_admin/administration/eAssessment_ePortfolio.de.md) eingeschränkt werden.

## Die Toolbar einer Mappe {: #binder_toolbar}

Wenn Sie eine Mappe öffnen, verwalten Sie sie über die Toolbar über den Tabs: links die Mappe als Ganzes, rechts ihren Inhalt. Welche Aktionen Sie sehen, hängt davon ab, ob Sie die Mappe selbst erstellt oder aus einer Vorlage abgeholt haben. Die Aktionen zeigt die Toolbar nur der Person, der die Mappe gehört. Wer eine Mappe über ein Zugangsrecht liest, etwa als Betreuer:in, sieht keine davon. Das Bild unter [Die Tabs einer Mappe](#binder_tabs) zeigt die Toolbar einer selbst erstellten Mappe.

* **Metadaten bearbeiten**: Hier ändern Sie "Titel", "Zusammenfassung", "Titelbild (jpg,png,gif)" und "Kategorien" der Mappe. In einer Mappe aus einer Vorlage gibt die Vorlage diese Angaben vor, die Aktion fehlt.
* **Mappe löschen**: OpenOlat legt die Mappe in den Papierkorb. Dort holen Sie sie mit "Wiedererstellen" zurück oder löschen sie mit "Mappe löschen" endgültig: `Persönliches Menü > Portfolio 2.0 > Papierkorb öffnen > Mappe`. Eine Mappe aus einer Vorlage dürfen Sie nur löschen, wenn die Vorlage "Benutzer:innen dürfen Mappe löschen" eingeschaltet hat.
* **Mappe exportieren**: Damit sichern Sie die Mappe oder geben sie ausserhalb von OpenOlat weiter. Das Ausklappmenü bietet drei Formen:
    * "Mappe als CP exportieren" lädt die Mappe als CP (Content Package) herunter.
    * "Mappe als PDF exportieren" lädt die Mappe als PDF-Datei herunter. Die Option erscheint nur, wenn Ihre Administrator:in den [PDF Generator](../../manual_admin/administration/External_Tools_-_Administration.de.md#pdf_generator) eingerichtet hat.
    * "Mappe in eine Seite" öffnet die ganze Mappe als eine Seite in einem neuen Browserfenster, zum Lesen und Drucken.
* **Neuen Bereich erstellen**: Ein Bereich gliedert die Mappe wie ein Kapitel und nimmt die Einträge auf. Die Aktion gibt es nur in selbst erstellten Mappen. In einer Mappe aus einer Vorlage legt die Vorlage die Bereiche fest.
* **Neuen Eintrag erstellen**: Hier schreiben Sie einen neuen Eintrag in einen Bereich der Mappe. Die Aktion erscheint erst, wenn die Mappe mindestens einen Bereich hat. In einer Mappe aus einer Vorlage erscheint sie nur, wenn die Vorlage "Benutzer:innen dürfen neue Einträge erstellen" eingeschaltet hat oder wenn die Mappe den Tab "Vorlagen" zeigt. Diesen Tab gibt es, wenn die Vorlage "Vorlagenordner hinzufügen" eingeschaltet hat und Vorlagen enthält.
* **Eintrag importieren**: Damit übernehmen Sie Einträge, die Sie bereits geschrieben haben, etwa unter [Meine Einträge](My_entries.de.md), in einen Bereich dieser Mappe. Der Assistent "Einträge importieren" führt durch die Auswahl. Die Aktion erscheint erst, wenn die Mappe mindestens einen Bereich hat. In einer Mappe aus einer Vorlage erscheint sie nur, wenn die Vorlage "Benutzer:innen dürfen neue Einträge erstellen" eingeschaltet hat.

Im Tab "Einträge" zeigt die Toolbar nur den Export und die Aktionen für den Inhalt. "Metadaten bearbeiten" und "Mappe löschen" fehlen dort, und "Eintrag importieren" erscheint dort nur in selbst erstellten Mappen.

Dieselbe Toolbar erscheint, wenn Sie die Mappe im Kursbaustein "Portfolioaufgabe" öffnen oder unter [Von mir freigegeben](Shared_by_me.de.md).

Welche Optionen eine Vorlage einschaltet, legen ihre Autor:innen in den Einstellungen der Portfoliovorlage fest, im Formular "Einstellungen zur Portfoliovorlage": `Portfoliovorlage > Administration > Einstellungen > Tab "Einstellungen"`. Mehr dazu unter [Portfoliovorlage: Administration und Bearbeitung](../learningresources/Portfolio_template_Administration_and_editing.de.md).

## Die Tabs einer Mappe {: #binder_tabs}

Eine geöffnete Mappe führt die Tabs "Überblick", "Einträge", "Änderungsprotokoll" und "Freigabe". Mit ihnen wechseln Sie zwischen dem Inhalt der Mappe, ihrem Verlauf und den Zugangsrechten.

![Tabs Überblick, Einträge, Änderungsprotokoll und Freigabe markiert, darüber die Toolbar mit sechs Aktionen; im Inhaltsverzeichnis zeigt jeder Eintrag seinen Status](assets/my_portfolio_binders_tabs_v1_de.png){ class="shadow lightbox" title="Tab Überblick und Toolbar einer Mappe · 2026.10.26" }

* **Überblick**: Das Inhaltsverzeichnis der Mappe zeigt die Bereiche mit ihren Einträgen, jeweils mit Status.
* **Einträge**: Hier stehen die Einträge der Mappe nach Bereichen geordnet, mit dem Zeitstrahl wie unter [Meine Einträge](My_entries.de.md).
* **Änderungsprotokoll**: Hier sind alle Änderungen in chronologischer Reihenfolge aufgelistet, die neueste zuoberst. Im Feld "Änderungen seit" legen Sie fest, ab welchem Datum die Liste beginnt. Über das Glockensymbol rechts oben neben der Überschrift lassen Sie sich über diese Änderungen informieren, statt den Tab selbst zu prüfen: Klicken Sie darauf und schalten Sie im Popup-Fenster "Abonnieren" ein. Gemeldet werden neue Kommentare zu Einträgen mit dem Namen der schreibenden Person sowie neue und geänderte Einträge, Bereiche und Einschätzungen, jeweils nur zu Inhalten, die Sie in der Mappe sehen dürfen. Die Meldungen sammeln sich unter [Abonnements](../personal_menu/Subscriptions.de.md) im persönlichen Menü und gehen je nach Ihrer Einstellung zusätzlich per E-Mail.
* **Freigabe**: Hier sehen Sie, wer mit welchem Recht auf die Mappe, ihre Bereiche und Einträge zugreift. Über "Zugangsrecht hinzufügen" geben Sie Bereiche und Einträge frei. Mehr dazu unter [Sammeln und Bearbeiten](../learningresources/Portfolio_task_and_assignment_Collecting_and_editing.de.md).

![Glockensymbol rechts oben öffnet das Popup-Fenster mit dem Schalter Abonnieren](assets/my_portfolio_binders_history_subscribe_v1_de.png){ class="shadow lightbox" title="Tab Änderungsprotokoll einer Mappe" }

![Button Zugangsrecht hinzufügen rechts oben; im Bereich Bodenkunde hat eine Person das Recht als Gutachter:in (lesen / kommentieren)](assets/my_portfolio_binders_access_control_v1_de.png){ class="shadow lightbox" title="Tab Freigabe einer Mappe · 2026.10.26" }

Zwei weitere Tabs erscheinen abhängig von der Mappe und Ihren Rechten:

* **Vorlagen**, wenn Sie in dieser Mappe eine Aufgabe aus einer Vorlage abholen können.
* **Bewertung**, wenn die Mappe bewertbar ist und Sie die Bewertung einsehen dürfen.

!!! info "Wichtig"

    Die Tabs "Überblick", "Einträge" und "Änderungsprotokoll" kann Ihre [Administrator:in](../../manual_admin/administration/eAssessment_ePortfolio.de.md) ausschalten.
