# Projects - Whiteboard

In the "Projects" area, the free drawing and diagramming tool "draw.io" is used as a whiteboard. It can also be used collaboratively by several project members.


![Whiteboard in the cockpit of a project with a diagram next to the Quick start](assets/project_whiteboard_v1_de.png){ class="shadow lightbox" }


![Drawing area of draw.io with the shape palette on the left and the format panel on the right, opened from the whiteboard of the project](assets/project_drawio_v1_de.png){ class="shadow lightbox" }


The created drawings can also be saved together with the other files of the project: `Whiteboard > 3-dot menu > "Save current version to project files"`.

![Option Save current version to project files in the 3-dot menu of the whiteboard, next to Edit and Reset whiteboard](assets/Whiteboard_speichern.jpg){ class="shadow lightbox" }

With "Reset whiteboard" in the same menu, OpenOlat saves the current version of the whiteboard as a file in the "Files" area and deletes the entire content of the whiteboard.
