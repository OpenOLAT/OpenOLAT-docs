# Data Management - Create or import questions {: #data_management}

If you create questions in the question bank, import them or change their metadata, you will find the instructions on the pages of the question bank. This page takes you from the help in OpenOlat to the right place. How you use the table of your questions, mark questions as favorites and arrange them in lists is described in [Overview of available questions](Question_Bank_Create_Questions.md#question_list).


## Create questions in the question bank

How you create a new question with the button "Create question" is described in [Create questions in the question bank](Question_Bank_Create_Questions.md#create).


## Import questions in the question bank {: #import}

The three import options of the button "Import" are described in [Import options](Question_Bank_Import_Questions.md#import_options). The structure of the template for the Excel import, the rows per question type and how to copy the rows are described in [Usage of the file "Excel Import Template"](Question_Bank_Import_Questions.md#excelimport).


## Change metadata {: #metadata}

How you use the button "Change metadata" to adjust the metadata of the selected questions in one step is described in [Change metadata](Question_bank_possible_operations.md#metadata).
