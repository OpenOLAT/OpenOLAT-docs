# Projects - Decisions


Decisions taken must be comprehensible and therefore documented. OpenOlat provides helpful functions for this purpose.

## Create decisions

To create a new decision within a project, you have the following options:

a) `Projects > Tab "My projects" > Select project > Section "Quick start" > Pulldown next to "Create note" > "Create decision"`

![Entry Create decision in the expanded pulldown next to the button Create note in the Quick start of the cockpit](assets/projekte_entscheid_erstellen_pulldown_v1_de.png){ class="shadow lightbox" }

b) `Projects > Tab "My projects" > Select project > Section "Decisions" > Plus icon`

![Plus icon on the right in the title bar of the section Decisions in the cockpit, below it the button Create decision in the empty section](assets/projekte_entscheid_neu_plus_v1_de.png){ class="shadow lightbox" }

<br>

c) `Projects > Tab "My projects" > Select project > Quick start button "Decisions" > Button "Create decision"`

![Quick start button Decisions in the button bar of the Quick start in the cockpit](assets/projekte_entscheide_neu_schnellzugriff_v1_de.png){ class="shadow lightbox" }

![Button Create decision at the top right of the list of decisions and in the middle of the still empty list](assets/projekte_entscheid_neu_button_v1_de.png){ class="shadow lightbox" }


## Show list of decisions

Once you have selected your project, you can access the decisions of the respective projects from the start screen (cockpit) in various ways.

a) `Projects > Tab "My projects" > Select project > Quick start button "Decisions"`<br>
or<br>
b) `Projects > Tab "My projects" > Select project > Title of the section "Decisions"`<br>
or<br>
c) `Projects > Tab "My projects" > Select project > Section "Decisions" > "Show all decisions"`

![Three marked ways to the list of decisions in the cockpit: Quick start button Decisions, title of the section Decisions and link Show all decisions](assets/projekte_entscheid-liste_anzeigen_v1_de.png){ class="shadow lightbox" }


## Edit decisions

To edit a decision, click in the list of decisions

**a) on the title of the decision**<br>
or<br>
**b) on the 3 dots at the end of a line.**

![List of decisions with the marked title of a decision and the 3-dot menu at the end of the line with the entries Edit decision and Delete](assets/projekte_entscheid_bearbeiten_v1_de.png){ class="shadow lightbox" }


## Link decisions

When editing a decision, you can create links to other objects of this project by linking to an already existing object **(button "Link object")**.

**Difference between "Link object" and "Add link"**<br>
Often, while thinking through a decision, the need arises to create another note, an additional appointment or another to-do.
With the **button "Add link"** you can create these objects and they are then automatically linked to the current decision. The long detour (select a different object type, create a new object, return to the decision and only then create the link) is thus eliminated.


![Buttons Link object and Add link in the section Links of the dialog Edit decision, the pulldown Add link offers appointment, to-do, decision, note, document and file](assets/projekte_entscheid_objektlink1_v1_de.png){ class="shadow lightbox" }

Linked objects can for example be to-dos:

![Dialog Link object with the to-dos of the project to choose from, two to-dos are ticked](assets/projekte_entscheid_objektlink2_v1_de.png){ class="shadow lightbox" }

Links added to a decision can be opened directly.

![Two linked to-dos in the section Links of the dialog Edit decision with the marked icon for opening them directly](assets/projekte_entscheid_objektlink3_v1_de.png){ class="shadow lightbox" }

!!! info "What happens if a linked object is deleted?"

    If a linked object is deleted, the links pointing to this object from other objects are also deleted.


## Members of a decision

In OpenOlat, as well as speaking about members of a course etc., we also talk about members of a decision. This does not necessarily mean the actual decision-makers, but in analogy to the concept of "members" in OpenOlat, all persons who have access to a "decision" object.

!!! info "Important"

    Because of this concept of membership, a member can be added to a decision even after the decision has been made. One can thus rather say that the members of a decision are those who support or are affected by a decision.

    Example:<br>A project sponsor can be added as a member to a decision, even though he is not actively involved in the project implementation and did not actively participate in the decision.


!!! info "Important"

    Only those who are already members of the **project** can be added as members of a **decision**. On the selection list of possible new members of a decision, only persons appear who have already been added in the project members management.


![Expanded section Member in the dialog Edit decision with the selection list Involved, in which the project members are ticked](assets/projekte_entscheid_bearbeiten_mitglied_v1_de.png){ class="shadow lightbox" }


## Metadata of a decision

The metadata of a decision includes the date of creation and the date of last modification.

The **activity log** with further change data becomes visible and can be expanded for the details as soon as the metadata is expanded.

![Expanded sections Metadata with Created and Last modification as well as Activity log with date, activity, original value, new value and person in the dialog Edit decision](assets/projekt_entscheid_metadaten_v1_de.png){ class="shadow lightbox" }



## Delete decisions

To delete a decision, click on the 3 dots at the end of a line and then on "Delete". The decision then only appears under the tab "Deleted". It cannot be restored.

![Entry Delete in the 3-dot menu at the end of the line of a decision in the list of decisions](assets/projekte_entscheid_loeschen_v1_de.png){ class="shadow lightbox" }
