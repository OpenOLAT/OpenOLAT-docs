# Projects - Schedule

![Schedule widget in the cockpit with the next milestone, today's appointments and the next appointments, above it the Quick start buttons](assets/Projekt_Terminplan.png){ class="shadow lightbox" }

The schedule uses the OpenOlat calendar to collect specific appointments for the project and make them visible to everyone. Each appointment can be described in more detail, tagged, and links and members can be assigned to the appointment.

![Dialog Edit appointment with the fields Appointment, Tags, Start, End, Recurrence, Location, Color and Description as well as the sections Links and Member](assets/Projekt_Kalender_Termin_bearbeiten.png){ class="shadow lightbox" }

Both single appointments and recurring appointments, e.g. for regular project meetings, can be created. Special milestones that can be marked as accomplished as soon as they have been completed are also possible.

An appointment or milestone can also be linked to other appointments, decisions, notes or files of the project. This makes certain connections even clearer.

![Appointment details in the calendar with linked to-dos, notes and files as well as the buttons Edit and Delete](assets/Projekt_Kalender_Kombination.png){ class="shadow lightbox" }

!!! info "Important"

    Milestones and appointments from projects are also transferred to the personal calendar.
