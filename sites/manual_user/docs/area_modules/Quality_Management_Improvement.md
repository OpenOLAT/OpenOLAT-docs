# Quality Management: Suggestion for improvement {: #Quality_Management_Improvement}


If the quality management is switched on, OpenOlat users normally see the entry "Quality management" at the top of the main navigation. Participants find **"My surveys"** and **"Suggestions for improvement"** there, quality managers find further options.

![Start page of the quality management from the participants' point of view with only two sections, My surveys and Suggestion for improvement](assets/quality_management_improvement_v1_de.png){ class="lightbox" title="Start page of the quality management for participants" }

!!! note "Note"

    System administrators can also deactivate the option for suggestions for improvement in the system administration. Participants then go directly to "My surveys" when they click on "Quality management" in the main navigation (without an intermediate step).


Calling up "Suggestion for improvement" opens a mail window in which text can be entered freely. System administrators set the recipient address (quality officers) in the system administration:<br>
`Administration > Modules > Quality management`

![Mail form Suggestion for improvement with prefilled sender and recipient quality officers, fields for subject and message, attachment and the option copy to sender](assets/quality_management_improvement_mail_v1_de.png){ class="lightbox" title="Mail form Suggestion for improvement" }
