# Fragenpool: Freigabemöglichkeiten {: #question_bank_sharing_options}

Es gibt verschiedene Möglichkeiten, um im Fragenpool anderen Personen Zugriff auf persönliche Frage-Items zu geben. Dabei können Sie jeweils auch entscheiden, ob die Personen die Fragen nur ansehen oder auch ändern dürfen.

## a) Einzelne Personen zu Mit-Besitzer:innen einer Frage machen {: #co-owners}

Wird die ausgewählte Person (Mit-)Besitzer:in der Frage, erscheint die Frage bei dieser Person ebenfalls unter "Meine Fragen". Ähnlich wie bei den OpenOlat Lernressourcen, haben Mit-Besitzer:innen sämtliche Berechtigungen für diese Frage.

Gehen Sie in den Bereich `Mein Fragenpool > Meine Fragen`, wählen Sie die gewünschten Fragen und wählen Sie über den Button "Autor:innenrechte" die Personen aus, die Sie zu Mit-Besitzer:innen der Frage machen möchten.

[Zum Seitenanfang ^](#question_bank_sharing_options)

## b) Freigabe in einen Pool [:octicons-tag-16:{ title="ab Release 9.0.0 (OO-533)" }](https://track.frentix.com/issue/OO-533){:target="_blank"} {: #sharing_in_a_pool}

Fragen können mit weiteren Personen geteilt werden, indem sie einem oder mehreren existierenden Fragenpools hinzugefügt werden. Welche Fragenpools zur Verfügung stehen und gewählt werden können, legen die Poolverwalter:innen fest. Meist existiert zumindest ein öffentlicher Pool.

Gehen Sie in den Bereich `Mein Fragenpool > Meine Fragen`, wählen Sie die gewünschten Fragen und wählen Sie über `Freigeben > In Pool freigeben` den gewünschten Pool aus. Anschliessend entscheiden Sie, ob die Frage im freigegebenen Pool auch bearbeitet werden darf oder nicht.

## c) Freigabe für eine Gruppe {: #release_for_a_group}

Sie können Fragen auch einer im Vorfeld angelegten [OpenOlat Gruppe](../groups/index.de.md) zugänglich machen. Erstellen Sie beispielsweise eine Gruppe, wenn Sie mit mehreren Personen an einer Sammlung von Fragen für einen Online-Test arbeiten oder eine gemeinsame Fragenbasis entwickeln wollen. Der Vorteil bei diesem Weg ist, dass Sie die Personen individuell zusammenstellen und auch später noch weitere Personen der Gruppe hinzufügen können.

Gehen Sie in den Bereich `Mein Fragenpool > Meine Fragen`, wählen Sie die gewünschten Fragen und wählen Sie über `Freigeben > In Gruppe freigeben` die gewünschte Gruppe aus. Anschliessend entscheiden Sie, ob die Frage in der Gruppe auch bearbeitet werden darf oder nicht.

Freigegebene Fragen werden nur referenziert, nicht kopiert. Alle Berechtigten ändern deshalb dieselbe Frage. Möchten Sie die Ursprungsfrage behalten, kopieren Sie sie vorher.

Für die gemeinsame Arbeit an Fragen eignen sich auch der [Beurteilungsprozess](Question_Bank_Review_Process.de.md) und der Status einer Frage.
