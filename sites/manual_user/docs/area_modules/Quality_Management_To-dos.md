# Quality Management: Actions (To-dos) {: #Quality_Management_To-dos}

## Learn from mistakes

Once the findings have been obtained from the reports, an action must generally be taken if the survey result is poor. In OpenOlat, actions are technically a type of to-do.


## Actions (to-dos) [:octicons-tag-16:{ title="from Release 18.0 (OO-6781)" }](https://track.frentix.com/issue/OO-6781)

To-dos already exist in other places in OpenOlat, e.g. in projects or as personal to-dos.

With the help of the to-do infrastructure, the results of data collections or a specific participant survey can be responded to directly with appropriate actions. Necessary to-dos can be created in context and delegated directly to the persons concerned. They are informed of a new to-do by email.

All to-dos for quality management are listed under "Action to-dos".

![Section Action to-dos with counter and the link Go to action to-dos highlighted, start page of the quality management](assets/quality_management_to-dos_overview1_v1_de.png){ class="shadow lightbox" }



## Actions (to-dos) for quality management in the overview

If the actions (to-dos) are called up in the overview of the quality management, quality management in general is entered as the context of the to-do when a new action is created.


![Buttons Add to-do and Create to-do highlighted, empty list Action to-dos with the filters My to-dos, All, Overdue, Recent, New, Done and Deleted](assets/quality_management_to-dos_overview2_v1_de.png){ class="shadow lightbox" }

## Actions (to-dos) for specific data collections
Actions (to-dos) can also be recorded directly at the data collection. They are then already assigned to this context (this data collection).

![Section Data collections highlighted, start page of the quality management](assets/quality_management_to-dos_data_collection1_v1_de.png){ class="shadow lightbox" }

Click on the name of an existing data collection.

![Title of a data collection in the list of data collections highlighted, on the right the columns Qualitative feedback, Participants and Action to-dos](assets/quality_management_to-dos_data_collection2_v1_de.png){ class="shadow lightbox" }

![Tab Action to-dos of a data collection and button Create to-do highlighted, list without to-dos yet](assets/quality_management_to-dos_data_collection3_v1_de.png){ class="shadow lightbox" }

![Dialog Edit to-do with the prefilled context Data collection and the title of the data collection](assets/quality_management_to-dos_data_collection4_v1_de.png){ class="shadow lightbox" }

The actions (to-dos) that were created for specific data collections also appear in the overview list, which can be called up at the top level of the quality management. The specific context (assignment to a specific data collection) is visible.

Click on the plus or minus symbol at the beginning of a row to expand or collapse the detailed view.

![Minus symbol at the beginning of the row highlighted, which expands the detailed view of the action with status, dates, description and assignment, list Action to-dos with context type and title](assets/quality_management_to-dos_overview4_v1_de.png){ class="shadow lightbox" }
