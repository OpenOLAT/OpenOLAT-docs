# Coaching - Personensuche {: #user_search}

Als Betreuer:in finden Sie über das Suchfeld auf der Einstiegsseite im Coaching jede Person, die Sie betreuen, und öffnen von dort ihre Kurse.

![Markiertes Suchfeld mit dem Platzhalter Wen möchten Sie coachen?, dem Button Suchen und dem Link Suchformular](assets/coaching_user_search1_v3_de.png){ class="shadow lightbox" title="Einstiegsseite Coaching · 2026.10.22" }

Geben Sie einen Namen oder einen Teil davon ein. Mehrere Suchbegriffe trennen Sie mit Leerzeichen oder Komma; eine Person erscheint, wenn alle Begriffe auf sie zutreffen. Der Stern `*` steht für beliebig viele beliebige Zeichen, zum Beispiel `Mei*` für alle Namen, die mit "Mei" beginnen. Der Stern verhält sich gleich wie in der Kurssuche im Coaching [:octicons-tag-16:{ title="ab Release 20.3.7 (OO-9630)" }](https://track.frentix.com/issue/OO-9630){:target="_blank"}.

!!! tip "Tipp"

    Klicken Sie ohne Eingabe eines Namens auf "Suchen", erhalten Sie die Liste aller Personen, die Sie betreuen. Über der Liste grenzen Sie mit den Filtern "Organisationen", "Nicht besucht", "Letzter Besuch" und "Erfolgsstatus" ein; den Filter "Zertifikate" fügen Sie über "Mehr..." hinzu. Den Filter "Organisationen" gibt es nur, wenn Ihre Instanz Organisationen nutzt.


![Gesamtliste der betreuten Personen mit den Filtern Organisationen, Nicht besucht, Letzter Besuch und Erfolgsstatus, nach einer Suche ohne Eingabe](assets/coaching_user_search2_v2_de.png){ class="shadow lightbox" title="Liste Personen im Coaching · 2026.10.22" }

<br>
Den Link "Suchformular" sehen nur Administrator:innen, Lernressourcenverwalter:innen und Principals. Über das Suchformular suchen Sie nach dem Anmeldenamen und weiteren Kontoangaben; auch in seinen Feldern steht der Stern `*` für beliebig viele Zeichen.

![Suchformular mit Feldern von Anmeldename bis Titel, dem Häkchen Nur aktive und dem Button Suchen](assets/coaching_user_search3_v2_de.png){ class="shadow lightbox" title="Suchformular der Personensuche im Coaching · 2026.10.22" }
