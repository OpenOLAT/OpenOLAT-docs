# Coaching - Personensuche {: #user_search}

![Markiertes Suchfeld mit dem Platzhalter Wen würden Sie gerne coachen?, dem Button Suchen und dem Link Suchformular, auf der Einstiegsseite Coaching.](assets/coaching_user_search1_v2_de.png){ class="shadow lightbox" }

Geben Sie einen Namen oder einen Teil davon ein. Mehrere Suchbegriffe trennen Sie mit Leerzeichen oder Komma; eine Person erscheint, wenn alle Begriffe auf sie zutreffen. Der Stern `*` steht für beliebig viele beliebige Zeichen, zum Beispiel `Mei*` für alle Namen, die mit "Mei" beginnen. Der Platzhalter verhält sich gleich wie in der Kurssuche des Coaching Tools [:octicons-tag-16:{ title="ab Release 20.3.7 (OO-9630)" }](https://track.frentix.com/issue/OO-9630){:target="_blank"}.

!!! tip "Tipp"

    Wenn Sie das Lupensymbol ohne Eingabe eines Namens klicken, erhalten Sie die Gesamtliste der von Ihnen betreuten Personen. Sie finden hier viele Filtermöglichkeiten.


![Gesamtliste der betreuten Personen mit den Filtern Organisations, Nicht besucht, Letzter Besuch, Erfolgsstatus und Zertifikate, nach einer Suche ohne Eingabe im Coaching.](assets/coaching_user_search2_v1_de.png){ class="shadow lightbox" }

<br>
Den Link "Suchformular" sehen nur Administrator:innen, Lernressourcenverwalter:innen und Principals. Über das Suchformular suchen Sie nach vielen Einzelmerkmalen; auch in seinen Feldern steht der Stern `*` für beliebig viele Zeichen.

![Suchformular mit Feldern von Anmeldename bis Studienfach und der Checkbox Nur aktive, unter Coaching Personensuche.](assets/coaching_user_search3_v1_de.png){ class="shadow lightbox" }
