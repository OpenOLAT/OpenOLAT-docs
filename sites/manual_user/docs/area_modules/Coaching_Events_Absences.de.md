# Coaching - Termine und Absenzen {: #events}

![Markierter Button Termine / Absenzen unter Aufgaben führt zur kursübergreifenden Termin- und Absenzenverwaltung, auf der Einstiegsseite Coaching.](assets/coaching_events_absences1_v1_de.png){ class="shadow lightbox" }

!!! info "Voraussetzungen"

    Dieses Werkzeug erscheint im Coaching, wenn Administrator:innen das [Modul Termine und Absenzen](../../manual_admin/administration/Modules_Events_and_Absences.de.md) aktiviert haben und in mindestens einem Kurs die [Termin- und Absenzenverwaltung eingeschaltet](../learningresources/Course_Settings_Execution.de.md#config_event_and_absence_management) ist.

Eine Schnellübersicht der anstehenden Termine der laufenden Woche steht bereits auf der Coaching-Übersicht im Widget **Termine** zur Verfügung. Dieses Werkzeug bietet die vollständige Verwaltung mit Cockpit, Absenzen, Meldungen, Rekursen und Personensuche.


## Als Betreuer - Als Klassenlehrer [:octicons-tag-16:{ title="ab Release 14.1 (OO-4216)" }](https://track.frentix.com/issue/OO-4216) {: #tabs_coach-master_coach}

![Markierte Fokus-Buttons Als Betreuer:in und Als Klassenlehrer über der Tab-Leiste, im Werkzeug Termine des Coachings.](assets/coaching_events_absences_events_coach-master_v1_de.png){ class="shadow lightbox" }

Auf oberster Ebene können Sie die Ansicht Ihrer Termine und Absenzen fokussieren auf Ihre Rolle als Betreuer:in oder ggf. als Klassenlehrer:in.

Im [Course Planner](../../manual_user/area_modules/Course_Planner.de.md) besteht die Möglichkeit, einer Person die Rolle Klassenlehrer:in zuzuweisen.
(Voraussetzung: Administrator:innen haben das Modul Course Planner aktiviert.)
Für jede Durchführung kann dies eine andere Person sein. In diesem Fall sind dann im Coaching Tool die Termine und Absenzen Ihrer Klassen angezeigt.

## Tab Cockpit {: #tab_cockpit}

Im Tab Cockpit finden Sie eine Tagesübersicht mit den Abschnitten

* Termine
* Absenzen
* Meldungen

(Je nach vorher getroffenem Fokus für Sie als Betreuer:in oder als Klassenlehrer:in.)<br>
Anstatt des aktuellen Tages kann auch ein anderer Tag ausgewählt werden.

![Tagesübersicht mit Datumswahl, einem Termin mit Zählern und Buchsymbol, darunter die Abschnitte Absenzen und Meldungen mit der Anzeige Alle oder Unentschuldigt, im Tab Cockpit.](assets/coaching_events_absences_tab_events_cockpit_v1_de.png){ class="shadow lightbox" }

Durch Klick auf das **Buchsymbol** in der Zeile eines Termins können Absenzen erfasst werden.

Durch Klick auf das **Symbol mit den 3 Punkten** in der Zeile eines Termins können einzelne Termine als Excel-Datei exportiert, eine Absenzenliste und eine Präsenzliste im PDF-Format heruntergeladen werden.

Über den Kurstitel in der Übersicht gelangen Sie zu den Terminen dieses Kurses und können dort die Absenzenerfassung für einen Tag abschliessen.

## Tab Termine {: #tab_events}

Um den Überblick über viele Termine zu behalten, stehen Ihnen mehrere Filterfunktionen zur Verfügung.

![Zeitraum-Buttons Heute und Bevorstehende, Letzte 3 Monate und Individuell, Filter-Tabs, Filter Durchführung, Dozenten und Absenzen sowie die Terminliste mit Status, im Tab Termine.](assets/coaching_events_absences_tab_events_events_v1_de.png){ class="shadow lightbox" }

Rechts oben über der Liste lassen sich mit dem Zahnrad-Icon die gewünschten Spalten auswählen. Passen Sie die Listenansicht Ihren Bedürfnissen an.

**Beispiele:**

* Durch Klick auf das **Buchsymbol** in der Zeile eines Termins können Absenzen erfasst werden, sofern für die Termine dieses Kurses eine Absenzenerfassung aktiviert wurde.

* Die Spalte mit dem **Stern-Symbol (Asterisk)** zeigt Ihnen, ob eine Anwesenheit verpflichtend geplant wurde oder nicht.

* Durch Klick auf das **Symbol mit den 3 Punkten** in der Zeile eines Termins können einzelne Termine als Excel-Datei exportiert, eine Absenzenliste und eine Präsenzliste im PDF-Format heruntergeladen werden.

Durch Klick auf das Plus-Symbol am Zeilenanfang können Sie die Details dieses Termins aufklappen.

## Tab Absenzen {: #tab_absences}

Das Erfassen von Absenzen kann in den Tabs **Cockpit** oder **Termine** durch Klick auf das **Buchsymbol** in der Zeile eines Termins gemacht werden.

Im Tab Absenzen erhalten Sie dann einen Überblick über die erfassten Absenzen.

* Im Suchfeld können Sie nach Benutzer:innen, Dozent:innen, Kurstiteln und Terminen suchen.
* Schränken Sie den Zeitraum ein, für den Absenzen gesucht werden sollen.
* In einer Vorauswahl können Sie alle oder nur die unentschuldigten Absenzen anzeigen lassen.

![Suchfeld, Datumsbereich und Anzeige Alle oder Unentschuldigt über der Liste der erfassten Absenzen mit Datum, Kurs, Termin, Ort, Abwesend und Entschuldigt, im Tab Absenzen.](assets/coaching_events_absences_tab_absences1_v1_de.png){ class="shadow lightbox" }

Um eine Absenz zu entschuldigen, markieren Sie die betreffende Person. Sobald mindestens eine Person markiert ist, erscheint der Button zum Erfassen einer Entschuldigung über der Liste.

![Button Absenz entschuldigen über der Liste, sobald eine Person markiert ist, im Tab Absenzen.](assets/coaching_events_absences_authorize_v1_de.png){ class="shadow lightbox" }

## Tab Meldungen {: #tab_notices}

Alle Meldungen im Zusammenhang mit Absenz und Dispens sind in diesem Tab gesammelt und können Ihren Bedürfnissen entsprechend gefiltert angezeigt werden.

![Filter Art der Meldung, Entschuldigt und Unentschuldigt, Grund und Datum sowie die Buttons Neue Absenzmeldung erfassen, Neue Dispens erfassen und Abmeldung, im Tab Meldungen.](assets/coaching_events_absences_tab_notices_v1_de.png){ class="shadow lightbox" }

Im **Suchfeld** können Sie nach Benutzer:innen, Dozent:innen, Kurstiteln und Terminen suchen.

Filtern Sie nach **Art der Meldung** ("Ohne Abmeldung", "Abgemeldet", "Dispensiert") oder<br> nach **entschuldigt** und/oder **unentschuldigt**.

Als Filteroption **"Grund"** stehen Ihnen die von Administrator:innen vordefinierten Begriffe zur Auswahl.

Ausserdem finden Sie hier Buttons für

* Neue Absenzmeldung erfassen
* Neue Dispens erfassen
* Abmeldung

## Tab Rekurse {: #tab_appeals}

In diesem Tab verschaffen Sie sich einen Überblick für die Verwaltung aller Rekurse. Der Tab erscheint, wenn Sie die Berechtigung für die Organisation von Rekursen haben. In der Regel bearbeiten Absenzenverwalter:innen die Rekurse in der kursübergreifenden [Absenzenverwaltung](../area_modules/Absence_Management.de.md).<br>

Im **Suchfeld** können Sie nach Benutzer:innen, Betreuer:innen und Terminen suchen.

Filtern Sie die Liste z.B. nach dem **Status** "Pendent", "Abgelehnt" oder "Angenommen". (Sie können wahlweise einen Status, zwei davon oder alle auswählen.)

![Suchfeld, Statusfilter Pendent, Abgelehnt, Angenommen und Datumsbereich über der Rekursliste, im Tab Rekurse.](assets/coaching_events_absences_tab_appeals_v1_de.png){ class="shadow lightbox" }

## Tab Personensuche {: #tab_user_search}

Verwenden Sie für die Personensuche das Suchfeld und die Möglichkeit zum Umschalten der Vorauswahl (Suche nach Kurs, Suche nach Teilnehmer:innen, Suche nach Produkt).

Wenn Sie auf einen der gefundenen Kurse oder ein Produkt klicken, gelangen Sie zur Liste der dort zugeordneten Personen.

![Markierte Umschalter Suche nach Kurs, Suche nach Teilnehmer:innen und Suche nach Produkt sowie das Suchfeld mit drei gefundenen Kursen samt Status und Anzahl Teilnehmer:innen, im Tab Personensuche.](assets/coaching_events_absences_tab_user_search_v1_de.png){ class="shadow lightbox" }
