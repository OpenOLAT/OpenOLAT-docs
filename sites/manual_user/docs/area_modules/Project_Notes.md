# Projects - Notes {: #notes}

In each project, notes can be stored in the "Quick start" section. They are only available within the project. Unlike to-dos, notes can also be downloaded.

![Button Create note in the Quick start and Quick start button Notes in the cockpit of a project, both marked](assets/Notizen_erstellen.jpg){ class="shadow lightbox" }

## Create notes

In addition to creating notes in the "Quick start" section, notes can also be created in the "Notes" area by clicking on the plus sign or directly in the notes area using the "Create note" button.

![Button Create note at the top right of the Notes area of a project, below it two notes in the card view](assets/Projekte_Notizen_erstellen.jpg){ class="shadow lightbox" }


## Show list of notes

Open the list of all notes in the project in the same way as for to-dos or decisions:

a) `Projects > Tab "My projects" > Select project > Quick start button "Notes"`<br>
or<br>
b) `Projects > Tab "My projects" > Select project > Title of the section "Notes"`<br>
or<br>
c) `Projects > Tab "My projects" > Select project > Section "Notes" > "Show all notes"`

Note that you can switch between the card view and the list view.

![Marked toggle buttons for card view and list view at the top right above the notes in the Notes area](assets/projekte_notizen_kartenansicht_v1_de.png){ class="shadow lightbox" }

You will find more options under the 3 dots at the end of each list entry.

![3-dot menu at the end of the line of a note in the list view with the entries Edit note, Open in new window, Download and Delete](assets/projekte_notizen_liste_v1_de.png){ class="shadow lightbox" }

## Quick start to notes

The Quick start section displays the most recently used **files** and **notes** (max. 6, created, modified, viewed, downloaded). They can be opened and edited directly by the creator or members by clicking on them.

![Marked section Quick start in the cockpit with one note and two files with modification date](assets/Notizen_Schnellzugriff.jpg){ class="shadow lightbox" }

## Edit notes

To edit a note, click on the title of the note in the Quick start or in the notes area and activate the edit mode using the slider.

![Marked toggle Edit mode at the top right of an opened note, next to it the hint that changes are saved automatically](assets/Notizen_Bearbeitungsmodus.jpg){ class="shadow lightbox" }

Instead of clicking on the title of a note, you can also go to the 3-dot menu and select "Edit note" there.

![Marked title of a note in the list view and entry Edit note in the 3-dot menu at the end of the line](assets/projekte_notizen_bearbeiten_v1_de.png){ class="shadow lightbox" }

The edit mode must then also be activated.

The notes support CommonMark, an unofficial specification of basic Markdown for formatting text. The syntax is listed on the following overview page: [https://commonmark.org/help/](https://commonmark.org/help/){:target="_blank"}

!!! info "Important"

    Notes are saved automatically.

## Link notes

When you edit a note, you can create links to other objects of this project by linking to an already existing object **(button "Link object")**.

**Difference between "Link object" and "Add link"**<br>
Often, while creating a note, the need arises to create a decision, an appointment or a to-do.
With the **button "Add link"** (in edit mode) you can create these objects and they are then automatically linked to the current note. The long detour (select a different object type, create a new object, return to the note and only then create the link) is thus eliminated.


![Buttons Link object and Add link in the section Links of a note in edit mode, the expanded pulldown Add link offers appointment, to-do, decision, note, document and file](assets/Notizen_Link_hinzufuegen.jpg){ class="shadow lightbox" }

Linked objects can be decisions, appointments, to-dos etc., for example:

![Dialog Link object with the to-dos and decisions of the project to choose from, one to-do is ticked](assets/projekte_notiz_objektlink2_v1_de.png){ class="shadow lightbox" }

Links added to a note can be opened directly via the corresponding icons.

![Section Links of a note with two linked appointments and one decision, the icons for opening them directly are marked](assets/Notizen_Direktlink1.jpg){ class="shadow lightbox" }


!!! info "What happens if a linked object is deleted?"

    If a linked object is deleted, the links pointing to this object from other objects are also deleted.



## Notes for other project members

You create notes for others in OpenOlat by assigning members to the notes in edit mode.

![Expanded section Member of a note in edit mode with the selection list Involved, in which two project members are ticked](assets/Notizen_Mitglieder.jpg){ class="shadow lightbox" }

By assigning members, a note appears for the members concerned, e.g. under "My notes".


## Download notes

The notes are created and displayed in a Markdown editor. This also allows them to be downloaded as files (.md) and used outside OpenOlat with a Markdown editor or viewer.

![Entry Download in the 3-dot menu at the end of the line of a note in the list view](assets/projekte_notizen_herunterladen_v1_de.png){ class="shadow lightbox" }

## Delete notes

Notes can be deleted under the icon with the 3 dots.

![Entry Delete in the 3-dot menu at the end of the line of a note in the list view](assets/projekte_notizen_loeschen_v1_de.png){ class="shadow lightbox" }

![Entry Delete in the 3-dot menu of an opened note](assets/projekte_notizen_loeschen2_v1_de.png){ class="shadow lightbox" }

!!! info "Final deletion"

    In order to ensure later traceability, the notes are not permanently deleted, but can still be viewed under "Deleted". There is also no option available there for final deletion.

    ![Tab Deleted in the Notes area with a deleted note whose 3-dot menu offers no final deletion](assets/projekte_notizen_geloeschte_v1_de.png){ class="shadow lightbox" }
