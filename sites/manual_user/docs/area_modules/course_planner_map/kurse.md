# Embedding courses and course templates {: #courses}

!!! warning "Concept study: possible new presentation"
    This page is part of an experiment exploring how the visual entry point to the Course Planner could look in the future. The content is deliberately abbreviated. The regular manual page [Course Planner](../../Course_Planner/) is authoritative.

Courses are embedded instead of duplicated: existing courses receive the usage "Use in Course Planner", course templates are only instantiated into real courses when needed. Title, reference and dates stay in sync with the element.

## How do I do this?

In the "Content" tab of an implementation, embed a course or a course template via "Add course". In the course itself, set the usage to "Use in Course Planner" or "Template".

## Prerequisites

Course or course template exists as a learning resource and is set to the usage "Use in Course Planner" or "Template".

## Where do I find the setting

`Course Planner > Implementations > "Implementation" > Content tab`; in the course: `Course > Administration > Settings > Share > Usage`

## Connections

Embedded courses have no standalone member management: this runs via the implementation. Course templates are instantiated (copied) per implementation and remain independent of the original afterwards.
