# Copying instead of rebuilding {: #copy}

!!! warning "Concept study: possible new presentation"
    This page is part of an experiment exploring how the visual entry point to the Course Planner could look in the future. The content is deliberately abbreviated. The regular manual page [Course Planner](../../Course_Planner/) is authoritative.

The next implementation is not rebuilt but copied: the copy wizard takes over structure, courses and events and shifts all dates to the new start date.

## How do I do this?

In the list of implementations, select "Copy" via the 3 dots. In the wizard, determine whether course content, events, members and to-dos are copied as well; in step 2, adjust the events and shift all dates together with "Shift all dates".

## Prerequisites

An existing implementation.

## Where do I find the setting

`Course Planner > Implementations > 3 dots > Copy`

## Connections

Creates the next implementation from an existing one. The link to the certification program is taken over, provided the permission for this exists.
