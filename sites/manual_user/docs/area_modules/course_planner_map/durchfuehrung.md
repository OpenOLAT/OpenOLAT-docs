# Planning an implementation {: #implementation}

!!! warning "Concept study: possible new presentation"
    This page is part of an experiment exploring how the visual entry point to the Course Planner could look in the future. The content is deliberately abbreviated. The regular manual page [Course Planner](../../Course_Planner/) is authoritative.

Concrete implementations arise from the product, for example "Program 2026/27". The implementation is the bookable unit: it carries events, members, offer and status and shows at a glance whether it is fully booked or overbooked.

## How do I do this?

Create an implementation for the product (the type, single course or structured, is chosen when creating) and configure it in the tabs (Overview, Structure, Content, Events, Members, Catalog, Settings). Implementation period, location and number of participants under `Settings tab > Implementation`.

## Prerequisites

A product must exist.

## Where do I find the setting

`Course Planner > Implementations` or `Course Planner > Products > "Product" > Implementations`

## Connections

Participants become members of an implementation (not of the product or of individual courses). Each implementation has its own events, course content, members and catalog offers and can be offered several times on different dates.
