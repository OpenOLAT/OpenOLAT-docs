When the program is over, the implementation is finished: the status changes to "Finished", evaluations and certificates have been produced, nothing remains open.

## How do I do this?

Implementations and elements pass through status values (including Preparation, Provisional, Confirmed as well as Finished and Cancelled). Status changes can be triggered manually or via automation rules (trigger "On status change"). A dedicated closing workflow is not specified in the manual.

## Prerequisites

Not specified in the manual.

## Where do I find the setting

Not specified in the manual (the status is shown, among other places, in the implementation widget and in the list of implementations).

## Connections

The status controls automation rules (action on status change) as well as access. Finished or cancelled implementations are sorted to the bottom of the product list.
