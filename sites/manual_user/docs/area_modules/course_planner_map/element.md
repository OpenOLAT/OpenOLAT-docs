Within an implementation, the program is structured: into modules, subjects or classes, nested as required according to the structure rules. In OpenOlat these structural units are called "elements": each one holds together its courses, events, planning tasks, absences and members.

## How do I do this?

In the "Structure" tab of a structured implementation, add an element of the desired element type via "Create". Edit it via the 3 dots or rearrange it in the tree structure with "Move element" (target positions that are not allowed are greyed out).

## Prerequisites

Structured implementation; element types defined in the system administration.

## Where do I find the setting

`Course Planner > Implementations > "Implementation" > Structure tab`

## Connections

Elements structure the implementation hierarchically. Elements "With content" carry courses, pure structural elements do not (comparable to the course element "Structure"). The element type determines the permitted positions in the tree.
