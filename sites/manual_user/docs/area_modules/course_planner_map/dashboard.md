# Cockpit and widgets {: #dashboard}

!!! warning "Concept study: possible new presentation"
    This page is part of an experiment exploring how the visual entry point to the Course Planner could look in the future. The content is deliberately abbreviated. The regular manual page [Course Planner](../../Course_Planner/) is authoritative.

The dashboard is the control center of the Course Planner and accompanies all process steps: pending memberships, upcoming events, offers, implementations, to-dos and reports.

## How do I do this?

When the Course Planner is opened, the dashboard appears with launchers, search and widgets (tiles). Use "Edit overview" to switch to edit mode and arrange, add or remove widgets by drag and drop; configure table widgets via the gear icon.

## Prerequisites

Course Planner activated. Guests do not see the "Edit overview" button.

## Where do I find the setting

Course Planner (start page/dashboard)

## Connections

The widgets (implementations, events, participants, to-dos) bundle key figures and link to the respective areas. A personal configuration overrides the system default, which administrators can define for everyone.
