Whole semesters at once: products, structures and members are imported and exported via Excel, with validation and error report.

## How do I do this?

Start the import wizard via the more-menu (⋮) on the dashboard and upload the Excel file. The wizard checks products, implementations, users and memberships in five steps and shows before execution what will be created, changed or ignored. The export works the same way via the more-menu or as a bulk action.

## Prerequisites

Role course planner or administrator. The Excel file must contain the sheet "Products", mandatory fields filled in, references unique system-wide; organisations, element types and subjects must already exist in the system.

## Where do I find the setting

`Course Planner > Dashboard > more-menu (⋮) > Import` or `Course Planner > Dashboard > more-menu (⋮) > Export`

## Connections

Products and implementations can be created or updated; users and memberships can only be newly created. Rows containing errors are automatically excluded from the import.
