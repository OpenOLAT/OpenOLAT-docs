# Projekte - Notizen {: #notes}

In jedem Projekt können im Abschnitt "Schnellzugriff" Notizen hinterlegt werden. Sie sind nur innerhalb des Projektes verfügbar. Im Unterschied zu To-dos können Notizen auch heruntergeladen werden.

![Button Notiz erstellen im Schnellzugriff und Schnellzugriff-Button Notizen im Cockpit eines Projekts, beide markiert](assets/Notizen_erstellen.jpg){ class="shadow lightbox" }

## Notizen erstellen

Neben dem Erstellen im Abschnitt "Schnellzugriff" können Notizen auch im Bereich "Notizen" mit Klick auf das Pluszeichen oder direkt im Notizbereich mit Hilfe des Buttons "Notiz erstellen" angelegt werden.

![Button Notiz erstellen rechts oben im Bereich Notizen eines Projekts, darunter zwei Notizen in der Kartenansicht](assets/Projekte_Notizen_erstellen.jpg){ class="shadow lightbox" }


## Liste der Notizen anzeigen

Die Liste aller im Projekt vorhandenen Notizen öffnen Sie analog zu den To-dos oder Entscheiden:

a) `Projekte > Tab "Meine Projekte" > Projekt wählen > Schnellzugriff-Button "Notizen"`<br>
oder<br>
b) `Projekte > Tab "Meine Projekte" > Projekt wählen > Titel des Abschnitts "Notizen"`<br>
oder<br>
c) `Projekte > Tab "Meine Projekte" > Projekt wählen > Abschnitt "Notizen" > "Alle Notizen anzeigen"`

Beachten Sie, dass Sie zwischen der Ansicht der Karten und der Listenansicht wechseln können.

![Markierte Umschalt-Buttons für Karten- und Listenansicht rechts oberhalb der Notizen im Bereich Notizen](assets/projekte_notizen_kartenansicht_v1_de.png){ class="shadow lightbox" }

Unter den 3 Punkten am Ende jedes Listeneintrags finden Sie weitere Optionen.

![3-Punkte-Menü am Zeilenende einer Notiz in der Listenansicht mit den Einträgen Notiz bearbeiten, In neuem Fenster öffnen, Herunterladen und Löschen](assets/projekte_notizen_liste_v1_de.png){ class="shadow lightbox" }

## Schnellzugriff auf Notizen

Im Abschnitt Schnellzugriff werden die zuletzt verwendeten **Dateien** und **Notizen** angezeigt (max. 6, erstellt, geändert, angesehen, heruntergeladen). Sie können direkt durch Anklicken vom Ersteller oder Mitgliedern geöffnet und weiterbearbeitet werden.

![Markierter Abschnitt Schnellzugriff im Cockpit mit einer Notiz und zwei Dateien mit Änderungsdatum](assets/Notizen_Schnellzugriff.jpg){ class="shadow lightbox" }

## Notizen bearbeiten

Um eine Notiz zu bearbeiten, klicken Sie beim Schnellzugriff oder im Notizenbereich auf den Titel der Notiz und aktivieren Sie den Bearbeitungsmodus über den Schieberegler.

![Markierter Schalter Bearbeitungsmodus rechts oben in einer geöffneten Notiz, daneben der Hinweis, dass Änderungen automatisch gespeichert werden](assets/Notizen_Bearbeitungsmodus.jpg){ class="shadow lightbox" }

Anstatt auf den Titel einer Notiz zu klicken, können Sie auch über das 3-Punkte-Menü gehen und hier "Notiz bearbeiten" wählen.

![Markierter Titel einer Notiz in der Listenansicht und Eintrag Notiz bearbeiten im 3-Punkte-Menü am Zeilenende](assets/projekte_notizen_bearbeiten_v1_de.png){ class="shadow lightbox" }

Anschliessend muss ebenfalls der Bearbeitungsmodus aktiviert werden.

In den Notizen wird CommonMark unterstützt, eine inoffizielle Spezifikation von grundlegendem Markdown zur Formatierung von Text. Auf der folgenden Übersichtsseite ist die Syntax aufgeführt: [https://commonmark.org/help/](https://commonmark.org/help/){:target="_blank"}

!!! info "Wichtig"

    Notizen werden automatisch gespeichert.

## Notizen verlinken

Wenn Sie eine Notiz bearbeiten, können Sie Links zu anderen Objekten dieses Projekts erstellen, indem Sie zu einem bereits bestehenden Objekt verlinken **(Button "Objekt verlinken")**.

**Unterschied "Objekt verlinken" und "Link hinzufügen"**<br>
Oft taucht während dem Erstellen einer Notiz das Bedürfnis auf, noch einen Entscheid, einen Termin oder ein To-do zu erstellen.
Mit dem **Button "Link hinzufügen"** (im Bearbeitungsmodus) können Sie diese Objekte neu erstellen und sie sind dann automatisch schon mit der aktuellen Notiz verlinkt. Der lange Umweg (anderen Objekttyp wählen, Objekt neu erstellen, Rückkehr zur Notiz und erst dann die Verlinkung vornehmen) entfällt dadurch.


![Buttons Objekt verlinken und Link hinzufügen im Abschnitt Links einer Notiz im Bearbeitungsmodus, das aufgeklappte Pulldown Link hinzufügen bietet Termin, To-do, Entscheid, Notiz, Dokument und Datei](assets/Notizen_Link_hinzufuegen.jpg){ class="shadow lightbox" }

Verlinkte Objekte können z.B. Entscheide, Termine, To-dos usw. sein:

![Dialog Objekt verlinken mit den To-dos und Entscheiden des Projekts zur Auswahl, ein To-do ist angehakt](assets/projekte_notiz_objektlink2_v1_de.png){ class="shadow lightbox" }

Einer Notiz hinzugefügte Links können direkt über die entsprechenden Icons aufgerufen werden.

![Abschnitt Links einer Notiz mit zwei verlinkten Terminen und einem Entscheid, die Symbole zum direkten Öffnen sind markiert](assets/Notizen_Direktlink1.jpg){ class="shadow lightbox" }


!!! info "Was passiert, wenn ein verlinktes Objekt gelöscht wird?"

    Wird ein verlinktes Objekt gelöscht, werden auch die Links gelöscht, die aus anderen Objekten auf dieses Objekt zeigen.



## Notizen für andere Projektmitglieder

Notizen für andere erstellen Sie in OpenOlat, indem Sie den Notizen im Bearbeitungsmodus Mitglieder zuweisen.

![Aufgeklappter Abschnitt Mitglied einer Notiz im Bearbeitungsmodus mit der Auswahlliste Beteiligte, in der zwei Projektmitglieder angehakt sind](assets/Notizen_Mitglieder.jpg){ class="shadow lightbox" }

Durch das Zuordnen von Mitgliedern erscheint eine Notiz bei den betreffenden Mitgliedern z.B. unter "Meine Notizen".


## Notizen herunterladen

Die Notizen werden in einem Markdown-Editor erstellt und angezeigt. Sie können dadurch auch als Dateien (.md) heruntergeladen werden und ausserhalb von OpenOlat mit einem Markdown-Editor oder -Viewer genutzt werden.

![Eintrag Herunterladen im 3-Punkte-Menü am Zeilenende einer Notiz in der Listenansicht](assets/projekte_notizen_herunterladen_v1_de.png){ class="shadow lightbox" }

## Notizen löschen

Gelöscht werden können Notizen jeweils unter dem Icon mit den 3 Punkten.

![Eintrag Löschen im 3-Punkte-Menü am Zeilenende einer Notiz in der Listenansicht](assets/projekte_notizen_loeschen_v1_de.png){ class="shadow lightbox" }

![Eintrag Löschen im 3-Punkte-Menü einer geöffneten Notiz](assets/projekte_notizen_loeschen2_v1_de.png){ class="shadow lightbox" }

!!! info "Endgültiges Löschen"

    Um eine spätere Nachvollziehbarkeit zu gewährleisten, werden die Notizen nicht endgültig gelöscht, sondern sind unter "Gelöschte" weiterhin einsehbar. Es steht dort auch keine Option zum endgültigen Löschen zur Verfügung.

    ![Tab Gelöschte im Bereich Notizen mit einer gelöschten Notiz, deren 3-Punkte-Menü kein endgültiges Löschen anbietet](assets/projekte_notizen_geloeschte_v1_de.png){ class="shadow lightbox" }
