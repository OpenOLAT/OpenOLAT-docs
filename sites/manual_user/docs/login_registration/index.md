# Login and Registration

To use OpenOlat to its full extent, you must be registered in OpenOlat. You can only use OpenOlat anonymously as a guest with very limited possibilities.

Each time you start OpenOlat, the [login page](Login_Page.md) appears, where you log in. You can read more about the different login methods in this chapter.

You can find some information about logout and timeout [here](../basic_concepts/Session_Timeout_and_Logout.md).

## Registration

The kind of the first registration as well as the concrete procedure can vary depending on the
OpenOlat instance:

* In most cases you were already registered as an OpenOlat user by your administrator or user manager before you got access to a specific course.
* But OpenOlat can also be configured so that people can register themselves.

Usually the procedure is visible directly on the corresponding OpenOlat
login page. In the case of uncertainties or queries, please contact
the local OpenOlat support of your organization.

After successful registration, the landing page defined by the system administrators
is displayed. This can differ between systems and also
between OpenOlat authors and users.
