# Login-Seite {: #login}

:octicons-device-camera-video-24: **Video-Einführung**: [Login](<https://www.youtube.com/embed/Sy5cXJL7K90>){:target="_blank"}

Auf der Login-Seite müssen Sie nachweisen, dass Sie eine Zugangsberechtigung zu OpenOlat haben. Sie können aber auch als Gast Zutritt erhalten.
Beachten Sie, dass die genauen Zugangsmöglichkeiten je nach OpenOlat-Instanz etwas variieren können.

Sie finden auf der Login-Seite je nach Konfiguration und Gestaltung

* ein Eingabefeld für den Anmeldenamen
* ein Eingabefeld für das Passwort (aus Sicherheitsgründen meistens in einem zweiten Schritt)
* je nach Sicherheitsstufe (mit oder ohne Passkey) eine Aufforderung zur Bestätigung
* je nach Konfiguration die Eingabe eines [One Time Code](One_Time_Code.de.md) (Bestätigungscode per E-Mail) [:octicons-tag-16:{ title="ab Release 21.0 (OO-9509)" }](https://track.frentix.com/issue/OO-9509)
* den Button "Anmelden" für das OpenOlat-Login
* evtl. verschiedene Buttons von anderen Authentifizierungsdiensten
* den Link "Hier registrieren" zur Selbstregistrierung
* den Button "Gastzugang" für einen Zugang als Gast
* den Button "Entdecken Sie unsere Angebote" zum Aufruf des Katalogs (ohne vorherige Registrierung)
* den Link "Passwort vergessen?", um ein neues Passwort anzufordern
* einen Link zu Ihrem Support (Telefonnummer, Mailadresse)
* den Link "Häufig gestellte Fragen" zu Hilfe-Seiten
* die Sprachauswahl

Oft ist die Login-Seite auch so eingerichtet, dass Sie zuerst Ihre Bildungseinrichtung oder eine Abteilung wählen können. Sie werden dann weitergeleitet und aufgefordert, Ihre Zugangsdaten einzugeben.

Es ist auch möglich, dass Sie nach einer einmaligen Anmeldung in Ihrer Bildungseinrichtung automatisch eine Zutrittsberechtigung zu OpenOlat erhalten haben und ohne weitere Anmeldung direkt Zugang zu OpenOlat erhalten (Single Sign On).

Wenn Sie keinen der angebotenen externen Authentifizierungsdienste nutzen wollen, wählen Sie die direkte Anmeldung mit dem OpenOlat-Konto.

Sollten Sie Ihre Zugangsdaten (Anmeldename und/oder Passwort) nicht mehr zur Hand haben, klicken Sie bitte auf "Passwort vergessen?" oder wenden Sie sich an Ihren zuständigen Support.

Ist Ihr Konto deaktiviert oder noch nicht aktiviert, zeigt OpenOlat nach der Eingabe Ihrer Zugangsdaten die Meldung "Ihr Konto ist deaktiviert." bzw. "Ihr Konto wurde noch nicht aktiviert." mit einem Link zum Support. [:octicons-tag-16:{ title="ab Release 20.0 (OO-8466)" }](https://track.frentix.com/issue/OO-8466)

## Gastzugang {: #guest}

Alternativ können Sie OpenOlat auch als Gast besuchen. Der Gastzugang gewährt Ihnen einen Einblick in OpenOlat mit eingeschränkter Funktionalität: Sie haben nur Zugriff auf Lerninhalte, die ausdrücklich für Gäste freigegeben sind. Um Zugang zu weiteren Lernmaterialien und -aktivitäten zu erhalten, müssen Sie sich bei OpenOlat registrieren. Weitere Informationen zum Gastzugang finden Sie [hier](../basic_concepts/guest_access.de.md).

## Browser {: #browsercheck}

OpenOlat funktioniert optimal mit den folgenden Browsern in einer aktuellen Version (mobil oder Desktop):

* [Apple Safari](https://www.apple.com/safari/)
* [Firefox](https://www.mozilla.org/firefox/)
* [Microsoft Edge](https://www.microsoft.com/edge)
* [Google Chrome](https://www.google.com/chrome/)

## Cookies & Javascript {: #cookies}

Grundsätzlich muss Ihr Browser Session Cookies akzeptieren und Javascript muss aktiviert sein.

## Nach dem Login {: #after_login}

Nach dem Login gelangen Sie entweder

* auf Ihre persönliche Startseite in OpenOlat,
* auf eine Infoseite, eine Seite die in der Regel generelle Informationen zu verschiedenen Themen enthält,
* auf das [OpenOlat Portal](../basic_concepts/Portal_configuration.de.md) oder
* auf eine von Ihnen selbst festgelegte Startseite.


## Nach dem Aufruf des Katalogs {: #webcatalog}

Beim Aufruf des Katalogs auf der Login-Seite wird der [Web-Katalog](../area_modules/catalog2.0_web.de.md) angezeigt, eine gespiegelte Version des Katalogs 2.0, die ohne Registrierung durchsucht werden kann. Erst wenn ein bestimmter Kurs gebucht werden soll, werden Personen ohne Konto durch die Registrierung geführt.
