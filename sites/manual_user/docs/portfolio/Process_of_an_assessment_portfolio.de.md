# Prozess eines Bewertungsportfolios {: #process_of_an_assessment_portfolio}

Ein E-Portfolio lässt sich auf verschiedene Arten nutzen. Diese Seite zeigt als Beispiel den Ablauf eines Lernportfolios mit Aufgaben, Kommentaren und Bewertung. Beteiligt sind Lehrende, die Aufgaben stellen und bewerten, und Lernende, die sie bearbeiten.

Mit dem Kursbaustein "Portfolioaufgabe" stellen Lehrende den Lernenden in einem Kurs eine vorbereitete Mappe bereit. Darin dokumentieren die Lernenden ihren Lernprozess und bearbeiten die bereitgestellten Aufgaben. Die Lernenden holen die Mappe im Kurs ab, bearbeiten sie und geben sie später für Feedback und Bewertung an die Lehrenden frei.

Ein Klick auf einen Prozessschritt öffnet die Seite, die ihn beschreibt.

!!! info "Wichtig"

    Eine Portfoliovorlage lässt sich auch ohne Kurs nutzen: Sie stellen sie den Lernenden als eigenständige Lernressource bereit.

!!! tip "Tipp"

    Besprechen Sie die Bewertungskriterien mit den Lernenden, bevor diese mit der Bearbeitung beginnen.
