# Question types {: #question_types}

For each test question, you choose the question type that suits your form of assessment. OpenOlat scores closed questions automatically. The three types marked with an *, Essay, Upload file and Drawing, you assess manually. The list shows all 16 question types with their purpose and their scoring; a click on the name opens the page of the type.

You choose the question type when you add the question: in the test editor under `Test > Administration > Test editor > Add elements`, in the question bank under `Question bank > My questions > Create question` in the "Type" field. The test editor offers all 16 types also without the question bank; the list follows its order. The page [Configure test questions](../Configure_test_questions.md) describes what applies to all question types, such as score, feedback and preview. The same list is available in the question bank under [Question types](../../area_modules/Question_Bank_Question_Types/index.md).
