# Wissensvermittlung {: #knowledge_transfer}

Mit den Kursbausteinen dieser Gruppe stellen Sie Ihren Teilnehmenden Kursinhalte bereit und strukturieren den Kurs. Je nach Kursbaustein binden Sie auch Inhalte ein, die ausserhalb von OpenOlat erstellt wurden, zum Beispiel Lerninhalte im Format CP oder SCORM oder Videos aus Opencast und Mediasite.

Im Kurseditor finden Sie die Kursbausteine im Dialog "Kursbausteine einfügen" in der Gruppe "Wissensvermittlung":<br>
`Kurs > Administration > Kurseditor > Kursbausteine einfügen`
