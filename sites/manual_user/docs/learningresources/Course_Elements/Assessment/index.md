# Assessment {: #assessment}

With the course elements of this group, you check the level of knowledge of your participants, assess their work and survey them.

In the course editor, you find the course elements in the dialog "Insert course elements" in the group "Assessment":<br>
`Course > Administration > Course editor > Insert course elements`

* [:o_icon_o_gta_icon: Task](../../Course_Element_Task/index.md)
* [:o_icon_o_gta_icon: Group Task](../../Course_Element_Grouptask.md)
* [:o_icon_o_ep_icon: Portfolio Task](../../Course_Element_Portfolio_Task.md)

* [:o_icon_o_icon_form: Form](../../Course_Element_Form.md)
* [:o_icon_o_survey_icon: Survey](../../Course_Element_Survey.md)

* [:o_icon_o_icon_wizard: Multiple checklists](../../Course_Element_Multiple_Checklists.md) (wizard)

The entry "Multiple checklists" is a wizard: it creates several course elements "Checklist" in one go.

In most course elements of this group you can award points. You then set up a [highscore](../index.md#highscore) in the course editor in the tab "HighScore" of the course element. The points of several course elements can be added up, and passing a course can depend on the assessments of different course elements. In conventional courses, that is courses without a learning path, a course element [Structure](../../Course_Element_Structure.md) from the group "Knowledge transfer" combines the points and determines whether a person has passed.

All course elements of this group except Self-test, Practice and Survey have the tab "Reminders"; for Task and Group task in [learning path courses](../../Learning_path_course/index.md) it is called "Reminders & to-dos". There you set up emails that OpenOlat sends depending on the progress of the course element, for example if a task or a test has not been worked on by a certain date. The options are similar to those in the menu "Reminders" of the course: `Course > Administration > Reminders`. More about this: [Course Reminders](../../Course_Reminders.md)

With the course elements "Survey" and "Form", you build OpenOlat [forms](../../Form_Editor/index.md) for surveys and similar purposes into a course.

Which course elements are assessable and where you edit the assessments is shown in the section [Performance assessment](../index.md#performance_assessment) of the overview.
