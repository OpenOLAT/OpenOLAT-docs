# Andere {: #other}

Die Gruppe "Andere" sammelt Kursbausteine, die zu keiner der übrigen Gruppen gehören. Dazu zählen Webseiten, die Sie selbst gestalten oder von ausserhalb einbinden, externe Lernapplikationen über LTI (Learning Tools Interoperability), Linklisten und die Themenvergabe. Mit dem Kursbaustein "Auswahl" bestimmen Teilnehmende selbst, welche Kursbausteine sie bearbeiten.

Im Kurseditor finden Sie die Kursbausteine im Dialog "Kursbausteine einfügen" in der Gruppe "Andere":<br>
`Kurs > Administration > Kurseditor > Kursbausteine einfügen`

* [:o_icon_o_lti_icon: LTI-Seite](../../Course_Element_LTI_Page.de.md)
* [:o_icon_o_sp_icon: HTML-Seite](../../Course_Element_HTML_Page.de.md)
* [:o_icon_o_icon_wizard: Mehrere HTML-Seiten](../../Course_Element_Multiple_HTML_Pages.de.md) (Assistent)
* [:o_icon_o_tu_icon: Externe Seite](../../Course_Element_External_Page.de.md)
* [:o_icon_o_projectbroker_icon: Themenvergabe](../../Course_Element_Topic_Assignment.de.md)
* [:o_icon_o_ll_icon: Linkliste](../../Course_Element_Link_List.de.md)
* [:o_icon_o_icon_cns: Auswahl](../../Course_Element_Selection.de.md)

Der Eintrag "Mehrere HTML-Seiten" ist ein Assistent: Er legt aus Ihren HTML-Dateien in einem Schritt mehrere Kursbausteine "HTML-Seite" samt Gliederung an.

Themen vergeben Sie auch mit dem Kursbaustein "Themenbörse" aus der Gruppe [Verwaltung und Organisation](../Administration_and_Organisation/index.de.md). Dort wählen die Teilnehmenden mehrere Themen mit Priorität, und OpenOlat teilt die Themen zu.
