# Other {: #other}

The group "Other" collects course elements that do not belong to any of the other groups. These include web pages that you design yourself or integrate from outside, external learning applications via LTI (Learning Tools Interoperability), link lists and the topic assignment. With the course element "Selection", participants decide themselves which course elements they work on.

In the course editor, you find the course elements in the dialog "Insert course elements" in the group "Other":<br>
`Course > Administration > Course editor > Insert course elements`

* [:o_icon_o_lti_icon: LTI Page](../../Course_Element_LTI_Page.md)
* [:o_icon_o_sp_icon: HTML page](../../Course_Element_HTML_Page.md)
* [:o_icon_o_icon_wizard: Multiple HTML pages](../../Course_Element_Multiple_HTML_Pages.md) (wizard)
* [:o_icon_o_tu_icon: External page](../../Course_Element_External_Page.md)
* [:o_icon_o_projectbroker_icon: Topic Assignment](../../Course_Element_Topic_Assignment.md)
* [:o_icon_o_ll_icon: Link list](../../Course_Element_Link_List.md)
* [:o_icon_o_icon_cns: Selection](../../Course_Element_Selection.md)

The entry "Multiple HTML pages" is a wizard: in one step, it creates several course elements "HTML page" from your HTML files, including their structure.

You also assign topics with the course element "Topic broker" from the group [Administration and Organisation](../Administration_and_Organisation/index.md). There, the participants choose several topics with a priority, and OpenOlat assigns the topics.
