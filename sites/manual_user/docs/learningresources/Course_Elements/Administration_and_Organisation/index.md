# Administration and Organisation {: #administration_and_organisation}

With the course elements of this group, you handle organisational matters in the course: enrolment in groups, the assignment of topics and appointments as well as information and emails to the participants.

In the course editor, you find the course elements in the dialog "Insert course elements" in the group "Administration and Organisation":<br>
`Course > Administration > Course editor > Insert course elements`

* [:o_icon_o_en_icon: Enrolment](../../Course_Element_Enrolment.md)
* [:o_icon_o_infomsg_icon: Info messages](../../Course_Element_Notifications.md)
* [:o_icon_o_co_icon: E-Mail](../../Course_Element_EMail.md)
* [:o_icon_o_icon_topicbroker: Topic Broker](../../Course_Element_Topic_Broker.md)
* [:o_icon_o_cal_icon: Calendar](../../Course_Element_Calendar.md)
* [:o_icon_o_appointment_icon: Appointment scheduling](../../Course_Element_Appointment_Scheduling.md)

In the topic broker, the participants choose several topics with a priority, and OpenOlat assigns the topics based on these wishes. You find the course element "Topic assignment" in the group [Other](../Other/index.md).
