# Detailansicht einer Lernressource {: #detailed_view}

Eine Lernressource besteht aus verschiedenen Bereichen. Auch wenn sich die Lernressourcen bezüglich Aufbau und Struktur unterscheiden, verfügen alle über eine Toolbar.

## Toolbar von Lernressourcen

Über die Toolbar ist ein Zugriff auf die "Infoseite" der Lernressource möglich (bei Kursen "Kursinfo"). Besitzer:innen der Lernressource sehen ihre Rolle (z.B. Besitzer:in) und können über die Toolbar die Menüs der Administration der Lernressource aufrufen. Auch der Status der Lernressource (z.B. "Veröffentlicht") wird in der Toolbar angezeigt und kann hier von Besitzer:innen geändert werden. Zudem lässt sich ein Bookmark auf die Lernressource setzen.

Je nach Lernressource können sich auch weitere Elemente in der Toolbar befinden. Was sich genau in der Toolbar befindet und sichtbar ist, hängt ab von:

- dem Typ der Lernressource
- der Rolle, in der man auf die Lernressource schaut
- ob man sich im Bearbeitungs- oder Ansichtsmodus befindet
- der konkreten Konfiguration (siehe Einstellungen)

## Administration von Lernressourcen

Im Menü "Administration" einer Lernressource können weitere Untermenüs für die Konfiguration aufgerufen werden.

Alle Lernressourcen verfügen über die Menüs:

* Einstellungen
* Mitgliederverwaltung
* Kopieren
* Inhalt exportieren
* Löschen

Je nach Lernressource kommen weitere Menüs hinzu.

In den **Einstellungen** werden generelle Informationen zur Lernressource hinterlegt, Metadaten konfiguriert, die Freigabe eingerichtet, ein Katalogeintrag definiert und weitere lernressourcenspezifische Einstellungen vorgenommen. Weitere Informationen zu den einzelnen Einstellungen mit Blick auf Kurse finden Sie unter [Kurseinstellungen](../learningresources/Course_Settings.de.md).

In der **Mitgliederverwaltung** können weitere Besitzer:innen der Lernressource hinzugefügt werden. Bei Lernressourcen mit dem Verwendungszweck "Eigenständig" können zusätzlich Betreuer:innen und Teilnehmer:innen hinzugefügt werden, siehe [Funktionskonzept Kurse und Lernressourcen](General_Functions_Concept.de.md) [:octicons-tag-16:{ title="ab Release 18.2 (OO-7277)" }](https://track.frentix.com/issue/OO-7277){:target="_blank"}.

**Kopieren** erstellt eine Kopie der Lernressource. Die so angelegte neue Lernressource erscheint anschliessend ebenfalls im Autorenbereich.

**Inhalt exportieren** ermöglicht einen Download der Lernressource, z.B. als Backup-Datei (ZIP-Datei). Diese Datei kann später wieder in OpenOlat importiert werden. Auf diese Weise können Lernressourcen auch in andere OpenOlat-Instanzen übertragen werden.

**Löschen** führt dazu, dass die Lernressource als "gelöscht" markiert wird. Sie erscheint dann im Autorenbereich im Tab "Gelöscht" (Papierkorb-Funktion). Solange sich die Lernressource noch im Papierkorb befindet, kann sie wiederhergestellt oder auch dauerhaft gelöscht werden.
