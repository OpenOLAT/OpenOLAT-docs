# Formular in der Portfolio 2.0 Vorlage {: #eportfolio_template_forms}

Mit einem Formular in der Lernressource "[Portfolio 2.0 Vorlage](Portfolio_template_Creation.de.md)" reflektieren Teilnehmende ihre Arbeit, schätzen ihre eigenen Leistungen ein oder beantworten einen Fragebogen.

Dafür brauchen Sie eine Portfolio 2.0 Vorlage. Wählen oder erstellen Sie darin einen "Bereich" und wählen Sie "Neue Aufgabe". Wie Sie eine Portfolio 2.0 Vorlage bearbeiten, beschreibt die Seite [Portfoliovorlage: Administration und Bearbeitung](../learningresources/Portfolio_template_Administration_and_editing.de.md).

![Bereich mit dem Button Neue Aufgabe unter Neue Aufgabe erstellen](assets/Formular_eportfolio.png){ class="shadow lightbox" title="Tab Einträge einer Portfoliomappe" }

Für ein Formular in einer Portfolio-Aufgabe wählen Sie unter "Typ" den Eintrag "Formular". Mit dem Button "Formular auswählen" wählen Sie danach ein vorbereitetes Formular oder erstellen ein neues.

![Aufgabe vom Typ Formular mit Formularauswahl und Art der Einschätzung](assets/portfolio_Aufgabe1.png){ class="shadow lightbox" title="Dialog Neue Aufgabe" }

Haben Sie noch kein Formular, legen Sie im Dialog "Formular auswählen" mit dem Button "Erstellen" eine neue Lernressource "Formular" an. Ein Formular aus einer Datei laden Sie mit dem Button "Datei importieren". OpenOlat übernimmt das neue oder importierte Formular direkt in die Portfolio-Aufgabe.

Ein Formular, das Sie hier erstellen, ist eine eigene Lernressource "Formular". Sie finden es im [Autorenbereich](../area_modules/Authoring/index.de.md) unter "Meine Einträge" und können es in weiteren Portfolio-Aufgaben, Kursen und Kursbausteinen einbinden.

Ein neu erstelltes Formular enthält noch keine Elemente. Diese fügen Sie direkt in der Lernressource im [Formulareditor](Form_Editor/index.de.md) hinzu. Öffnen Sie dazu das Formular im Autorenbereich und danach:<br>
`Formular > Administration > Formulareditor`

**Weitere Einstellungen:**

Unter "Einschätzung" legen Sie fest, wer das Formular ausfüllt: "Nur Selbsteinschätzung" oder "Selbsteinschätzung und Fremdeinschätzung", bei der eingeladene Personen das Formular ebenfalls ausfüllen. Wie die Teilnehmenden Personen zu ihrer Mappe einladen, beschreibt die Seite [Rollen und Rechte: Rollen zuweisen](../basic_concepts/Assign_Roles.de.md#role_assignment_invitee). Bei "Selbsteinschätzung und Fremdeinschätzung" stehen zwei weitere Optionen zur Wahl: Mit "Selbsteinschätzung an eingeladenen Benutzer:innen anzeigen" sehen die eingeladenen Personen auch die Selbsteinschätzung. Mit "Anonyme Fremdeinschätzung" bleibt die Fremdeinschätzung anonym.

Unter "Dokument" hängen Sie der Aufgabe bei Bedarf eine Datei an.

Über den Kursbaustein "[Portfolioaufgabe](../learningresources/Creating_Portfolio_Tasks.de.md)" binden Sie die Portfolio 2.0 Vorlage in einen Kurs ein.
