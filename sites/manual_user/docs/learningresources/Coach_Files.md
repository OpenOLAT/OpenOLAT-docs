# Coach files {: #coach_files}

A shared folder can be set up for coaches to store files. The folder is opened by coaches and owners of the course, as well as by persons with the "Course editor" right.

![Administration menu of a course with the entry "Coach files" highlighted, used to open the coach folder](assets/course_coach_files_v1_de.png){ class="shadow lightbox" title="Administration menu of a course" }

So that the entry "Coach files" appears in the "Administration" menu of the course, owners of the course first switch on the option "Coach files folder" under `Course > Administration > Settings > Tab "Options"`.

There, under "File destination", they choose where the folder is located: "Automatically generated folder" creates a new folder in the [storage folder](Storage_folder.md) of the course, "Choose folder from course storage" uses an existing folder. In both cases, coaches only open this folder via the menu entry, not the other files of the storage folder.

Owners of the course and persons with access to the course editor see the entire storage folder. With the automatically generated folder, they find the coaches' files there in the folder "_coachdocuments". They can link these files in course elements, for example in a single page. Coaches cannot do this via this folder.
