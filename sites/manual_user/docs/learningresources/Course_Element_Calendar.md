# Course Element "Calendar"  {: #cal}

## Profile

Name | Calendar
---------|----------
Icon | :o_icon_o_cal_icon:
Available since | Release 7.1 or earlier
Functional group | Administration and organisation
Purpose | Embedding the course calendar into the course structure (course menu)
Assessable | no
Specialty / Note |



With the course element "Calendar" you show the [course calendar](Course_Settings_Toolbar.md#calendar) directly in the course structure, for example at the place where the participants find the materials of a week. You can also insert the course element several times. Every course element "Calendar" shows the same course calendar.

The course element is an alternative to the calendar in the toolbar of the course, see [Toolbar](Course_Settings_Toolbar.md#calendar).

By default, the owners and the coaches of the course create and edit events. All participants read the events. You define the rights and the date displayed in the course editor:<br>
`Course > Administration > Course editor > Select course element > Tab "Calendar configuration"`

Under "Edit events" you define whether coaches and participants may create and edit events in addition to the owners. Under "Date displayed" you choose between "Current date" and "Select fixed date": the calendar then opens at today's date or at the date you set. The members of the course automatically also see the course calendar in their [personal calendar](../personal_menu/Calendar.md).

The setting "Edit events" applies to this course element. For the calendar that the course members open from the toolbar, the option "Coaches can edit the calendar" in the course settings in the "Toolbar" tab determines whether coaches edit events there. Both ways show the same events, and you set the rights for each way. [:octicons-tag-16:{ title="from Release 21.2 (OO-9968)" }](https://track.frentix.com/issue/OO-9968)

If the calendar shows a fixed semester week and the events contain links to course elements, it serves as an overview of the events and tasks of that week.

In many courses, especially in [learning path courses](Learning_path_course/index.md), the calendar in the toolbar is the simpler choice. You switch it on with the checkbox "Course calendar":<br>
`Course > Administration > Settings > Tab "Toolbar"`<br>
[More about the calendar in the toolbar >](Course_Settings_Toolbar.md#calendar)

!!! info "Important"

    The course editor offers the course element "Calendar" if system administrators have switched it on in the system administration: `Administration > Core functions > Calendar`, checkbox "Enable course element". If the course element is missing for you, contact your organisation.
