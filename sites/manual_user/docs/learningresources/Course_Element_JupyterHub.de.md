# Kursbaustein "JupyterHub" {: #jupyterhub}


## Steckbrief

Name | JupyterHub
---------|----------
Icon | ![JupyterHub Icon](assets/course_element_jupyterhub_icon.png){ class=size24 }
Verfügbar seit | Release 18
Funktionsgruppe | Wissensvermittlung
Verwendungszweck | Bereitstellung von Jupyter-Images
Bewertbar | nein
Spezialität / Hinweis | Beta-Version


Der Kursbaustein dient der Bereitstellung von Jupyter-Images für Lernende und bietet somit Gelegenheit für zusätzliche sowie sehr spezifische Arten von Aufgabenstellungen.

Weitere Informationen finden Sie auf [Jupyter.org](https://jupyter.org/hub).

## Kursbaustein konfigurieren

Im Kurseditor legen Sie im Tab «JupyterHub Konfiguration» im Feld **Hub** fest, welcher Hub verwendet wird. Zur Auswahl stehen nur aktive Hubs [:octicons-tag-16:{ title="ab Release 21.0 (OO-9565)" }](https://track.frentix.com/issue/OO-9565){:target="_blank"}. Ist der bei einem bestehenden Kursbaustein hinterlegte Hub inzwischen inaktiv, bleibt er ausgewählt, wird aber mit einer Warnung angezeigt, dass er nicht mehr funktioniert.
