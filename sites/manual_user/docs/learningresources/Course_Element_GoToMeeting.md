# Course Element "GoToMeeting" {: #gotomeeting}


## Profile

Name | GoToMeeting
---------|----------
Icon | :o_icon_o_gotomeeting_icon:
Available since | Release 10.5 (OO-1944)
Functional group | Communication and collaboration
Purpose | Integration of the GoToMeeting web conferencing software
Assessable | no
Specialty / Note | GoToMeeting is commercial software. To use the course element, a separate license and server hosting is required.

## Configuration in the course editor {: #editor_config}

No specific tab

## Configuration in the course run (closed editor) {: #closed_editor_config}

A new meeting can be created in the "Configuration" area:<br>
`Course > Course element "GoToMeeting" > Configuration > Add new training`

![Required fields Organizers, Name, Start training and End, plus Description and the "I have an account" button](assets/Gotomeeting_EN.png){ class="shadow lightbox" title="Add new training dialog" }

!!! info "Access to the meeting room"

    In the "Trainings" area you get access to the meeting room.
