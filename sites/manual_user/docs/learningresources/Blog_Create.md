# Create a blog {: #blog_create}

For a blog in the course, there are two kinds of creating: you set up a new blog and embed it in the course, or you write an entry (blog post) in an existing blog. The list separates the two and the two actions that follow an entry. For each, it states who carries it out and which page describes the steps.

* **Create blog:** A blog in the course consists of two parts. The learning resource "Blog" contains the entries, the course element "Blog" shows them as an item in the course menu. As an [owner](../basic_concepts/Roles/index.md#owner) of the course, you insert the course element in the course editor and there select an existing blog learning resource or create a new one. A blog learning resource contains either its own entries, or it embeds an external blog with "Embed via URL" through the address of its feed, that is the address at which the external blog provides its entries. The entries of an external blog are created there, not in OpenOlat. If the whole course is to reach the blog via an icon in the toolbar, the bar with the course tools at the top of the course, select the blog learning resource in the toolbar settings instead, see [Toolbar](Course_Settings_Toolbar.md#blog). The guide [How do I create a blog?](../../manual_how-to/blog/blog.md) shows the steps, the page [Configure a blog in the course element](Blog_Configuration.md) the settings in the course.

* **Create entry:** In an existing blog, you write an entry with the "Add entry" button. Who may do this is defined by the user right "Create items" in the course element, see [Configure a blog in the course element](Blog_Configuration.md#create_entries). In a new course element, it is switched on for [coaches](../basic_concepts/Roles/index.md#coach) and participants, owners of the course and moderators always write. This way the participants run the blog together. So that the others have something to comment on, it is best if you write the first entries yourself as an owner or coach, for example initial questions. In the toolbar blog, only owners and coaches of the course ever write, the other course members read the entries and comment on and rate them if the learning resource allows this. See [Blogging, Add and edit entries](Blog_Blogging.md#blog_blogging_add_posts).

* **Comment on entry:** If the option "Posts are commentable" is switched on in the blog learning resource under `Blog > Administration > Settings > Tab "Options"`, all persons who open the blog, except [guests](../basic_concepts/guest_access.md), comment on the entries and read the comments of the others. This option is set by the owners of the blog learning resource, see [Blog: Administration](Blog_Administration.md#tab_options). How this works is shown in [Blogging, Comment on entries](Blog_Blogging.md#blog_blogging_comment_posts).

* **Rate entry:** If the option "Posts are rateable" is switched on in the same tab, all persons who open the blog, except guests, rate the entries with 1 to 5 stars and see the ratings of the others, see [Blogging, Rate entries](Blog_Blogging.md#blog_blogging_assess_posts).
