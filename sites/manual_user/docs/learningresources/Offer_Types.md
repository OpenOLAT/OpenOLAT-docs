# Offer types {: #offer_types}


Whoever offers a course or another learning resource through an offer in the catalog wants to know who booked it. OpenOlat lists every booking through an offer as a booking order. The menu item "Offer types" of the administration shows the booking orders of the learning resource, each with its status:<br>
`Course > Administration > Offer types`

Despite its name, the menu item does not list the offer types but the booking orders. The column "Offer type" shows through which offer type a booking came in. Which offer types exist and where they are available is described in [Offer concepts: Offer types](../basic_concepts/Offer_Concepts.md#offer_types).

The administration of other learning resources shows the same menu item, for example of the learning resources "CP learning content", "SCORM 1.2", "Video" and "Podcast".

## When does the menu item appear? {: #menu_visibility}

The menu item "Offer types" appears as soon as two conditions are met:

* In the tab "Share", "Access for participants" is set to "Bookable and open offers".
* The learning resource has an offer with booking, for example "Freely available", "Access code" or "PayPal Checkout". The menu item then appears even before the first booking. Offers "Without booking" and "Guest" create no booking orders and therefore do not make the menu item appear.

The menu item can be opened by owners of the learning resource, learning resource managers and administrators, see [Roles and Rights](../basic_concepts/Roles/index.md).

You create the offers of a course under:<br>
`Course > Administration > Settings > Tab "Share" > Section "Offer" > Button "Add offer"`
