# Speichern (eines Kurses) als Template {: #course_copy_template}

Soll ein Template aus einem bereits bestehenden Kurs erstellt werden, wählen Sie im entsprechenden Kurs `Kurs > Administration > Als Template speichern`. Der existierende Kurs (unabhängig vom technischen Typ) wird damit auf eine Art kopiert, die ein Template für die Instanziierung daraus erstellt.
