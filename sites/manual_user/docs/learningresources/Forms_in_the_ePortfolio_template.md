# Form in the Portfolio 2.0 template {: #eportfolio_template_forms}

With a form in the learning resource "[Portfolio 2.0 Template](Portfolio_template_Creation.md)", participants reflect on their work, assess their own achievements or answer a questionnaire.

For this, you need a Portfolio 2.0 template. Select or create a "Section" in it and select "New assignment". How you edit a Portfolio 2.0 template is described on the page [Portfolio template: Administration and editing](../learningresources/Portfolio_template_Administration_and_editing.md).

![Section with the button New assignment under Create new assignment](assets/Formular_eportfolio.png){ class="shadow lightbox" title="Tab Entries of a portfolio binder" }

For a form in a portfolio assignment, select the entry "Form" under "Type". With the button "Select a form", you then select a prepared form or create a new one.

![Assignment of type Form with form selection and evaluation mode](assets/portfolio_Aufgabe1.png){ class="shadow lightbox" title="Dialog New assignment" }

If you do not have a form yet, you create a new "Form" learning resource with the button "Create" in the "Select a form" dialog. You load a form from a file with the button "Import file". OpenOlat adds the new or imported form directly to the portfolio assignment.

A form that you create here is a learning resource "Form" of its own. You find it in the [Authoring Area](../area_modules/Authoring/index.md) under "My entries" and can include it in further portfolio assignments, courses and course elements.

A newly created form does not yet contain any elements. You add them directly in the learning resource in the [form editor](Form_Editor/index.md). To do so, open the form in the Authoring Area and then:<br>
`Form > Administration > Form editor`

**Additional settings:**

Under "Evaluation", you set who fills in the form: "Only self evaluation" or "Self and external evaluation", in which invited people also fill in the form. How participants invite people to their binder is described on the page [Roles and Rights: Assign roles](../basic_concepts/Assign_Roles.md#role_assignment_invitee). With "Self and external evaluation", two further options are available: With "Invitee can see self evaluation", the invited people also see the self evaluation. With "Anonymous external evaluation", the external evaluation stays anonymous.

Under "Document", you attach a file to the assignment if needed.

Via the course element "[Portfolio task](../learningresources/Creating_Portfolio_Tasks.md)", you include the Portfolio 2.0 template in a course.
