# Various Types of Learning Resources {: #learning_resources}

In OpenOlat, you create courses, tests, wikis, forms and other content as [learning resources](General_Functions_Concept.md) in the [authoring area](../area_modules/Authoring/index.md). You embed most learning resources in a course via a [course element](Course_Elements/index.md), the glossary and the resource folder via the course settings. You create many types directly in the "Create" menu of the authoring area, and you upload [further learning resources](#further_learningresources) via "Import file".

The sections on the individual types show the icon of the type below the title. The learning resource appears with the same icon in the "Type" column of the authoring area. If you point to the icon with the mouse, OpenOlat shows the name of the type.

## Course {: #course}

![Entry Course with the cube icon highlighted](assets/learning_resource_course_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_CourseModule_icon:

An OpenOlat course serves as an online-only course or accompanies lectures, seminars and other face-to-face events. It combines any number of course elements in a structure. This way, you implement different didactic concepts, for example webquests, group puzzles, cooperative online seminars, problem-based learning or game-based approaches.

You find the profile and the course cycle from creation to deletion on the page [General Information](General_Information/index.md) about the course. How to create courses is explained in the chapter ["Creating Courses"](Creating_Course.md). Details on course elements and the course editor can be found in the chapter ["Course elements at a glance"](Course_Elements/index.md).

If you or your organisation have prepared templates, you can create a new course directly from one of them: with the entry "Course from template" in the "Create" menu. A template is a course with the usage "Template". A wizard guides you through two steps: in the step "Template" you select the template, in the step "Settings" you give the new course a title, a reference and an execution period, among other things. OpenOlat creates the course as a copy, the template itself remains unchanged. Available are the templates you own or manage and templates that are released to authors for copying. More about the usage "Template" can be found in the chapter ["Creating Courses"](Creating_Course.md#purpose). ## Test {: #test}

![Entry Test with the pen icon highlighted](assets/learning_resource_test_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_FileResource-IMSQTI21_icon:

You use tests for examinations and for practice. In the course element "Test", owners and coaches see the results of the participants; in the course element "Self-test", OpenOlat saves all entries anonymously. Each test is available in the standardized format IMS QTI 2.1.

More information on using and creating tests can be found in the chapter ["Creating Tests"](Test/index.md).

## CP Learning Content {: #cp-content}

![Entry CP learning content with the archive icon highlighted](assets/learning_resource_cp-content_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_FileResource-IMSCP_icon:

A Content Packaging (abbr.: CP) is learning content in a standardized e-learning format. As with tests, the specification of this data format comes from [IMS resp. 1EdTech Consortium](http://www.imsglobal.org/ "IMS resp. 1EdTech Consortium"). OpenOlat supports the IMS CP version 1.1.2. You use CP learning content in OpenOlat courses and also in other LMS (learning management systems). You embed it in a course with the course element "CP learning content". How to create CP learning content is described in the chapter ["Create CP learning content"](../learningresources/CP_Editor.md).

In the authoring area, OpenOlat shows CP learning content with the icon of an archive. [SCORM learning content](#scorm) has the same icon. The name tells you which of the two types it is: if you point to the icon in the "Type" column with the mouse, OpenOlat shows "CP learning content" or "SCORM 1.2".

## Podcast {: #podcast}

![Entry Podcast with the podcast icon highlighted](assets/learning_resource_podcast_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_FileResource-PODCAST_icon:

In a podcast, you provide audio and video files as episodes in OpenOlat. Participants listen to or watch the episodes directly in OpenOlat or subscribe to the podcast via services such as iTunes and load the episodes onto mobile devices. If ratings and comments are switched on, participants rate and comment on the episodes. You embed a podcast in a course with the course element "Podcast".

Further information on podcasts can be found in the chapter ["Podcast: Overview"](Podcast/index.md).

## Blog {: #blog}

![Entry Blog with the blog icon highlighted](assets/learning_resource_blog_v2_en.png){ width="203" class="aside-right lightbox" title="Create menu in the authoring area · 2026.10.27" }

:o_icon_o_FileResource-BLOG_icon:

In a blog, you publish subject-related or personal information in chronological order, for example as an online diary or online journal. If ratings and comments are switched on, participants rate and comment on the entries.

In the authoring area, in the course menu and in the toolbar, the blog has its own blog icon. The megaphone icon belongs to the [info messages](Course_Element_Notifications.md).

## Resource Folder {: #resource_folder}

![Entry Resource folder with the open folder icon highlighted](assets/learning_resource_resource_folder_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_FileResource-SHAREDFOLDER_icon:

With a resource folder, you use the same files, for example content, information or graphics, in several courses without creating them several times. In the linked course, the resource folder appears in the [storage folder](Storage_folder.md) of the course as the subfolder `_sharedfolder` with all its files. If you change a file in the resource folder, the change applies in all linked courses. You embed a resource folder in the course settings, one per course:<br>
`Course > Administration > Settings > Tab "Options"`

The page [Course Settings - Tab Options](Course_Settings_Options.md) describes the details, the page [Resource folder](Resource_Folder.md) the profile.

## Glossary {: #glossary}

![Entry Glossary with the graduation cap icon highlighted](assets/learning_resource_glossary_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

:o_icon_o_FileResource-GLOSSARY_icon:

In a glossary, you collect terms with their definitions, sorted alphabetically. If the glossary is embedded in a course, OpenOlat shows the definition of a term directly in the learning content, for example in the course elements "Page" and "HTML page". Glossaries can be configured so that participants can also add terms.

You embed a glossary in the course settings in two steps. First select it with "Select glossary":<br>
`Course > Administration > Settings > Tab "Options"`<br>
Then switch on the "Glossary" checkbox so that it appears in the toolbar of the course:<br>
`Course > Administration > Settings > Tab "Toolbar"`

You find the profile on the page [Glossary](Glossary/index.md). Further information on the [creation](../learningresources/Glossary_create.md) and [usage](../learningresources/Glossary_usage.md) of glossaries can be found in the corresponding chapters.

## Further learning resources {: #further_learningresources}

You usually bring the following learning resources into OpenOlat via "Import file" in the authoring area.


### SCORM 1.2 {: #scorm}

:o_icon_o_FileResource-SCORMCP_icon:

OpenOlat supports the standardized e-learning format SCORM in version 1.2. SCORM stands for "Sharable Content Object Reference Model" and is a reference model for exchangeable electronic learning content of the ["Advanced Distributed Learning Initiative" (ADL)](http://www.adlnet.gov/). You use SCORM learning content in OpenOlat courses and also in other LMS.

You bring SCORM learning content into OpenOlat as a package via "Import file" and embed it in a course with the course element "SCORM 1.2". In the authoring area, it has the same icon as [CP learning content](#cp-content).

### Learning resources of the type file and other files

![Entries Word, Excel and PowerPoint with their file icons highlighted at the end of the Create menu in the authoring area](assets/learning_resource_file_v2_en.png){ width="202" class="aside-right lightbox" title="Create menu in the authoring area · 2026.11.10" }

Via "Import file", you bring further file types into OpenOlat as a learning resource, for example PDF, PowerPoint, Excel and Word files as well as images, music and animations.

If a document editor is switched on, you also create Word, Excel or PowerPoint files directly in OpenOlat as a learning resource. The "Create" menu shows which file types you can create with your configuration.


!!! info "Important"

    Diagram files (draw.io) can usually not be created directly here. Use the Media Center, a course or the "Projects" area for this purpose.
