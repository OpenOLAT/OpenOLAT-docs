# General Functions: Info Page {: #general_functions_info}

## What's the purpose of the info page? {: #purpose}

Each learning resource has an info page. This page contains information provided by the system, as well as details that the owners of the learning resource can add themselves. These are available to interested users as soon as the learning resource is published (regardless of a booking), even before they access the learning resource. This makes sense if you want to inform the target audience in advance, for example, if the course involves a fee.

!!! note "Note"

    If you, as a participant, can hardly find any information on the info page, it is because your instructor has not set up this page (yet). Ask your instructor about it.

## How do you access the info page? {: #access}

### Access the info page via the course overview {: #access_course_overview}

In the main navigation, open your course overview by clicking on "Courses".<br>
Then select the link "Learn more" next to the "Open" button of a course.

![Link Learn more next to the Open button of a course, highlighted in the course overview Courses in the tab Active](assets/general_functions_infopage_access_courses_v1_de.png){ class="shadow lightbox" }


[To the top of the page ^](#general_functions_info)

---


### Access the info page in the catalog {: #access_catalog}

In the tile view of the catalog, you find the link "Learn more" to display the info page at the bottom right. You can also click on the image.

![Tile of a course in the catalog, highlighted are the image and the link Learn more at the bottom right next to the Open button](assets/general_functions_infopage_access_catalog_tile_v1_de.png){ class="shadow lightbox" }

In the list view, click the link "Learn more" or the title of the learning resource.

![List view of the catalog, highlighted are the title of a course and the link Learn more in the column of the same name](assets/general_functions_infopage_access_catalog_list_v1_de.png){ class="shadow lightbox" }

[To the top of the page ^](#general_functions_info)

---


### Access the info page within a course {: #access_within_a_course}

Once you are in the course, select the icon "Course info" in the toolbar.

![Icon Course info highlighted in the toolbar of an opened course, next to it Course chat and Course search](assets/general_functions_infopage_access_toolbar_v1_de.png){ class="shadow lightbox" }

[To the top of the page ^](#general_functions_info)

### Access the info page of other learning resources {: #access_other_learning_resources}

The info page of other learning resources can be accessed in the same way as the info page of courses.
Unlike courses, it also contains information on usage.
