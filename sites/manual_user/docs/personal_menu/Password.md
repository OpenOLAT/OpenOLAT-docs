# Personal Configuration: Password {: #personal_configuration_password}

![Entry Password in the section Configuration of the personal menu, below the entries Profile and System settings](assets/pers_menu_password_v1_de.png){ class="aside-right lightbox"}

![Icon Password](assets/icon_password.png)

If your account is not controlled by an external user management system (see [Login Concept](../login_registration/Login_Concept.md)), you can change your password in the personal menu, section "Configuration". Enter your old OpenOlat password and then the new password twice. OpenOlat displays the criteria the new password must meet above the input fields.

![Current security level with button Change security level, criteria for the new password and the fields for the old, new and confirmed password, page Password in the personal menu](assets/Passwort_20_en.png){ class="shadow lightbox" }

* Administrators can force the renewal of the password at certain intervals.
* When assigning a new password, make sure not to use the old password again.
* The use of previous passwords can be prevented by administrators.
* If you have forgotten your password, you can request a new one on the [login page](../login_registration/Login_Page.md) via "Forgot password?". OpenOlat sends you an 8-digit validation code by e-mail. [:octicons-tag-16:{ title="from Release 20.0 (OO-8189)" }](https://track.frentix.com/issue/OO-8189)
* If SMS authentication is possible in your system and you have stored a mobile phone number, the validation code can also be sent by SMS.
* If enabled by the OpenOlat administrators, you can also change your [security level](../login_registration/Security_levels.md) yourself with "Change security level".
