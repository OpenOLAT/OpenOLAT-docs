# Personal tools: Booking orders {: #bookings}

![Personal tools menu with the entry Booking orders, which leads to the overview of all courses and learning resources the user booked themselves](assets/pers_menu_bookings_v3_de.png){ class="aside-right lightbox"}

![Booking orders icon](assets/icon_bookings.png)

Under "Booking orders" in the "Personal tools" section, users find an overview of all their booked courses and learning resources. Only those courses and learning resources appear that are linked to an [offer type](../learningresources/Access_configuration.md), e.g. an access code, and that the users booked themselves. Booking can be understood as a synonym for "enroll", "register" or "purchase".

Learning resources where the owners enter the participants manually, or where participants are assigned via a group, do *not* appear here.

![Table My booking orders with booking number, status, offer type, content and order date per booking, above it the tabs Booking orders and Billing addresses](assets/pers_menu_booking_orders2_v1_en.png){ class="shadow lightbox" }

Use the cogwheel to select the columns you want to see, e.g. the offer type ("Access code", "Freely available", "Invoice", PayPal), the offer and the content (the booked learning resource). With every booking, OpenOlat automatically creates a booking number under which this booking order is managed. This number is also shown here.

Use the download icon to the right of the cogwheel to download all booking orders as a table. Use the 3-dot menu of a booking to display the detail information on this booking order.

If the offer type "Invoice" is enabled, the additional tab "Billing addresses" appears. There you see the billing addresses stored for your bookings. [Administrators](../../manual_admin/administration/Modules_Organisations.md) maintain the billing addresses of organisations.

The option to book also appears in the [catalog](../area_modules/catalog2.0_angebote.md#offers_create), provided that the corresponding offer has been published there.
