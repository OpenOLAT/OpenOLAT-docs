# Personal achievements/successes {: #achievements}

What you have achieved in OpenOlat is found in the [personal menu](../index.md) in the section "Achievements/Successes", between the sections "User tools" and "Configuration": results from courses, certificates, badges, competences and credit points.

Which menu items you see here is set by system administrators. In your [Settings](../Settings.md#personal_tools) you decide yourself whether a menu item also appears as an icon in the main navigation.


## Menu items {: #menu_items}

If you are looking for proof of something you have achieved, the overview tells you under which menu item it is located and takes you to its description with the link. The table follows the order in the personal menu.

| Menu item | Purpose |
|---|---|
| [Evidence of achievement](../Evidence_of_Achievements.md) | See the results of your courses, for example points and status of your tests and tasks. |
| [Certificates](../Certificates.md) | See all your certificates, including expired ones, and upload your own certificates. |
| [Badges](../OpenBadges.md) | See the badges you have earned, download them as an image file or add them to your LinkedIn profile. |
| [Competences](../Competences.md) | See the competences assigned to you. |
| [Credit points](../Credit_Points.md) | See the credit points credited to you for completed courses. |
