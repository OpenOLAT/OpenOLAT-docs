# Personal tools: Media Center {: #media_center}

![Entry Media Center in the Personal tools menu: access to your own media and to the media that others have shared with you](assets/pers_menu_mediacenter_v3_de.png){ class="aside-right lightbox"}

![Media Center icon](assets/icon_media_center.png)

All OpenOlat users find their personal "Media Center" under "Personal tools". Here, users can create, upload and manage media. Media that other users have shared with you is also displayed here. 

The media can be normal files, for example, but also OpenOlat-specific elements such as forum posts, blog entries or evidence of achievement. 
Furthermore, various filter options are available to display only certain files. 

![Tile view My Media Center with five media items, the tabs from All to Search, the filters by type, subject, usage and share, and the button Add media file](assets/pers_menu_media_center_example_v1_de.png){ class=" shadow lightbox" }

"My Media Center" initially reflects a person's individual files. This is why the Media Center can also be found under Personal tools. Regardless of this, the media in the Media Center can also be accessed at certain points in OpenOlat, e.g. in courses or in the portfolio. A corresponding menu appears there, which can be used to select existing elements from your own Media Center or to create new media and save them directly in the Media Center.

Detailed information on how the Media Center works can be found at ["Media Center Concept"](../basic_concepts/Media_Center_Concept.md).
