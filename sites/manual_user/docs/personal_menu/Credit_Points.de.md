# Persönliche Erfolge/Leistungen: Kreditpunkte {: #credit_points}

![Menügruppe Erfolge/Leistungen mit den Einträgen Leistungsnachweise, Zertifikate, Badges und Kreditpunkte, der Eintrag Kreditpunkte ist ausgewählt, im persönlichen Menü](assets/pers_menu_credit_points_v2_de.png){ class="aside-right lightbox"}

![Symbol Kreditpunkte](assets/icon_credit_points.png)



Wenn in Kursen Kreditpunkte vergeben werden, werden Ihnen nach erfolgreichem Absolvieren eines Kurses Kreditpunkte gutgeschrieben.

Die Kreditpunkte können Ihnen in verschiedenen "Währungen" gutgeschrieben werden. Welche "Währungen" (Kreditpunktesysteme) grundsätzlich im System verfügbar sind, legen Administrator:innen fest.

Im persönlichen Menü unter "Kreditpunkte" finden Sie Ihr aktuelles Kreditpunkteguthaben.

Die Seite "Meine Kreditpunkte" zeigt je Kreditpunktesystem die Kacheln "Kreditpunkteguthaben" und "Nächster Kreditpunkteverfall". Darunter listet die Tabelle "Transaktionen" alle Gutschriften, Belastungen, Stornos, Abzüge und Verfälle auf. Mit den Tabs "Alle", "Relevant" und "Verfallen" sowie den Filtern "Buchungsnummer" und "Typ" grenzen Sie die Liste ein. [:octicons-tag-16:{ title="ab Release 20.1.1 (OO-8558)" }](https://track.frentix.com/issue/OO-8558)

Ein Kreditpunktesystem erscheint erst, wenn Sie darin Transaktionen haben oder Mitglied eines Zertifikatsprogramms sind, das dieses Kreditpunktesystem verwendet. [:octicons-tag-16:{ title="ab Release 20.2.0 (OO-9070)" }](https://track.frentix.com/issue/OO-9070)

## Kreditpunkte als Voraussetzung für eine Kursteilnahme {: #prerequisite}

Im Rahmen von Zertifikatsprogrammen kann eingerichtet werden, dass vor der Zulassung zu einem Kurs eine bestimmte Anzahl Kreditpunkte auf Ihrem Konto vorhanden sein muss.

Beachten Sie dabei, dass es Kreditpunkte in verschiedenen "Währungen" (Kreditpunktesystemen) geben kann.

**Beispiel**<br>
Es kann z.B. eingerichtet werden, dass Sie "Sicherheitspunkte" (= Währung der OpenOlat-Kreditpunkte) in verschiedenen Sicherheitsschulungen Level 1 erwerben können. Für die Zulassung zu einer Sicherheitsschulung Level 2 kann als Voraussetzung ein Guthaben von 50 "Sicherheitspunkten" verlangt werden. Andere Kreditpunkte werden für diese Schulung nicht anerkannt.

## Mit Kreditpunkten weitere OpenOlat-Kurse bezahlen {: #pay_with_credit_points}

Kreditpunkte können auch als Währung verwendet werden. Die Möglichkeit, mit Kreditpunkten innerhalb OpenOlat weitere Kurse zu bezahlen, ist in Entwicklung. (Stand: Release 20.2.0)
