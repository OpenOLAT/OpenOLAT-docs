# Personal achievements/successes: Competences {: #competences}

![Menu group Achievements/Successes in the personal menu, the entry Competences is marked: this is where you find the overview of your competences](assets/pers_menu_competences_v4_en.png){ width="244" class="aside-right lightbox" }

![Competences icon](assets/icon_competences.png)


You see which competences are assigned to you in OpenOlat in the personal menu, in the section "Achievements/Successes" under "Competences".

You receive competences, for example, via your ePortfolio entries, or user managers enter them in your user profile.


![List My competences, structured by taxonomy and taxonomy level, with the columns Competence, Resource, Additional information and Type; types are Manage or Have](assets/pers_menu_competences_example_v1_de.png){ class="shadow lightbox" title="Competences in the section Achievements/Successes" }

!!! info "Important"

    Competences always belong to a taxonomy. The list therefore only shows entries if system administrators have enabled the module Taxonomy and built taxonomies. They set up both in the system administration: `Administration > Modules > Taxonomy`.
