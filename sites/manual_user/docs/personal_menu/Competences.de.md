# Persönliche Erfolge/Leistungen: Kompetenzen {: #competences}

![Menügruppe Erfolge/Leistungen im persönlichen Menü, der Eintrag Kompetenzen ist markiert: Hier finden Sie die Übersicht Ihrer Kompetenzen](assets/pers_menu_competences_v4_de.png){ width="244" class="aside-right lightbox" }

![Symbol Kompetenzen](assets/icon_competences.png)


Welche Kompetenzen Ihnen in OpenOlat zugeordnet sind, sehen Sie im persönlichen Menü im Abschnitt "Erfolge/Leistungen" unter "Kompetenzen".

Kompetenzen erhalten Sie zum Beispiel über Ihre ePortfolio-Einträge, oder Benutzerverwalter:innen tragen sie in Ihrem Benutzerprofil ein.


![Liste Meine Kompetenzen, gegliedert nach Taxonomie und Taxonomieebene, mit den Spalten Kompetenz, Ressource, Zusätzliche Informationen und Typ; Typen sind Verwalten oder Haben](assets/pers_menu_competences_example_v1_de.png){ class="shadow lightbox" title="Kompetenzen im Abschnitt Erfolge/Leistungen" }

!!! info "Wichtig"

    Kompetenzen gehören immer zu einer Taxonomie. Die Liste zeigt deshalb nur dann Einträge, wenn Systemadministrator:innen das Modul Taxonomie eingeschaltet und Taxonomien aufgebaut haben. Beides richten sie in der System-Administration ein: `Administration > Module > Taxonomie`.
