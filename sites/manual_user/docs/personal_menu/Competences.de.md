# Persönliche Erfolge/Leistungen: Kompetenzen {: #competences}

![Menügruppe Erfolge/Leistungen im persönlichen Menü, der Eintrag Kompetenzen ist markiert: Hier finden Sie die Übersicht Ihrer Kompetenzen](assets/pers_menu_competences_v4_de.png){ width="244" class="aside-right lightbox" }

![Symbol Kompetenzen](assets/icon_competences.png)


Welche Kompetenzen Ihnen in OpenOlat zugeordnet sind, sehen Sie im [persönlichen Menü](index.de.md) im Abschnitt "Erfolge/Leistungen" unter "Kompetenzen". [:octicons-tag-16:{ title="ab Release 15.5 (OO-5354)" }](https://track.frentix.com/issue/OO-5354)

Kompetenzen erhalten Sie zum Beispiel, wenn Sie in Ihrem ePortfolio einem Eintrag eine Kompetenz zuordnen. Ausserdem tragen Benutzerverwalter:innen Kompetenzen in der Benutzerverwaltung bei Ihrem Konto ein.


![Liste Meine Kompetenzen nach Taxonomie und Ebene gegliedert, je Kompetenz mit ihrer Herkunft in der Spalte Ressource und dem Typ Haben oder Verwalten](assets/pers_menu_competences_example_v2_de.png){ class="shadow lightbox" title="Kompetenzen im Abschnitt Erfolge/Leistungen · 2026.11.26" }

Die Liste "Meine Kompetenzen" ist nach Taxonomie gegliedert. Eine Taxonomie ist ein Baum von Fachgebieten, mit dem Ihre Organisation Kompetenzen, Lernressourcen und Fragen einordnet; jede Verzweigung ist eine Taxonomieebene. Die Spalte "Ressource" zeigt, woher eine Kompetenz stammt: "Portfolio" aus Ihrem ePortfolio, "Händisch vergeben" von einer Person in OpenOlat, etwa in der Benutzerverwaltung, "Extern vergeben" von einem anderen System über die Schnittstelle von OpenOlat. Ein Klick auf "Portfolio" öffnet den Eintrag in Ihrem ePortfolio. Die Spalte "Typ" sagt, in welcher Beziehung Sie zur Kompetenz stehen, etwa "Haben" oder "Verwalten". Was die einzelnen Kompetenztypen bedeuten, erklärt die Seite [Taxonomie](../basic_concepts/Taxonomy_Concept.de.md#competences).

!!! info "Wichtig"

    Kompetenzen gehören immer zu einer Taxonomie. Die Liste zeigt deshalb nur dann Einträge, wenn Systemadministrator:innen das Modul Taxonomie eingeschaltet und Taxonomien aufgebaut haben. Beides richten sie in der System-Administration ein: `Administration > Module > Taxonomie`.
