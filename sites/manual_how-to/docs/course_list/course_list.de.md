# Wie erstelle ich eine Excel-Liste aller vorhandenen Kurse? {: #course_list}

??? abstract "Ziel und Inhalt dieser Anleitung"

    Sie haben bereits mehrere Kurse erstellt und benötigen eine Übersicht als Excel-Tabelle (auch der noch nicht veröffentlichten). Hier eine kurze Anleitung.

??? abstract "Zielgruppe"

    [x] Autor:innen [x] Betreuer:innen  [ ] Teilnehmer:innen

    [x] Anfänger:innen [x] Fortgeschrittene  [ ] Expert:innen

Im Autorenbereich lassen sich alle erstellten Kurse (auch die noch nicht veröffentlichten) durchsuchen, filtern und sortieren. Für manche Zwecke benötigt es jedoch den Export einer Übersichtsliste als Excel-Datei. Gehen Sie dazu in den folgenden Schritten vor.


## Schritt 1: Autorenbereich öffnen {: #open_authoring}

Den Autorenbereich zeigt Ihnen die Hauptnavigation, wenn Sie die Rolle Autor:in haben. Ebenso sehen ihn Lernressourcenverwalter:innen, Principals und Administrator:innen. Wenden Sie sich an Ihre Administrator:innen, falls Ihnen der Autorenbereich nicht angezeigt wird.

## Schritt 2: Suche der Kurse {: #search_courses}

* Verwenden Sie die Tabs "Favoriten", "Meine Kurse" oder "Meine Einträge", wenn diese Filter bereits eine Vorauswahl nach Ihren Vorstellungen enthalten.
* Verwenden Sie den Tab "Suche", wenn nicht nur die eigenen Kurse angezeigt werden sollen.
* Mit dem Suchfeld finden Sie Lernressourcen, deren Titel oder Kennzeichen den eingegebenen Text enthält. Geben Sie mehrere Wörter ein, sucht OpenOlat nach genau dieser Wortfolge.
* Starten Sie die Suche mit Klick auf das Lupensymbol oder durch Drücken der Eingabetaste.

Kurse im Papierkorb stehen im Tab "Gelöscht".

## Schritt 3: Filtern der Suchergebnisse {: #filter_results}

Setzen Sie den Filter "Typ = Kurs".<br>
Übernehmen Sie ihn mit Klick auf den Button "Übernehmen" am unteren Rand des Popups.

Der Tab "Meine Kurse" zeigt ausschliesslich Kurse. Dort entfällt dieser Schritt.

![Geöffneter Filter Typ mit angekreuztem Eintrag Kurs, darunter der Button Übernehmen](assets/course_list_filter_typ_v1_de.png){ class="shadow lightbox" title="Filter Typ im Autorenbereich" }

[zum Seitenanfang ^](#course_list)

## Schritt 4: Reihenfolge festlegen {: #set_order}

Die im Schritt 5 erzeugte Excel-Liste enthält die Zeilen in der gleichen Reihenfolge, wie sie in OpenOlat angezeigt werden. Bereiten Sie deshalb die Liste in OpenOlat entsprechend vor.

Klicken Sie auf die Spaltentitel, um die angezeigte Liste auf- oder absteigend zu sortieren. Alternativ wählen Sie das Sortierkriterium über den Sortier-Button rechts oben über der Liste. Er zeigt das aktive Kriterium an, etwa "Titel der Lernressource".

Wenn Sie eine andere Sortierung benötigen, hilft es Ihnen vielleicht, weitere Spalten einzublenden und nach diesen zu sortieren. Für das Einblenden weiterer Spalten klicken Sie auf das Zahnrad-Symbol "Spalten auswählen" rechts oben über der Liste.

[zum Seitenanfang ^](#course_list)

## Schritt 5: Erstellen einer Excel-Liste {: #create_list}

Klicken Sie auf den Button "Herunterladen" (Symbol mit Pfeil nach unten) rechts oben über der Liste und speichern Sie die Excel-Liste.

![Nach Typ Kurs gefilterte Liste, rechts oben über der Liste der Button Herunterladen markiert](assets/course_list_download_v1_de.png){ class="shadow lightbox" title="Gefilterte Kursliste im Autorenbereich" }
